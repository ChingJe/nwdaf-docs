# NWDAF 與外部產業應用規格解讀

本分類記錄 NWDAF 與外部產業應用（vertical application）整合的規格解讀。內容以 SEAL 為主軸：先弄清楚 SEAL 是什麼、長什麼樣、怎麼與核心網路和應用互動，再把 VAL、ADAE、AIMLE 與 NWDAF 放到對應的位置。

## 解讀目標

理解 NWDAF 與外部應用層的角色、能力及整合邊界，釐清應用資料、網路資料與分析結果如何在規格所描述的架構中被使用。

文件中的產業應用例子僅用於解釋概念；研究方向與具體應用選擇以另行確認的決定為準。這些研究紀錄不直接構成目前 Release 18 實作的需求。

## 紀錄方式

- 每份文件標明實際使用的 Release、版本與條文。

- 修正既有理解時，更新原文並保留修正原因及規格出處。
- 主線每篇維持只回答一個問題；新的主題另開一篇或放入輔助文件，並更新本索引。
