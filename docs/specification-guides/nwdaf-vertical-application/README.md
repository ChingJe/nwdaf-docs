# NWDAF 與外部產業應用規格解讀

本分類記錄 NWDAF 與外部產業應用（vertical application）整合的規格解讀，
從基本名詞開始，逐步理解應用層分析、AI/ML 支援與網路分析之間的角色關係。

## 解讀目標

理解 NWDAF 與外部應用層的角色、能力及整合邊界，
釐清應用資料、網路資料與分析結果如何在規格所描述的架構中被使用。

後續解讀將逐步釐清誰提供資料、誰負責分析，以及應用如何使用結果。
具體資料路徑與整合方式仍需依規格查證。
文件中的產業應用例子僅用於解釋概念；研究方向與具體應用選擇以另行確認的決定為準。

每份文件應標明實際使用的 Release、版本與條文。
這些研究紀錄不直接構成目前 Release 18 實作的需求。

## 後續紀錄方式

每次新增少量已討論的內容，依主題維護文件並更新本索引。
後續可分別建立架構分工、資料流及與 NWDAF 整合的解讀。
規格內容、說明用例子、研究推論與待查證問題應明確區分；
若修正既有理解，更新原文並保留修正原因及規格出處。
