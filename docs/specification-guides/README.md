# Specification Guides

此分類收錄跨越多份 3GPP Technical Specification 與 OpenAPI 的規格解讀。
文件的目的，是先建立標準能力、角色、介面與流程邊界，再供
`docs/design/` 的架構決策及 `docs/plans/` 的實作規劃引用。

本分類中的文件應區分：

- 規格明確要求的行為；
- 規格允許但交由實作或營運政策決定的行為；
- 規格沒有定義、需要專案自行建立的協議；
- 現有 free5GC 或本專案實作與 Release 18 規格的差距。
