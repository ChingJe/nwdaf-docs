# 6.1.6.2.6 Type: AssignedEbiData

Table 6.1.6.2.6-1: Definition of type AssignedEbiData

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------|-----|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------|
| pduSessionId                                                                                                                                                                                                                                          | PduSessionId         | M   | 1           | Represents the identifier of the PDU Session requesting EBI(s) to be assigned.                                                                                                                                                |               |
