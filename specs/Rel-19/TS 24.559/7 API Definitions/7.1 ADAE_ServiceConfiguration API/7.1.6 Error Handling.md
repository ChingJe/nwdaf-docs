# 7.1.6 Error Handling


## 7.1.6.1 General

HTTP error handling shall be supported as specified in clause 5.2.6 of 3GPP TS 29.122 \[4\].

In addition, the requirements in the following clauses shall apply.

## 7.1.6.2 Protocol Errors

In this release of the specification, there are no additional protocol errors applicable for the ADAE_ServiceConfiguration API.
