# 7.1.3.3 Resource: Individual application performance event subscription


## 7.1.3.3.1 Description

The individual application performance event subscription resource represents an individual event subscription of the ADAES.

## 7.1.3.3.2 Resource Definition

Resource URI: **{apiRoot}/adae-sc/\<apiVersion\>/application-performance****/{appPerfId}**

This resource shall support the resource URI variables defined in the table 7.1.3.3.2-1.

Table 7.1.3.3.2-1: Resource URI variables for this resource

| Name      | Data Type | Definition                                               |
|-----------|-----------|----------------------------------------------------------|
| apiRoot   | string    | See clause 5.2.4 in 3GPP TS 29.122 \[6\]                 |
| appPerfId | string    | Identifies an application performance event subscription |
