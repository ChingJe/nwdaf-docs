## 7.1.4.2 Application performance event notification


### 7.1.4.2.1 Description

Application performance event notification is by the ADAEC to notify the ADAES, the VAL performance analytics.

### 7.1.4.2.2 Notification definition

The POST method shall be used for the event notification and the callback URI shall be the one provided by the consumer during the subscription to the event.

Callback URI: **{notifUri}**
