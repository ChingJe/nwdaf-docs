# 5 Functional entities


## 5.1 Application data analytics enablement server (ADAES)

The ADAES is a functional entity with a unique identity in the PLMN and uses the provided data analytics to administer the operations and performance of one or more VAL applications.

## 5.2 Application data analytics enablement client (ADAEC)

The ADAEC is a functional entity with a unique identity and acts as the VAL application client which provides data analytics of the VAL applications.
