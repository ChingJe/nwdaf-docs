# 28.21 MPQUIC Identifiers

## 28.21.1 General

The following clauses describe MPQUIC specific identifiers which are used by both the UE and the 5GC (UPF) if MPQUIC functionality is utilized, see clause 5.32 in TS 23.501 \[119\].

## 28.21.2 Context ID

If MPQUIC functionality is used between the UE and the anchor UPF, the Context ID value determines the contents of the UDP Proxying Payload (see section 4 and section 5 of IETF RFC 9298 \[150\]) and also whether 3GPP specified Datagram mode 1 or mode 2 is used (see TS 24.193 \[151\]).
