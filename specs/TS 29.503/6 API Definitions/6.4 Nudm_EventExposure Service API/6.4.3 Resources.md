## 6.4.3.2 Resource: EeSubscriptions (Collection)


### 6.4.3.2.1 Description

This resource is used to represent subscriptions to notifications.


### 6.4.3.2.2 Resource Definition

Resource URI: {apiRoot}/nudm-ee/v1/{ueIdentity}/ee-subscriptions

This resource shall support the resource URI variables defined in table 6.4.3.2.2-1.

Table 6.4.3.2.2-1: Resource URI variables for this resource

<table>
<colgroup>
<col style="width: 11%" />

<thead>
<tr class="header">
<th>Name</th>
<th>Data type</th>
<th>Definition</th>
</tr>
</thead>
<tbody>
<tr class="odd">
<td>apiRoot</td>
<td>string</td>
<td>See clause 6.4.1</td>
</tr>
<tr class="even">
<td>ueIdentity</td>
<td>string</td>
<td><p>Represents a single UE or a group of UEs or any UE.</p>
<p>- If representing a single UE, this parameter shall contain the Generic Public Subscription Identifier (see TS 23.501 [2] clause 5.9.8) or Subscription Permanent Identifier (see TS 33.535 [55] clause 6.2.1 for the usage of SUPI in this procedure).<br />
pattern: "^(msisdn-[0-9]{5,15}|extid-[^@]+@[^@]+|.+|imsi-[0-9]{5,15}|nai-.+|gci-.+|gli-.+)$"</p>
<p>- If representing a group of UEs, this parameter shall contain the External GroupId.</p>
<p>pattern: "^extgroupid-[^@]+@[^@]+$"</p>
<p>- If representing any UE, this parameter shall contain "anyUE".</p>
<p>pattern: "^anyUE$"</p></td>
</tr>

</table>
