## 6.3.5.2 Data Restoration Notification

The POST method shall be used to inform the NF Service Consumer about a potential data-loss event occurred at the UDR, and the callback URI may be provided during the confirmation of a successful authentication event, or dynamically discovered by UDM by querying NRF for a default notification URI.

Resource URI: {dataRestorationCallbackUri}

Support of URI query parameters is specified in table 6.3.5.2-1.

Table 6.3.5.2-1: URI query parameters supported by the POST method

|------|-----------|-----|-------------|-------------|

| n/a  |           |     |             |             |
