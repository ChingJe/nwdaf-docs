# 6.1.3.32 Resource: UcSubscriptionData (Document)


## 6.1.3.32.1 Description

This resource represents the subscribed User Consent Data for a UE as defined in Annex V.2 of TS 33.501 \[6\], clause 5.1.3 of TS 33.558 \[63\] and clause 6.2 of TS 23.288 \[35\]. It is queried by the NWDAF, DCCF, NEF and trusted AF (e.g. EES).


## 6.1.3.32.2 Resource Definition

Resource URI: {apiRoot}/nudm-sdm/\<apiVersion\>/{supi}/uc-data
