# 6.1.3.12 Resource: IdTranslationResult (Document)


## 6.1.3.12.1 Description

This resource represents the SUPI or GPSI. It is queried by the NEF for GPSI to SUPI translation or SUPI to GPSI translation. See TS 23.502 \[3\] clauses 4.13.2.2, 4.13.7.2 and 4.15.6.8.


## 6.1.3.12.2 Resource Definition

Resource URI: {apiRoot}/nudm-sdm/\<apiVersion\>/{ueId}/id-translation-result
