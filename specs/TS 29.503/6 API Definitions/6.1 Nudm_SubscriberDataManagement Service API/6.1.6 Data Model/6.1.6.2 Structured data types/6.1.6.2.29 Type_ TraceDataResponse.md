# 6.1.6.2.29 Type: TraceDataResponse

Table 6.1.6.2.29-1: Definition of type TraceDataResponse

| Attribute name    | Data type    | P   | Cardinality | Description                                                                                                                           | Applicability |
|-------------------|--------------|-----|-------------|---------------------------------------------------------------------------------------------------------------------------------------|---------------|
| traceData         | TraceData    | C   | 0..1        | UE-individual trace data. Shall not be absent unless the feature SharedData is supported and traceData is present within shared data. |               |
| sharedTraceDataId | SharedDataId | C   | 0..1        | Shared data identifier. Shall be present if traceData is absent.                                                                      |               |
