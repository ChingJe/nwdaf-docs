<td>C</td>
<td>0..1</td>
<td><p>When present, this IE indicates the Confidence level for the associated Expected UE Behaviour parameter.</p>
<p>The confidence level is a string formatted as {operator}+{value}.</p>
<p>The following operators shall be supported:</p>
<p>"=" match parameter value equal to the value indicated.</p>
<p>"&gt;" match parameter value greater than the value indicated</p>
<p>"&gt;=" match parameter value greater than or equal to the value indicated</p>
<p>"&lt;" match parameter value less than the value indicated</p>
<p>"&lt;=" match parameter value less than or equal to the value indicated</p>
<p>If no operator or an unknown operator is provided, "=" operator is applied.</p>
<p>The value shall be between 0.01 and 1.00 with a step size of 0.01.</p>
<p>The string can be extended by using '&amp;' operator as below:</p>
<p>{operator}+{value}&amp;{operator}+{value}</p>
<p><u>Examples:</u></p>
<p>Case1: "=0.5" or "0.5" means matching the value "0.5"</p>
<p>Case2: "&gt;0.6" means value greater than "0.6"</p>
<p>Case3: "&gt;0.2&amp;&lt;0.4" means the value in the range of "0.2" and "0.4".</p>
<p>(NOTE 1)</p></td>
