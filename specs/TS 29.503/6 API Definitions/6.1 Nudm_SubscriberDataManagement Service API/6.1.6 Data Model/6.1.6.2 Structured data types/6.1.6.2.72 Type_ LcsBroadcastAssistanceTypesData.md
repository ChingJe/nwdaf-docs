<td><p>This IE contains a bitmap ,encoded as a base64 string, which indicates the broadcast location assistance data types for which the UE is subscribed to receive ciphering keys used to decipher broadcast assistance data. A bit set to 1 indicates that the UE is subscribed to receive ciphering keys applicable to corresponding positioning SIB type.</p>
<p>The bits are ordered as following in the bitmap:</p>
<p>- first octet is the right-most octet. E.g. in "0x0123", “first octet” would be "0x23" and “second octet” would be "0x01"</p>
<p>- bit 1 is the right-most bit and bit 8 is the left-most bit in the octet. E.g. for octet "0x01", “bit 1” would be "1", and “bit 2” to "bit 8" would be "0"</p>
<p>The mapping of the bits to the positioning SIB types is as follows:</p>
<p>-- bit 8 in the first octet maps to positioning SIB Type 1-1</p>
<p>-- bit 7 in the first octet maps to positioning SIB Type 1-2</p>
<p>-- bit 6 in the first octet maps to positioning SIB Type 1-3</p>
<p>-- bit 5 in the first octet maps to positioning SIB Type 1-4</p>
<p>-- bit 4 in the first octet maps to positioning SIB Type 1-5</p>
