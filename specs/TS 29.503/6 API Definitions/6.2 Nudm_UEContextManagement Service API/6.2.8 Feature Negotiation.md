# 6.2.8 Feature Negotiation

The optional features in table 6.2.8-1 are defined for the Nudm_UECM API. They shall be negotiated using the extensibility mechanism defined in clause 6.6 of TS 29.500 \[4\].

Table 6.2.8-1: Supported Features

<table>
<colgroup>
<col style="width: 15%" />
<col style="width: 26%" />
<col style="width: 58%" />
</colgroup>
<thead>
<tr class="header">
<th>Feature number</th>
<th>Feature Name</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr class="odd">
<td>1</td>
<td>SharedData</td>
<td>When receiving a Nudm_UECM_Registration service operation request for a UE that shares subscription data with other UEs, and the request does not indicate support of this feature by the service consumer, the UDM may – based on operator policy – decide to reject the registration.</td>
</tr>
<tr class="even">
<td>2</td>
<td>PatchReport</td>
<td>If some of the modifications included in the PATCH request are not successfully implemented, the UDM reports the result of PATCH request execution to the consumer. See clause 5.2.7.2 of TS 29.500 [4].</td>
</tr>
<tr class="odd">
<td>3</td>
<td>SharedDataTreatment</td>
<td><p>This feature is an extension to the SharedData feature, i.e. support of SharedDataTreatment requires support of SharedData.</p>
<p>When receiving a Nudm_UECM_Registration service operation request for a UE that shares subscription data with treatment instruction with other UEs, and the request does not indicate support of this feature by the service consumer, the UDM may – based on operator policy – decide to reject the registration.</p></td>
</tr>
<tr class="even">
<td>4</td>
<td>CAGFeature</td>
<td>If the NF consumer (AMF) does not support this feature and the UE is allowed to access 5GS via CAG cell(s) only, the UDM shall reject AMF registration.</td>
</tr>
<tr class="odd">
<td>5</td>
<td>DeregistrationResponseBody</td>
<td>The UDM and the NF consumer (e.g. SMF) supporting this feature shall support sending information in Deregistration Notification body with "200 OK" response (e.g. the indication that the SMF event subscriptions on the SMF for the UE have been implicitly removed).</td>
</tr>

</table>
