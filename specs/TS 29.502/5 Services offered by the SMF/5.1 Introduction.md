# 5.1 Introduction

The SMF supports the following services.

Table 5.1-1: NF Services provided by SMF

| Service Name       | Description                                                                                                                                                                                                                                                         | Example Consumer              |
|--------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------|
| Nsmf_PDUSession    | This service manages the PDU sessions and uses the policy and charging rules received from the PCF. The service operations exposed by this NF service allows the consumer NFs to establish, modify and delete the PDU sessions, and to send mobile originated data. | V-SMF, H-SMF, I-SMF, SMF, AMF |
| Nsmf_EventExposure | See 3GPP TS 29.508 \[6\].                                                                                                                                                                                                                                           |                               |
| Nsmf_NIDD          | See 3GPP TS 29.542 \[37\].                                                                                                                                                                                                                                          |                               |
