# 6.1.6.4 Binary data

## 6.1.6.4.1 Introduction

This clause defines the binary data that shall be supported in a binary body part in an HTTP multipart message (see clauses 6.1.2.2.2 and 6.1.2.4).

Table 6.1.6.4.1-1: Binary Data Types

| Name               | Clause defined | Content type   |
|--------------------|----------------|----------------|
| N1 SM Message      | 6.1.6.4.2      | vnd.3gpp.5gnas |
| N2 SM Information  | 6.1.6.4.3      | vnd.3gpp.ngap  |
| n1SmInfoFromUe     | 6.1.6.4.4      | vnd.3gpp.5gnas |
| n1SmInfoToUe       | 6.1.6.4.4      | vnd.3gpp.5gnas |
| unknownN1SmInfo    | 6.1.6.4.4      | vnd.3gpp.5gnas |
