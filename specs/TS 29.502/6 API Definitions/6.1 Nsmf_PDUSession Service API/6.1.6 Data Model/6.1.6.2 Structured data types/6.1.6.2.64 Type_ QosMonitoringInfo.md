<td><p>This IE shall be present and set to "true" if QoS monitoring activated for QoS flows of the PDU session is performed using end to end accumulated packet delay reporting in UL GTP-U packets (see clause 5.33.3.3 of 3GPP TS 23.501 [2]).</p>

<p>- False (default): QoS monitoring is performed using UPF and RAN time information in GTP-U packets (see clause 5.33.3.2 of 3GPP TS 23.501 [2]).</p>
<p>When this attribute is present and set to "true", the I-SMF shall provision the I-UPF to report an end to end accumulated packet delay in UL GTP-U packets as specified in 3GPP TS 29.244 [29].</p></td>
