# 6.1.6.2.34 Type: GroupIdentifiers

Table 6.1.6.2.34-1: Definition of type GroupIdentifiers

| Attribute name | Data type   | P   | Cardinality | Description                                                                                                                     |
|----------------|-------------|-----|-------------|---------------------------------------------------------------------------------------------------------------------------------|
| extGroupId     | ExtGroupId  | C   | 0..1        | This IE shall contain the External Group ID associated to the provided Internal Group ID.                                       |
| intGroupId     | GroupId     | C   | 0..1        | This IE shall contain the Internal Group ID associated to the provided External Group ID..                                      |
| ueIdList       | array(UeId) | C   | 1..N        | This IE shall contain a list of the UE identifiers that belong to the provided Internal/External Group ID if they are required. |
