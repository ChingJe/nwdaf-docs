# 6.1.6.2.109 Type: MbsrLocationInfo

Table 6.1.6.2.109-1: Definition of type MbsrLocationInfo

| Attribute name    | Data type       | P   | Cardinality | Description                                                                                                                                                                                   |
|-------------------|-----------------|-----|-------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| mbsrLocation      | array(Tai)      | C   | 1..N        | This IE contains the coverage area (i.e., a list of TAIs) for MBSR operation. mbsrLocation shall be present if and only if mbsrLocationAreas is absent.                                       |
| mbsrLocationAreas | array(AreaCode) | C   | 1..N        | This IE contrains the coverage area (i.e., Area Codes that can be interpreted by AMF into TAIs) for MBSR operation. mbsrLocationAreas shall be present if and only if mbsrLocation is absent. |
