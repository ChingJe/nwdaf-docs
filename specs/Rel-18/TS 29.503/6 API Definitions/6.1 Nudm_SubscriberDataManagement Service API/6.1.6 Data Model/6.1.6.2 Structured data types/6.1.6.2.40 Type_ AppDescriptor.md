# 6.1.6.2.40 Type: AppDescriptor

Table 6.1.6.2.40-1: Definition of type AppDescriptor

| Attribute name | Data type | P   | Cardinality | Description                                                                   |
|----------------|-----------|-----|-------------|-------------------------------------------------------------------------------|
| osId           | OsId      | O   | 0..1        | OS identifier, does not include an OS version number                          |
| appId          | string    | O   | 0..1        | Application identifier, does not include a version number for the application |
