# 6.4.6.2.26 Type: GroupMembListChanges

Table 6.4.6.2.26-1: Definition of type GroupMembListChanges

| Attribute name                                                                                    | Data type   | P   | Cardinality | Description                                   |
|---------------------------------------------------------------------------------------------------|-------------|-----|-------------|-----------------------------------------------|
| addedUEs                                                                                          | array(Gpsi) | O   | 1..N        | Identifies the UE(s) added to the group.      |
| removedUEs                                                                                        | array(Gpsi) | O   | 1..N        | Indentifies the UE(s) removed from the group. |
| NOTE: At least one of the "addedUEs" attributes and the "removedUEs" attribute shall be provided. |             |     |             |                                               |
