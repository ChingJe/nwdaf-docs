# 6.5.6.2.27 Type: MbsAssistanceInfo

Table 6.5.6.2.27-1: Definition of type MbsAssistanceInfo

| Attribute name | Data type    | P   | Cardinality | Description                                                                                                                                                                                              |
|----------------|--------------|-----|-------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| mbsSessionId   | MbsSessionId | M   | 1           | The IE shall contain the MBS session id of the MBS session for which the MBS Session Assistance Information is applicable.                                                                               |
| assistanceInfo | array(Gpsi)  | C   | 1..N        | The IE shall be present to contain a list of UEs eligible for MBS Session assistance for the MBS session except for the case when all UEs in the external group are eligible for MBS Session assistance. |
