# 6.5.9 Security

As indicated in TS 33.501 \[8\] and TS 29.500 \[4\], the access to the Namf_MBSBroadcast API may be authorized by means of the OAuth2 protocol (see IETF RFC 6749 \[9\]), based on local configuration, using the "Client Credentials" authorization grant, where the NRF (see TS 29.510 \[10\]) plays the role of the authorization server.

If OAuth2 is used, an NF Service Consumer, prior to consuming services offered by the Namf_MBSBroadcast API, shall obtain a "token" from the authorization server, by invoking the Access Token Request service, as described in TS 29.510 \[10\], clause 5.4.2.2.

NOTE: When multiple NRFs are deployed in a network, the NRF used as authorization server is the same NRF that the NF Service Consumer used for discovering the Namf_MBSBroadcast service.

The Namf_MBSBroadcast API defines a single scope "namf-mbs-bc" for the entire service, and it does not define any additional scopes at resource or operation level.
