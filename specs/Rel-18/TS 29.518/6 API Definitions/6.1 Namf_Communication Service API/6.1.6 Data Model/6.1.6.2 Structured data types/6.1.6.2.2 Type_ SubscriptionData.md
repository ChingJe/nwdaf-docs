# 6.1.6.2.2 Type: SubscriptionData

Table 6.1.6.2.2-1: Definition of type SubscriptionData

| Attribute name | Data type    | P   | Cardinality | Description                                                                                                                                                               |
|----------------|--------------|-----|-------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| amfStatusUri   | Uri          | M   | 1           | This IE shall include the callback URI to receive notification of AMF status change.                                                                                      |
| guamiList      | array(Guami) | C   | 1..N        | This IE shall be absent for subscribing to status change for any GUAMI supported by the AMF, it shall be present for subscribing to specific GUAMIs supported by the AMF. |
