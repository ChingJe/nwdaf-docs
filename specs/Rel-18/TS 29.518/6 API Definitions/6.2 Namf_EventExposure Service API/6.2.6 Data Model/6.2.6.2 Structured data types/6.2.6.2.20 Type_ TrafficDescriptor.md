# 6.2.6.2.20 Type: TrafficDescriptor

Table 6.2.6.2.20-1: Definition of type TrafficDescriptor

| Attribute name           | Data type                   | P   | Cardinality | Description                                                                                                                 |
|--------------------------|-----------------------------|-----|-------------|-----------------------------------------------------------------------------------------------------------------------------|
| dnn                      | Dnn                         | C   | 0..1        | This IE shall be present if it is available. When present, it shall indicate the Data Network Name.                         |
| sNssai                   | Snssai                      | C   | 0..1        | This IE shall be present if it is available. When present, it shall indicate the associated S-NSSAI for the PDU Session.    |
| dddTrafficDescriptorList | array(DddTrafficDescriptor) | C   | 1..N        | This IE shall be present if it is available. When present, it shall indicate the Traffic Descriptor related to the traffic. |
