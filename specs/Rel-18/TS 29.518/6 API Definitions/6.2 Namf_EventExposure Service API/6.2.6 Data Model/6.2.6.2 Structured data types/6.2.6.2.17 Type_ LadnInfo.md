# 6.2.6.2.17 Type: LadnInfo

Table 6.2.6.2.17-1: Definition of type LadnInfo

| Attribute name | Data type     | P   | Cardinality | Description                                                                                                                                                                                |
|----------------|---------------|-----|-------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ladn           | string        | M   | 1           | Represents the Local Access Data Network DNN. The AMF shall identify the list of tracking areas corresponding to the LADN DNN based on local configuration.                                |
| presence       | PresenceState | C   | 0..1        | This IE shall be included when the UE presence in area of interest is reported. When present, this IE contains the status of UE presence within the Area of Interest (IN / OUT / UNKNOWN). |
