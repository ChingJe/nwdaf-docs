# 28.19 User Location Information for UE accessing to 5G-RG acting as a TNAP

The User Location information for a UE behind the 5G-RG using trusted N3GPP access (see clause 7.2.8.1 of TS 23.316 \[131\]), shall include a TNAP ID with 5G-RG civic address information.
