# 28.14 Data Network Access Identifier (DNAI)

A Data Network Access Identifier (DNAI) is an operator defined identifier of a user plane access to one or more DN(s) where applications are deployed (see clauses 3.1 and 5.6.7 in TS 23.501 \[119\]). The same DN may also be referred to by multiple DNAIs.

DNAI is represented as an operator specific string (see clause A.2 in TS 29.571 \[129\]. The format of the DNAI is defined by the operator and is not standardized.
