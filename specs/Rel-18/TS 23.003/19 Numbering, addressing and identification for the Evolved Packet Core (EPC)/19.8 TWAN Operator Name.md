# 19.8 TWAN Operator Name

The TWAN Operator Name identifies the TWAN operator when the TWAN is not operated by a mobile operator.

The TWAN Operator Name shall be encoded as a realm in the form of an Internet domain name, e.g. operator.com, as specified in IETF RFC 1035 \[19\] and IETF RFC 1123 \[20\]. The TWAN Operator Name consists of several labels. Each label shall consist of the alphabetic characters (A-Z and a-z), digits (0-9) and the hyphen (-) in accordance with IETF RFC 1035 \[19\]. Each label shall begin and end with either an alphabetic character or a digit in accordance with IETF RFC 1123 \[20\]. The case of alphabetic characters is not significant.

NOTE: The TWAN Operator Name is encoded as a dotted string.
