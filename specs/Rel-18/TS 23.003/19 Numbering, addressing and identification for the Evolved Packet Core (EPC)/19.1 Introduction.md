# 19.1 Introduction

This clause describes the format of the parameters needed to access the Enhanced Packet Core (EPC). For further information on the use of the parameters see TS 23.401 \[72\] and TS 23.402 \[68\]. For more information on the ".3gppnetwork.org" domain name and its applicability, see Annex D of the present document
