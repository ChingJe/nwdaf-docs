# 5.1.6.2.28 Type AddressList


Table 5.1.6.2.28-1: Definition of type AddressList

|                                                                     |                 |     |             |                                          |               |
|---------------------------------------------------------------------|-----------------|-----|-------------|------------------------------------------|---------------|
| Attribute name                                                      | Data type       | P   | Cardinality | Description                              | Applicability |
| ipv4Addrs                                                           | array(Ipv4Addr) | O   | 1..N        | Each element identifies an IPv4 address. |               |
| ipv6Addrs                                                           | array(Ipv6Addr) | O   | 1..N        | Each element identifies an IPv6 address. |               |
| NOTE: At least one of "ipv4Addrs" or "ipv6Addrs" shall be provided. |                 |     |             |                                          |               |
