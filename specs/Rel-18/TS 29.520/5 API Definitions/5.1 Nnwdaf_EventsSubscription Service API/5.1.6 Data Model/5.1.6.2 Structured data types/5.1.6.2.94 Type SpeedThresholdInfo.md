# 5.1.6.2.94 Type SpeedThresholdInfo


Table 5.1.6.2.94-1: Definition of type SpeedThresholdInfo

|                |               |     |             |                                                                                |               |
|----------------|---------------|-----|-------------|--------------------------------------------------------------------------------|---------------|
| Attribute name | Data type     | P   | Cardinality | Description                                                                    | Applicability |
| speedThr       | Float         | M   | 1           | Speed threshold utilized to filter the UEs, expressed in kilometres per hour.  |               |
| numOfUe        | Uinteger      | O   | 0..1        | Indicate the number of UEs whose speed is faster than the speed threshold.     |               |
| ratio          | SamplingRatio | O   | 0..1        | Indicate the percentage of UEs whose speed is faster than the speed threshold. |               |
