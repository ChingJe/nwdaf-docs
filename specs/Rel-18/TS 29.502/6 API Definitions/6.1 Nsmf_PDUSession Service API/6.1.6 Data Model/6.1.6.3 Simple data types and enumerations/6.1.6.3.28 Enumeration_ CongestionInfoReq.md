# 6.1.6.3.28 Enumeration: CongestionInfoReq

Table 6.1.6.3.28-1: Enumeration CongestionInfoReq

| Enumeration value | Description                                                                                       | Applicability |
|-------------------|---------------------------------------------------------------------------------------------------|---------------|
| UL                | Indicates to NG-RAN to report the congestion information of the QoS Flow on UL direction.         |               |
| DL                | Indicates to NG-RAN to report the congestion information of the QoS Flow on DL direction.         |               |
| BOTH              | Indicates to NG-RAN to report the congestion information of the QoS Flow on UL and DL directions. |               |
| STOP              | Indicates to NG-RAN to stop reporting the congestion information of the QoS Flow.                 |               |
