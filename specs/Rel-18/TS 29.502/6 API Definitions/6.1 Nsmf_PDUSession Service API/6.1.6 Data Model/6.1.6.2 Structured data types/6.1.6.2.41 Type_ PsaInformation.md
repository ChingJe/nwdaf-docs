# 6.1.6.2.41 Type: PsaInformation

Table 6.1.6.2.41-1: Definition of type PsaInformation

| Attribute name | Data type     | P   | Cardinality | Description                                                                                                                           |
|----------------|---------------|-----|-------------|---------------------------------------------------------------------------------------------------------------------------------------|
| psaInd         | PsaIndication | M   | 1           | This IE shall indicate, for a PDU session with an I-SMF, if a PSA and UL CL or BP, or only a PSA is inserted or removed by the I-SMF. |
| dnaiList       | array(Dnai)   | M   | 1..N        | This IE shall indicate the DNAI(s) supported by the PSA that is inserted or removed.                                                  |
| ueIpv6Prefix   | Ipv6Prefix    | C   | 0..1        | This IE shall be present if a PSA and UL CL or BP is inserted or removed, and IPv6 multi-homing applies to the PDU session.           |
| psaUpfId       | NfInstanceId  | C   | 0..1        | This IE shall be present if a PSA UPF is inserted by the I-SMF. When present, it shall contain the identifier of the PSA UPF.         |
