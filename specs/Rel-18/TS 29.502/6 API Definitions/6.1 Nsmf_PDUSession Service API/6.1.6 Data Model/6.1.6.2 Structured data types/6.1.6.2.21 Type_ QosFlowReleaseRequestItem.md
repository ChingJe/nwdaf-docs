# 6.1.6.2.21 Type: QosFlowReleaseRequestItem

Table 6.1.6.2.21-1: Definition of type QosFlowReleaseRequestItem

| Attribute name     | Data type | P   | Cardinality | Description                                                                                                                                                                                                                                                                                                                 |
|--------------------|-----------|-----|-------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| qfi                | Qfi       | M   | 1           | This IE shall contain the QoS Flow Identifier.                                                                                                                                                                                                                                                                              |
| qosRules           | Bytes     | O   | 0..1        | When present, this IE shall contain the QoS Rule(s) to be sent to the UE. It shall be encoded as the Qos rules IE specified in clause 9.11.4.13 of 3GPP TS 24.501 \[7\] (starting from octet 4).                                                                                                                            |
| qosFlowDescription | Bytes     | O   | 0..1        | When present, this IE shall contain the description of the QoS Flow level Qos parameters to be sent to the UE. It shall be encoded as the Qos flow descriptions IE specified in clause 9.11.4.12 of 3GPP TS 24.501 \[7\] (starting from octet 1), encoding one single Qos flow description for the QoS flow to be released. |
