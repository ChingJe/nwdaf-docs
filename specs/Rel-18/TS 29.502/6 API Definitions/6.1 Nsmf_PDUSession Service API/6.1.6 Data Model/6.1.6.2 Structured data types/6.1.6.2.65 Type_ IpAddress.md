# 6.1.6.2.65 Type: IpAddress

Table 6.1.6.2.65-1: Definition of type IpAddress

| Attribute name                                                      | Data type  | P   | Cardinality | Description              |
|---------------------------------------------------------------------|------------|-----|-------------|--------------------------|
| ipv4Addr                                                            | Ipv4Addr   | C   | 0..1        | Indicate an IPv4 Address |
| ipv6Addr                                                            | Ipv6Addr   | C   | 0..1        | Indicate an IPv6 Address |
| ipv6Prefix                                                          | Ipv6Prefix | C   | 0..1        | Indicate an IPv6 Prefix  |
| NOTE: Either ipv4Addr, or ipv6Addr, or ipv6Prefix shall be present. |            |     |             |                          |
