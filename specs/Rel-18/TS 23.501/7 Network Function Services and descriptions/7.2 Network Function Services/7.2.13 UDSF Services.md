# 7.2.13 UDSF Services

The following NF services are specified for UDSF:

Table 7.2.13-1: NF Services provided by UDSF

| Service Name                     | Description                                                                                                            | Reference in TS 23.502 \[3\] |
|----------------------------------|------------------------------------------------------------------------------------------------------------------------|------------------------------|
| Nudsf_UnstructuredDataManagement | Allows NF consumers to retrieve, create, update and delete data stored in the UDSF.                                    | 5.2.14.2                     |
| Nudsf_Timer                      | Allows NF consumers to start, stop, update and search timers in UDSF. NF consumers may be notified about timer expiry. | 5.2.14.3                     |
