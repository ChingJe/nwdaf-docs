# 6.1.6.2.116 Type: PruExistenceInfo


Table 6.1.6.2.116-1: Definition of type PruExistenceInfo

| Attribute name | Data type       | P   | Cardinality | Description                                                                                                                              |
|----------------|-----------------|-----|-------------|------------------------------------------------------------------------------------------------------------------------------------------|
| taiList        | array(Tai)      | O   | 1..N        | When present, this IE shall contain PRU(s) TAI list that the LMF can serve. It may contain one or more non-3GPP access TAIs.             |
| taiRangeList   | array(TaiRange) | O   | 1..N        | When present, this IE shall contain PRU(s) TAI range list that the LMF can serve. It may contain one or more non-3GPP access TAI ranges. |
