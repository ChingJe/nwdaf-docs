## 9.2.19.2 Aimles_HierarchicalServer_Registration operation

**API operation name:** Aimles_HierarchicalServer_Registration

**Description:** The consumer requests to register to central AIMLE server in hierarchical AIMLE deployments.

**Inputs:** See clause 8.27.3.1.

**Outputs:** See clause 8.27.3.2*.*

See clause 8.272.1 for details of usage of this operation.

## 9.2.19.3 Aimles_HierarchicalServer_UpdateRegistration operation

**API operation name:** Aimles_HierarchicalServer_UpdateRegistration

**Description:** The consumer requests to update registration information in central AIMLE server in hierarchical AIMLE deployments.

**Inputs:** See clause 8.27.3.3.

**Outputs:** See clause 8.27.3.4*.*

See clause 8.27.2.2 for details of usage of this operation.

## 9.2.19.4 Aimles_HierarchicalServer_De-Registration operation

**API operation name:** Aimles_HierarchicalServer_De-Registration

**Description:** The consumer requests to delete its registration from central AIMLE server in hierarchical AIMLE deployments.

**Inputs:** See clause 8.27.3.5.

**Outputs:** See clause 8.27.3.6*.*

See clause 8.27.2.3 for details of usage of this operation.
