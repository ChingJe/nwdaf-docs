9.2.18.2 Aimles_MLModelEvalInfoStorage_Request operation

**API operation name:** Aimles_MLModelEvalInfoStorage_Request

**Description:** The consumer requests for one time ML Model Evaluation Information storage.

**Inputs:** See clause 8.26.3.1.

**Outputs:** See clause 8.26.3.2*.*

See clause 8.26.2.2 for details of usage of this operation.

9.2.18.3 Aimles_MLModelEvalInfoRetrieval_Request operation

**API operation name:** Aimles_MLModelEvalInfoRetrieval_Request

**Description:** The consumer requests for one time ML Model Evaluation Information retrieval.

**Inputs:** See clause 8.26.3.3.

**Outputs:** See clause 8.26.3.4*.*

See clause 8.26.2.3 for details of usage of this operation.

9.2.18.4 Aimles_MLModelEvalInfoRemoval_Request operation

**API operation name:** Aimles_MLModelEvalInfoRemoval_Request

**Description:** The consumer requests for one time ML Model Evaluation Information removal.

**Inputs:** See clause 8.26.3.5.

**Outputs:** See clause 8.26.3.6*.*

See clause 8.26.2.4 for details of usage of this operation.

9.2.18.5 Aimles_MLModelEvalInfoRetrieval_Subscribe operation

**API operation name:** Aimles\_ MLModelEvalInfoRetrieval_Subscribe

**Description:** The consumer subscribe for ML Model Evaluation Information retrieval.

**Inputs:** See clause 8.26.3.7.

**Outputs:** See clause 8.26.3.8

See clause 8.26.2.5.2 for details of usage of this operation.

9.2.18.6 Aimles_MLModelEvalInfoRetrieval_Notify

**API operation name:** Aimles_MLModelEvalInfoRetrieval_Notify

**Description:** The consumer is notified with ML Model Evaluation Information.

**Inputs:** See clause 8.26.3.9.

**Outputs:** None

See clause 8.26.2.5.3 for details of usage of this operation.

9.2.18.7 Aimles_MLModelEvalInfoRetrieval_UpdateSubscription operation

**API operation name:** Aimles_MLModelEvalInfoRetrieval_UpdateSubscription

**Description:** The consumer updates an existing subscription for ML Model Evaluation Information retrieval.**Inputs:** See clause 8.26.3.10.

**Outputs:** See clause 8.26.3.11.

See clause 8.26.2.5.4 for details of usage of this operation.

## 9.2.18.8 Aimles_MLModelEvalInfoRetrieval_Unsubscribe operation

**API operation name:** Aimles_MLModelEvalInfoRetrieval_Unsubscribe

**Inputs:** See clause 8.26.3.12.

**Outputs:** See clause 8.26.3.13.

See clause 8.26.2.5.5 for details of usage of this operation.
