## 9.2.23.2 Subscribe

**API operation name:** MLModelPerfEvaluation_Subscribe

**Description:** The consumer subscribes for ML model performance evaluation.

**Inputs:** See clause 8.31.3.1.

**Outputs:** See clause 8.31.3.2*.*

See clause 8.31.2 for details of usage of this operation.

## 9.2.23.3 Notify

**API operation name:** MLModelPerfEvaluation_Notify

**Description:** The consumer is notified by ML server on the ML model performance evaluation.

**Inputs:** -

**Outputs:** See clause 8.31.3.7*.*

See clause 8.31.2 for details of usage of this operation.
