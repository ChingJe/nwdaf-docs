## 9.2.14.2 Subscribe

**API operation name:** MLModelPerfMonitor_Subscribe

**Description:** The consumer subscribes for ML model performance monitoring.

**Inputs:** See clause 8.22.3.1.

**Outputs:** See clause 8.22.3.2*.*

See clause 8.22.2 for details of usage of this operation.

## 9.2.14.3 Notify

**API operation name:** MLModelPerfMonitor_Notify

**Description:** The consumer is notified by ML repository on the ML model performance monitoring.

**Inputs:** -

**Outputs:** See clause 8.22.3.3*.*

See clause 8.22.2 for details of usage of this operation.
