## 9.2.11.2 AIMLE client registration request operation

**API operation name:** Aimles_AIMLEClientRegistration_Request

**Description:** The consumer requests AIMLE server for AIMLE client registration.

**Inputs:** See clause 8.7.3.2-1.

**Outputs:** See clause 8.7.3.3*.*

See clause 8.7.2.2 for details of usage of this operation.

## 9.2.11.3 AIMLE client registration update request operation

**API operation name:** Aimles_AIMLEClientRegistration_Update Request

**Description:** The consumer requests AIMLE server for update AIMLE client registration.

**Inputs:** See clause 8.7.3.4.

**Outputs:** See clause 8.7.3.5*.*

See clause 8.7.2.3 for details of usage of this operation.

## 9.2.11.4 AIMLE client registration delete request operation

**API operation name:** Aimles_AIMLEClientRegistration_Delete Request

**Description:** The consumer requests AIMLE server for delete AIMLE client registration.

**Inputs:** See clause 8.7.3.6.

**Outputs:** See clause 8.7.3.7*.*

See clause 8.7.2.4 for details of usage of this operation.
