## 9.2.28.2 Aimles_MLModelInferenceFeedback_Subscribe operation

**API operation name:** Aimles_MLModelInferenceFeedback_Subscribe

**Description:** The AIMLE server subscribes for ML model inference service performance feedback from the VAL server or AIMLE client.

**Inputs:** See clause 8.38.3.1.

**Outputs:** See clause 8.38.3.2*.*

See clause 8.38.2 for details of usage of this operation.

## 9.2.28.3 Aimles_MLModelInferenceFeedback_Notify operation

**API operation name:** Aimles_MLModelInferenceFeedback_Notify

**Description:** The VAL server or AIMLE client provides ML model inference service performance feedback to the AIMLE server.

**Inputs:** See clause 8.38.3.3.

**Outputs:** See clause 8.38.3.4*.*

See clause 8.38.2 for details of usage of this operation.
