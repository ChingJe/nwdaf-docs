## 9.2.21.2 Aimles_FLMember_Registration operation

**API operation name:** Aimles_FLMember_Registration

**Description:** The consumer requests for registering as FL member.

**Inputs:** See clause 8.4.4.8.

**Outputs:** See clause 8.4.4.9*.*

See clause 8.4.3b for details of usage of this operation.

## 9.2.21.3 Aimles_FLMember_Registration_Update operation

**API operation name:** MLR_FLMember_Registration_Update

**Description:** The consumer requests for updating the registration as FL member.

**Inputs:** See clause 8.4.4.10.

**Outputs:** See clause 8.4.4.11*.*

See clause 8.4.3d for details of usage of this operation.

## 9.2.21.4 Aimles_FLMember_Deregistration operation

**API operation name:** MLR_FLMemberDeregistration_Request

**Description:** The consumer requests for deregistering a candidate registered FL member.

**Inputs:** See clause 8.4.4.12.

**Outputs:** See clause 8.4.4.13*.*

See clause 8.4,3e for details of usage of this operation.
