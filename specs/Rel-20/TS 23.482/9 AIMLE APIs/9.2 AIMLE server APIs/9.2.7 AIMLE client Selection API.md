# 9.2.7 AIMLE client Selection API


## 9.2.7.1 General

Table 9.2.7.1-1 illustrates the APIs for AIMLE client selection. This API enables the communication between a requestor (e.g. the VAL server) and the AIMLE server for AIMLE client selection operation. The API may also be used for communication between AIMLE servers over the AIML-E reference point for federation purposes.
