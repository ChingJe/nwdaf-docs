## 9.2.22.2 Subscribe

**API operation name:** MLModelMaintenance_Subscribe

**Description:** The consumer subscribes for ML model maintenance service.

**Inputs:** See clause 8.30.3.1.

**Outputs:** See clause 8.30.3.2*.*

See clause 8.30.2 for details of usage of this operation.

## 9.2.22.3 Notify

**API operation name:** MLModelMaintenance_Notify

**Description:** The consumer is notified by ML server on the ML model maintenance.

**Inputs:** -

**Outputs:** See clause 8.30.3.3*.*

See clause 8.30.2 for details of usage of this operation.
