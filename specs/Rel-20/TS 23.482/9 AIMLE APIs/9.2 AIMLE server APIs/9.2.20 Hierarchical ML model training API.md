## 9.2.20.2 Aimles_HierarchicalMLModelTraining_Subscribe operation

**API operation name:** Aimles_HierarchicalMLModelTraining_Subscribe

**Description:** The consumer subscribes to ML model training from an edge AIMLE server in hierarchical AIMLE deployments.

**Inputs:** See clause 8.28.3.1.

**Outputs:** See clause 8.28.3.2*.*

See clause 8.28.2 for details of usage of this operation.

## 9.2.20.3 Aimles_HierarchicalMLModelTraining_Notify operation

**API operation name:** Aimles_HierarchicalMLModelTraining_Notify

**Description:** The consumer notifies a central AIMLE server of ML model training status in hierarchical AIMLE deployments.

**Inputs:** See clause 8.28.3.3.

**Outputs:** None*.*

See clause 8.28.2 for details of usage of this operation.
