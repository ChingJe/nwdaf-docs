# 8.14.3.4 Split operation pipeline create request

Table 8.14.3.4-1 shows the request sent by a AIMLE client to the AIMLE server for split operation pipeline create request.

Table 8.14.3.4-1: Split operation pipeline create request

|                                                  |        |                                                                                                                                                                                                                                                       |
|--------------------------------------------------|--------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Information element                              | Status | Description                                                                                                                                                                                                                                           |
| Requestor identifier                             | M      | The identity of the requestor (e.g., VAL client ID, AIMLE client ID, UE identifier).                                                                                                                                                                  |
| Computing resource information                   | O      | The computing resource information of the requestor.                                                                                                                                                                                                  |
| Security credentials                             | M      | The security credentials of the requestor.                                                                                                                                                                                                            |
| Split operation requirements                     | M      | Split operation requirements.                                                                                                                                                                                                                         |
| \> model information                             | M      | Information about the ML models to be used in each stage (e.g., identifiers, versions, etc.).                                                                                                                                                         |
| \> Multi-client split operation pipeline support | O      | Indicates if multi-client split operation pipeline support is required or not.                                                                                                                                                                        |
| \> usage information                             | O      | Information about the planned usage of the split operation (e.g., inputs frequency/size, output frequency/size, etc.).                                                                                                                                |
| \> notification target                           | O      | Endpoint information where the result of the split operation is sent by the tail node.                                                                                                                                                                |
| \> stage information                             | M      | Information about the split operation stages (e.g., number, order, etc.).                                                                                                                                                                             |
| \>\> Model partitioning information              | O      | Information describing the partitioning of the ML model for the stage across participating AIMLE client(s) and/or processing node(s), e.g. the model segment, layer subset or cut associated with each participating AIMLE client or processing node. |
| \>\> head node                                   | M      | Endpoint of the head node - for providing initial the inference data.                                                                                                                                                                                 |
| \>\> tail node                                   | M      | Endpoint of the tail node - for obtaining inference results.                                                                                                                                                                                          |
| \>\> node information                            | M      | List of Information about the nodes in order of the stage (e.g., identifier, endpoint, etc.).                                                                                                                                                         |
