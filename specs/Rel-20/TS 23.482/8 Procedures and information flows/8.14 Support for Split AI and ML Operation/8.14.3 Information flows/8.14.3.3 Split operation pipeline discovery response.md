Table 8.14.3.3-2: Split operation profile

|                                               |        |                                                                                                                                                                                                                                                                                           |
|-----------------------------------------------|--------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Information element                           | Status | Description                                                                                                                                                                                                                                                                               |
| Split operation pipeline identifier           | M      | The identifier of the split operation pipeline.                                                                                                                                                                                                                                           |
| Head endpoint                                 | M      | The endpoint information of the head node for providing intermediate data.                                                                                                                                                                                                                |
| Tail endpoint                                 | M      | The endpoint information of the tail node for obtaining results.                                                                                                                                                                                                                          |
| Multi-client split operation pipeline support | O      | Indicates if multi-client split operation pipeline is supported or not.                                                                                                                                                                                                                   |
| Usage information                             | O      | The usage information of the AI/ML split operation (e.g., inputs frequency/size, output frequency/size, etc.).                                                                                                                                                                            |
| Energy Criteria and status                    | O      | The energy criteria and status information (credit/budget, energy usage or consumption) for the split operation and/or the VAL UE/ app.                                                                                                                                                   |
| Stage information                             | M      | The list of stage(s) of the AI/ML split operation, the nested information is provided for each stage.                                                                                                                                                                                     |
| \> Stage identifier                           | M      | The identifier of the stage.                                                                                                                                                                                                                                                              |
| \> number of nodes                            | O      | Number of nodes included in the stage                                                                                                                                                                                                                                                     |
| \> head node                                  | M      | Endpoint of the head node - for providing initial the inference data.                                                                                                                                                                                                                     |
| \> tail node                                  | M      | Endpoint of the tail node - for obtaining inference results.                                                                                                                                                                                                                              |
| \> order of the nodes                         | M      | The order of the nodes in the AI/ML split operation (including head node, tail node).                                                                                                                                                                                                     |
| \>\> list of nodes                            | M      | List of all discovered nodes in the order in which they process the data.                                                                                                                                                                                                                 |
| \>\> notification target                      | O      | Endpoint information where the inference result of the split operation is sent by the nodes                                                                                                                                                                                               |
| \> Model information                          | M      | The ML model information used in the stage (e.g., identifiers, versions, etc.).                                                                                                                                                                                                           |
| \>\> Model partitioning information           | O      | Information describing the partitioning of the ML model for the stage across participating AIMLE client(s) and/or processing node(s), including, when applicable, a common or matching partitioning to be applied for participating AIMLE client(s) in the same split operation pipeline. |
