# 8.26.3 Information flows

8.26.3.1 ML model evaluation information storage request

Table 8.26.3.1-1 describes the request from the AIMLE client or VAL server to the AIMLE server or from the AIMLE server to ML model repository for storing ML model evaluation information in the ML repository.

Table 8.26.3.1-1: ML Model Evaluation Information Storage Request

| Information element                     | Status | Description                                                                                                     |
|-----------------------------------------|--------|-----------------------------------------------------------------------------------------------------------------|
| Requestor identifier                    | M      | The identifier of the requestor.                                                                                |
| List of ML model evaluation information | M      | The list of ML model evaluation information to be stored in the ML repository as described in Table 8.26.3.1-2. |

Table 8.26.3.1-2 describes the ML model evaluation profile and Table 8.26.3.1-3 describes the ML model evaluation information which is used in the ML model evaluation information management procedures between the AIMLE client, VAL server, AIMLE server and ML model repository.

Table 8.26.3.1-2: ML Model Evaluation Profile

| Information element                    | Status | Description                                                                         |
|----------------------------------------|--------|-------------------------------------------------------------------------------------|
| ML model evaluation profile identifier | M      | The identifier of the ML model evaluation profile.                                  |
| AIMLE server identifier                | M      | The identifier of the AIMLE server that stored the ML model evaluation information. |
| List of ML model evaluations           | M      | The list of ML model evaluation information as defined in Table 8.26.3.1-3.         |

Table 8.26.3.1-3: ML Model Evaluation Information

| Information element           | Status | Description                                                                                                                                                                                                                                                                                    |
|-------------------------------|--------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Evaluation identifier         | M      | The identifier of the evaluation information used for evaluating ML model(s).                                                                                                                                                                                                                  |
| List of ML models identifiers | M      | The list of ML models identifiers to which the evaluation applies.                                                                                                                                                                                                                             |
| Source identifier             | O      | The identifier of the source (e.g., VAL server ID, VAL client ID) that stored the ML model evaluation information in the ML repository.                                                                                                                                                        |
| Description                   | M      | The description of the ML model evaluation.                                                                                                                                                                                                                                                    |
| Metric information            | M      | The metric measured by the performing the ML model evaluation (e.g., accuracy, precision, recall, F1 score, etc.) that identifies the type of evaluation.                                                                                                                                      |
| Input information             | M      | Represents the input information which is aligned with the associated ML model input parameters. The format of input information for application specific ML models is out of scope.                                                                                                           |
| Output information            | M      | Represents the expected output information which is expected as a result of processing the input information by the ML model. The format of output information for application specific ML models is out of scope.                                                                             |
| Grading information           | M      | The information for evaluating and grading the performance and correctness of a ML model (e.g., grading the obtained evaluation output based on the expected output).                                                                                                                          |
| Execution information         | O      | The execution information which is required to evaluate performance and correctness of a ML model. The information indicates whether the evaluation is executed once, repeatedly in a time window, has its output averaged, etc. If not included, the evaluation is evaluated and graded once. |

## 8.26.3.9 ML model evaluation information retrieval notification

Table 8.26.3.9-1 describes information elements for the ML model evaluation information retrieval subscription notification from the AIMLE server.

Table 8.26.3.9-1: ML model evaluation information retrieval notification

| **Information element**                                  | **Status** | **Description**                                                                                                                                                    |
|----------------------------------------------------------|------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Subscription ID                                          | M          | Subscription identifier corresponding to the subscription.                                                                                                         |
| List of ML model evaluation information                  | M          | The list of retrieved ML model evaluation information; the nested information elements are provided for each ML model evaluation information profiles in the list. |
| \> ML model evaluation profile identifier                | O          | The ML model evaluation profile identifier.                                                                                                                        |
| \> ML model evaluation profile retrieval endpoint (NOTE) | O          | The endpoint (e.g., URL, URI, IP address) where the ML model evaluation profile can be retrieved.                                                                  |
| \> ML model evaluation profile (NOTE)                    | O          | The ML model evaluation profile containing a retrieved ML model evaluation information as in Table 8.26.3.1-3.                                                     |
| NOTE: At least one of these elements is needed.          |            |                                                                                                                                                                    |
