# 6.19.4 Impacts on services, entities and interfaces

**UE:**

\- Register UE Data Collection Capability to AMF.

\- Reads system information and process DCP.

\- Establishes a PDU Session towards the DCF.

\- Indicated that a PDU Session is intended for Data Collection.

\- Evaluates URSP rules consider a connection capability associated to Data Collection.

**DCF:**

\- Manages Data Collection Configuration request from UE-model training entity.

\- Constructs DCP.

\- Applies applicable post-processing on Collected Data (e.g. anonymization).

\- Configures UE and RAN for data collection.

\- Enforces User Consent permissions for the Data Collection.

**AF (e.g. an UE-model training entity):**

\- Requests Configuration of Data Collection and provides Configuration parameters.

**NRF:**

\- Support DCF registration and discovery procedure for UE-side data collection.

**PCF:**

\- Provides polices that are used for the generation of the DCP profile.

\- During the policy association procedure, the PCF uses the indication from the SMF that the PDU session is use for data collection, to derive PCC rules.

**SMF:**

\- It selects a PCF based on the indication from the UE that the PDU Session is used for Data Collection.

\- It derives QoS rules based on the indication that the PDU Session is used to transfer collected data.

\- It signals the RAN indicating that Data Collection Context information is requested from the RAN.

**AMF:**

\- Handles SMF selection based on an indication that a PDU Session is established for the purpose of collected data transfer.

**UDM/UDR:**

\- Stores DNN/S-NSSAI, UE-ID mapping of AF ID to FQDN/IP Address of AF, for a specific UE ID and Data Collection transfer subscription authorization.
