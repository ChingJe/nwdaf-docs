# 14.3.2.82 Power saving assist response

Table 14.3.2.82-1 describes power saving assist response sent from the NRM server to the VAL server and from NRM sever to the NRM client.

Table 14.3.2.82-1: Power saving assist response

|                                                                                                                                                             |        |                                                                                                                                                   |
|-------------------------------------------------------------------------------------------------------------------------------------------------------------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| Information element                                                                                                                                         | Status | Description                                                                                                                                       |
| VAL User or VAL UE(s) ID(s) (NOTE)                                                                                                                          | M      | The identity of the VAL user whose UE(s) are target for power savings configuration. Alternatively, is the UE ID on which the NRM client resided. |
| \>Result                                                                                                                                                    | M      | Indicates whether the result of the power saving configuration request is successful or not                                                       |
| \>Accepted power saving configuration                                                                                                                       | O      | Indicates the accepted power saving configuration                                                                                                 |
| NOTE: If the consumer is the NRM client, this IE shall be the UE ID. If the consumer is VAL server, the IE may be a list of UE IDs or identity of VAL user. |        |                                                                                                                                                   |
