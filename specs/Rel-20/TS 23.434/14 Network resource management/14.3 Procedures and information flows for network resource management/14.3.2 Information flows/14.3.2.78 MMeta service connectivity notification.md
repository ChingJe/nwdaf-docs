# 14.3.2.78 MMeta service connectivity notification

Table 14.3.2.78-1 describes the information flow for MMeta service connectivity notification from the NRM server to the VAL server.

Table 14.3.2.78-1: MMeta service connectivity notification

| **Information element**   | **Status** | **Description**                                                                                                    |
|---------------------------|------------|--------------------------------------------------------------------------------------------------------------------|
| Session information       | M          | Session information for the established connectivity for application communication                                 |
| VAL service ID            | M          | Identifier of the VAL service                                                                                      |
| List of VAL UEs           | O          | The list of VAL UEs which are accepted for the connectivity established for the application service communication. |
| \>VAL UE/user ID          | O          | Identity of the VAL UE.                                                                                            |
| \> Connection information | O          | Connection information including address / port and / or URL of the VAL UE.                                        |
