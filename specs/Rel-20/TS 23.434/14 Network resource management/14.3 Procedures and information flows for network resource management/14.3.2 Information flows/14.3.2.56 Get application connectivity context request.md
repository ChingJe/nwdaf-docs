# 14.3.2.56 Get application connectivity context request.

Table 14.3.2.56-1 describes the information flow for application connectivity context request from the NRM server to the NRM client, the context applying to UE-to-UE application-level direct communications.

Table 14.3.2.56-1: Get Application connectivity context request.

| **Information element**                                  | **Status** | **Description**                                                                                     |
|----------------------------------------------------------|------------|-----------------------------------------------------------------------------------------------------|
| Requester VALUE ID                                       | M          | The identity of the source VAL client for which the NRM client performs the request.                |
| VAL service ID                                           | M          | Identify of the VAL service for which the information is requested.                                 |
| VAL-specific connection coordination context information | O          | Additional information required to identify the context data (e.g. device type, device vendor, etc) |
