# 14.3.2.19 Monitoring Events Notification message

Table 14.3.2.19-1 describes the information flow from the NRM server to the VAL server on notification of monitoring events.

Table 14.3.2.19-1: Monitoring Events Notification

|                     |        |                                                                |
|---------------------|--------|----------------------------------------------------------------|
| Information element | Status | Description                                                    |
| EventDetails        |        | List of events related to VAL UE(s).                           |
| \> identity         | M      | VAL UE for which the events are related to.                    |
| \> events           | M      | List of Monitoring and Analytics events related to the VAL UE. |
| Timestamp           | O      | The timestamp for the monitoring and analytics events          |
