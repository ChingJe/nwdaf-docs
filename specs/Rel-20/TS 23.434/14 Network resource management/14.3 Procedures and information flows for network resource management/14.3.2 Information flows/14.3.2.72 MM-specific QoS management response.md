# 14.3.2.72 MM-specific QoS management response

Table 14.3.2.72-1 describes the information flow MM-specific QoS management response from the NRM server to the NRM client.

Table 14.3.2.72-1: MM-specific QoS management response

| Information element      | Status | Description                                                                                                                                                                                    |
|--------------------------|--------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Result                   | M      | The positive or negative result of the MM-specific QoS management request.                                                                                                                     |
| QoS report configuration | O      | The configuration of the NRM client's report triggering by NRM server (e.g. setting thresholds for reporting a QoS downgrade / notifications based on channel loss great than threshold value) |
