# 14.3.2.22 Unicast QoS monitoring notification

Table 14.3.2.22-1 describes the information flow for unicast QoS monitoring notification from the network resource management server to the VAL server.

Table 14.3.2.22-1: Notify unicast QoS monitoring event

<table>
<colgroup>
<col style="width: 33%" />
<col style="width: 16%" />
<col style="width: 50%" />
</colgroup>
<tbody>
<tr class="odd">
<td>Information element</td>
<td>Status</td>
<td>Description</td>
</tr>
<tr class="even">
<td>List of VAL UE IDs</td>
<td><p>O</p>
<p>(see NOTE 1)</p></td>
<td>List of VAL UEs whose QoS monitoring data is provided. This list is either the list provided in the subscription request or a subset of that list. It can contain a single UE.</td>
</tr>
<tr class="odd">
<td>VAL group ID</td>
<td><p>O</p>
<p>(see NOTE 1)</p></td>
<td>The group ID used for the VAL group for which QoS monitoring data is provided. This group ID shall be the same VAL group ID as the VAL group ID provided in the subscription request.</td>
</tr>
<tr class="even">
<td>List of VAL stream IDs</td>
<td><p>O</p>
<p>(see NOTE 1)</p></td>
<td>List of VAL stream IDs whose QoS monitoring data is provided. This list is either the list provided in the subscription request or a subset of that list. It can contain a single stream ID.</td>
</tr>
<tr class="odd">
<td>QoS monitoring data</td>
<td><p>O</p>
<p>(see NOTE 2)</p></td>
<td>QoS monitoring data is an aggregate of QoS measurements data obtained from the 5GS.</td>
</tr>
<tr class="even">
<td>Termination cause</td>
<td><p>O</p>
<p>(see NOTE 2)</p></td>
<td>Indicates that the subscription is terminated with the termination cause.</td>
</tr>
<tr class="odd">
<td>Monitoring profile ID</td>
<td>O</td>
<td>Represents the monitoring profile identifier whose reporting requirements triggered notification.</td>
</tr>
<tr class="even">
<td colspan="3"><p>NOTE 1: Only one of these information elements shall be present.</p>
<p>NOTE 2: At least one of these information elements shall be present.</p></td>
</tr>
