# 14.3.2.34 Unicast QoS monitoring data response

Table 14.3.2.34-1 describes the information flow from the VAL server to the network resource management server for unicast QoS monitoring data response.

Table 14.3.2.34-1: Unicast QoS monitoring data response

<table>
<colgroup>
<col style="width: 33%" />
<col style="width: 16%" />
<col style="width: 50%" />
</colgroup>
<tbody>
<tr class="odd">
<td>Information element</td>
<td>Status</td>
<td>Description</td>
</tr>
<tr class="even">
<td>List of VAL UE IDs</td>
<td><p>O</p>
<p>(see NOTE 1)</p></td>
<td>List of VAL UEs whose QoS monitoring data is provided. This list is either the list provided in the request or a subset of that list. It can contain a single UE.</td>
</tr>
<tr class="odd">
<td>VAL group ID</td>
<td><p>O</p>
<p>(see NOTE 1)</p></td>
<td>The group ID used for the VAL group for which QoS monitoring data is provided. This group ID shall be the same VAL group ID as the VAL group ID provided in the request.</td>
</tr>
<tr class="even">
<td>List of VAL stream IDs</td>
<td><p>O</p>
<p>(see NOTE 1)</p></td>
<td>List of VAL stream IDs whose QoS monitoring data is provided. This list is either the list provided in the request or a subset of that list. It can contain a single stream ID.</td>
</tr>
<tr class="odd">
<td>Result</td>
<td>M</td>
<td>Indicates the success or failure for the operation</td>
</tr>
<tr class="even">
<td>QoS monitoring data</td>
<td><p>M</p>
<p>(see NOTE 2)</p></td>
<td>QoS monitoring data is an aggregate of QoS measurements data obtained from the 5GS.</td>
</tr>
<tr class="odd">
<td>Cause</td>
<td>O</td>
<td>Provides reason for the failure (e.g. when data for the requested time period is not available).</td>
</tr>
<tr class="even">
<td colspan="3"><p>NOTE 1: Only one of these information elements shall be present.</p>
<p>NOTE 2: If the Result information element indicates failure then the value of the QoS monitoring data information element has no meaning.</p></td>
</tr>
