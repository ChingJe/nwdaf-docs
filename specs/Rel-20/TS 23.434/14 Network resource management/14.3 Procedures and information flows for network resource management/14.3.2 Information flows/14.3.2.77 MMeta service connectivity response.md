# 14.3.2.77 MMeta service connectivity response

Table 14.3.2.77-1 describes the information flow for MMeta service connectivity response from the NRM client to the NRM server.

Table 14.3.2.77-1: MMeta service connectivity response

| **Information element** | **Status** | **Description**                                                                                            |
|-------------------------|------------|------------------------------------------------------------------------------------------------------------|
| Result                  | M          | Result from the NRM client in response to request indicating success or failure for accepting the request. |
| Cause                   | O          | The cause of failure, if the result indicates failure.                                                     |
