# 14.3.2.18 Monitoring Events Subscription Response

Table 14.3.2.18-1 describes the information flow from the NRM server to the VAL server for Monitoring Events Subscription response.

Table 14.3.2.18-1: Monitoring Events Subscription response

|                       |        |                                                                                                                                                                                 |
|-----------------------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Information element   | Status | Description                                                                                                                                                                     |
| Subscription status   | M      | It indicates the subscription result                                                                                                                                            |
| Monitoring profile ID | O      | It indicates the monitoring profile identifier. It is present when Subscription status is success and Event Details are provided in the Monitoring Events Subscription request. |
