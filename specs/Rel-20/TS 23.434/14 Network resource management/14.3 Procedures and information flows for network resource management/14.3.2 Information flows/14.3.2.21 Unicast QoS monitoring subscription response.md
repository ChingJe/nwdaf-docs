# 14.3.2.21 Unicast QoS monitoring subscription response

Table 14.3.2.21-1 describes the information flow from the network resource management server to the VAL server for unicast QoS montoring subscription response.

Table 14.3.2.21-1: Unicast QoS monitoring subscription response

|                          |        |                                                                                                                            |
|--------------------------|--------|----------------------------------------------------------------------------------------------------------------------------|
| Information element      | Status | Description                                                                                                                |
| Subscription status      | M      | It indicates the subscription result                                                                                       |
| Monitoring profile ID    | O      | Represents the identifier of the stored monitoring profile. This IE may be present if the subscription status is success.  |
| Termination of reporting | O      | It indicates when the reporting of QoS monitoring will stop. This IE may be present if the subscription status is success. |
