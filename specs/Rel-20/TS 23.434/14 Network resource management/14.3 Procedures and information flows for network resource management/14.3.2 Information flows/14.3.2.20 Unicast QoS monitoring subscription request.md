<td>O</td>
<td>It indicates the requested frequency of reporting. The reporting frequency may be periodic or event triggered (i.e. threshold reached). If absent in the request, default event triggered reporting is used.</td>
</tr>
<tr class="odd">
<td>&gt;&gt; Reporting threshold</td>
<td>O</td>
<td>If the Frequency of reporting is event triggered (threshold reached), the reporting threshold corresponding to the measurement index shall be provided.</td>
</tr>
<tr class="even">
<td>&gt;&gt; Threshold reaching direction</td>
<td>O</td>
<td>It indicates the reaching direction (i.e. ascending, descending or crossed) for the reporting threshold. It shall be provided if reporting threshold is present.</td>
</tr>
<tr class="odd">
<td>&gt;&gt; Reporting periodicity</td>
<td>O</td>
<td>If the Frequency of reporting is periodic, the reporting periodicity shall be provided.</td>
</tr>
<tr class="even">
<td>&gt; Termination of reporting</td>
<td><p>O</p>
<p>(see NOTE 6)</p></td>
<td>It indicates when the reporting of QoS monitoring shall stop. It can be event triggered (i.e. either number of reports reached or threshold reached) or when reporting duration expires or when explicit termination is requested. If absent in the request, it defaults to explicit termination. Once the termination condition is met, the monitoring subscription ceases to exist.</td>
</tr>
<tr class="odd">
<td>&gt; Max number of reports</td>
<td><p>O</p>
<p>(NOTE 3, NOTE 6)</p></td>
<td>It indicates the maximum number of reports, it shall be provided when Termination of reporting is set to event triggered (number of reports reached).</td>
</tr>
<tr class="even">
<td>&gt; Termination threshold</td>
<td><p>O</p>
<p>(see NOTE 2, NOTE 3, NOTE 6)</p></td>
<td>It indicates the reporting termination threshold corresponding to the measurement index. Each measurement index has only one termination threshold.</td>
</tr>
<tr class="odd">
<td>&gt; Termination condition for termination threshold</td>
<td><p>O</p>
<p>(see NOTE 2, NOTE 6)</p></td>
<td>It indicates threshold-based termination condition (e.g. all reached or any of them reached) if multiple measurement indexes are provided.</td>
</tr>
<tr class="even">
<td>&gt; Reporting duration</td>
<td><p>O</p>
<p>(NOTE 3, NOTE 6)</p></td>
<td>It indicates the reporting duration, it shall be provided when Termination of reporting is set to duration expiration.</td>
</tr>
<tr class="odd">
<td colspan="3"><p>NOTE 1: Only one of these information elements shall be present.</p>
<p>NOTE 2: It shall be provided when Termination of reporting is set to event triggered (threshold reached).</p>
<p>NOTE 3: If provided, only one of these information elements shall be present.</p>
<p>NOTE 4: When used by the Update_Unicast_QoS_Monitoring_Subscription operation, the same information element with identical content shall be present as in the associated Subscribe_Unicast_QoS_Monitoring operation.</p>
<p>NOTE 5: Only one of these information elements shall be present.</p>
<p>NOTE 6: When used by the Update_Unicast_QoS_Monitoring_Subscription operation, this IE may be used by the VAL server to modify the proposed by NRM server subscription termination conditions.</p></td>
</tr>
