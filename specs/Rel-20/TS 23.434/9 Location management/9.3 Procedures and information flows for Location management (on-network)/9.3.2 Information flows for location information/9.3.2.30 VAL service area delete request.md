# 9.3.2.30 VAL service area delete request

Table 9.3.2.30-1 describes the information flow from a VAL server to a location management for delete VAL service area identifiers at the location management server.

Table 9.3.2.30-1: Update VAL service area request

| Information element     | Status | Description                                                             |
|-------------------------|--------|-------------------------------------------------------------------------|
| Identity                | M      | Indicates the VAL server identity.                                      |
| List of VAL service IDs | M      | List of one or more VAL service area identifiers that shall be deleted. |
