# 9.3.2.75 Confirm location request

Table 9.3.2.75-1 describes the information elements for the confirm location request from the location management client to the location management server.

Table 9.3.2.75-1: Confirm location request

|                      |        |                                                                                                                                                       |
|----------------------|--------|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| Information element  | Status | Description                                                                                                                                           |
| UE ID                | M      | The identifier of UE whose location information is to be confirmed                                                                                    |
| UE provided location | M      | UE provided non-3GPP location information taken from functionality within UE (e.g. GNSS). It can include latitude and longitude, accuracy, timestamp. |
| Timestamp            | M      | Timestamp of the UE provided location                                                                                                                 |
| Application ID       | M      | Application identifier                                                                                                                                |
