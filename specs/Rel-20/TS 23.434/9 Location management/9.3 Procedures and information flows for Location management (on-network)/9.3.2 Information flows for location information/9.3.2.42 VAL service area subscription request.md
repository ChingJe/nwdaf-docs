# 9.3.2.42 VAL service area subscription request

Table 9.3.2.42-1 describes the information flow from a SEAL server to a location management server to subscribe VAL service area identifier update events or update an existing subscription at the location management server.

Table 9.3.2.42-1: VAL service area subscription request

| Information element                                                                                       | Status | Description                                                                                                                                                               |
|-----------------------------------------------------------------------------------------------------------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Identity                                                                                                  | M      | Indicates the SEAL server identity (see NOTE).                                                                                                                            |
| List of the subscribed events                                                                             | M      | Indicates the list of the requested events.                                                                                                                               |
| \> Event type                                                                                             | M      | Indicates the subscribed event (e.g., update/deletion of the VAL service area ID)                                                                                         |
| \> VAL service area IDs                                                                                   | O      | Indicates the list of the VAL service area identifiers. This information element shall be provided when the requested event type is update or delete VAL service area ID. |
| Notification Target URI                                                                                   | M      | Target URI where the VAL server wishes to receive the notifications about VAL service area update events.                                                                 |
| Subscription duration                                                                                     | O      | It indicates the subscription duration.                                                                                                                                   |
| NOTE: This information element shall not be updated via the update VAL service area subscription request. |        |                                                                                                                                                                           |
