# 9.3.2.11 Monitor Location Subscription Request

Table 9.3.2.11-1 describes the information flow from the VAL server to the location management server for monitoring the location deviation of the VAL UE(s) or for updating an existing monitor location subscription.

Table 9.3.2.11-1: Monitor Location Subscription Request

<col style="width: 33%" />
<col style="width: 16%" />

<td>Information element</td>
<td>Status</td>
<td>Description</td>
</tr>
<tr class="even">
<td>Target Identity</td>
<td>M</td>
<td>Identifier of the target VAL users or VAL UEs whose location monitoring is requested to be monitored in a given location (see NOTE).</td>
</tr>
<tr class="odd">
<td>Area of Interest</td>
<td>M</td>
<td><p>Geographic area location information where the VAL server wishes to monitor the VAL UE's location adherence. This could be geographical co-ordinates or VAL service area identified by the VAL service area ID.</p>
<p>Alternatively, it includes identifier of the reference VAL user or VAL UE and its proximity range.</p></td>
</tr>
<tr class="even">
<td>Notify Interval</td>
<td>M</td>
<td>Periodic time interval in which the location management server needs to notify the target VAL UE's location information to the VAL server.</td>
</tr>
<tr class="odd">
<td>Notification Target URI</td>
<td>M</td>
<td>Target URI where the VAL server wishes to receive the notifications about target VAL UE's location.</td>
</tr>
<tr class="even">
<td>Timeout</td>
<td>O</td>
<td>A timeout period when subscription response is not received.</td>
</tr>
<tr class="odd">
<td>Interested notification information</td>
<td>O</td>
<td>One or more interested notification events (e.g. Notify Absence, Notify Presence, Notify Mismatch Location and Notify Unknown) the VAL server can subscribe to.</td>
</tr>
<tr class="even">

<td>O</td>
<td>Temporal, connectivity and/or spatial conditions for the reference VAL UE.</td>
</tr>

</tr>
