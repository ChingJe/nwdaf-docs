# 9.3.2.10 Get UE(s) information response

Table 9.3.2.10-1 describes the information flow for a LM server to respond with UE(s) information to the VAL server.

Table 9.3.2.10-1: Get UE(s) information response

| Information element                                                | Status | Description                                                                                                       |
|--------------------------------------------------------------------|--------|-------------------------------------------------------------------------------------------------------------------|
| Result                                                             | M      | Result from the VAE server in response to subscription request indicating success or failure                      |
| List of UEs information (see NOTE)                                 | O      | The information of the UEs which were detected in the application defined proximity range. The list can be empty. |
| \>UE ID                                                            | M      | The identifier of VAL UE or VAL user.                                                                             |
| \>Location information                                             | M      | Location information of UE within the application defined proximity range                                         |
| \> VAL service ID                                                  | O      | Indicates the VAL service identified associated with UE ID information flow.                                      |
| NOTE: This IE shall be included when the Result indicates success. |        |                                                                                                                   |
