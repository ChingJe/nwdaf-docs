# 9.3.2.77 Confirm location service usage notification

Table 9.3.2.77-1 describes the information elements for the confirm location service usage notification from the location management server to the VAL server.

Table 9.3.2.77-1: Confirm location service usage notification

|                     |        |                                                               |
|---------------------|--------|---------------------------------------------------------------|
| Information element | Status | Description                                                   |
| Identity            | M      | Identity of the requesting VAL server/VAL user                |
| UE ID               | M      | The identifier of UE whose location information was confirmed |
| Timestamp           | O      | Timestamp of the confirm location service notification        |
