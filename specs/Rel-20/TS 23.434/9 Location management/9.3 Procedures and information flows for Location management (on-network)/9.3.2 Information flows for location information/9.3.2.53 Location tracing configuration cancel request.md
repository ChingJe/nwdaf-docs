# 9.3.2.53 Location tracing configuration cancel request

Table 9.3.2.53-1 describes the information flow from the VAL server to the location management server for cancelling the location tracing configuration.

Table 9.3.2.53-1: Location tracing configuration cancel request

|                     |        |                                                                                        |
|---------------------|--------|----------------------------------------------------------------------------------------|
| Information element | Status | Description                                                                            |
| Identity            | M      | Identity of the VAL user or identity of the VAL UE.                                    |
| VAL service ID      | O      | Identity of the VAL service for which the location tracing configuration is requested. |
