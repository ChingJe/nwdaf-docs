# 9.3.2.21 VAL service area configuration request

Table 9.3.2.21-1 describes the information flow from the VAL server to the location management server for VAL service area configuration request.

Table 9.3.2.21-1: VAL service area configuration request

|                                      |        |                                                                                                       |
|--------------------------------------|--------|-------------------------------------------------------------------------------------------------------|
| Information element                  | Status | Description                                                                                           |
| Identity                             | M      | Identity of the requesting VAL server                                                                 |
| List of VAL service area information | M      | List of one or more VAL service area identifiers.                                                     |
| \> VAL service area ID               | M      | The VAL service area identifier.                                                                      |
| \> Geographical location list        | M      | List of one more geographical locations (e.g., co-ordinates) corresponding to the VAL service area ID |
