# 9.3.2.57 Verify location sharing request

Table 9.3.2.57-1 describes the information flow from the location management server to the location management client to verify if it is sharing the same location with other UEs.

Table 9.3.2.57-1: Verify location sharing request

| Information element                         | Status | Description                                                                                         |
|---------------------------------------------|--------|-----------------------------------------------------------------------------------------------------|
| Identity                                    | M      | Identity of the requested VAL users or VAL UEs.                                                     |
| VAL service ID                              | O      | Identity of the VAL service that is requested.                                                      |
| Identity of VAL UE who sharing the location | M      | Indicates the list of identities of VAL UEs who share the same location with the requested VAL UEs. |
