# 10.3.2.18 Store group configuration request

Table 10.3.2.18-1 describes the information flow store group configuration request from the group management client or VAL server to the group management server.

Table 10.3.2.18-1: Store group configuration request

|                              |        |                                                                                   |
|------------------------------|--------|-----------------------------------------------------------------------------------|
| Information element          | Status | Description                                                                       |
| Requester Identity           | M      | The identity of the group management client or VAL server performing the request. |
| VAL group ID                 | M      | VAL group ID of the group                                                         |
| VAL group configuration data | M      | VAL group configuration data                                                      |
