# 10.3.2.14 Group information subscribe request

Table 10.3.2.14-1 describes the information flow group information subscribe request from the group management client or VAL server to the group management server.

Table 10.3.2.14-1: Group information subscribe request

|                                                |        |                                                                                                                |
|------------------------------------------------|--------|----------------------------------------------------------------------------------------------------------------|
| Information element                            | Status | Description                                                                                                    |
| Requester Identity                             | M      | The identity of the group management client or VAL server performing the request.                              |
| VAL group ID                                   | M      | VAL group ID of the group                                                                                      |
| Minimum time between consecutive notifications | O      | Defaults to 0 if not provided, otherwise indicates the minimum time interval between consecutive notifications |
