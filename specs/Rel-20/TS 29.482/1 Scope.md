# 1 Scope

The present document specifies the stage 3 protocol and data model for the SEAL AIMLE Services, for enabling the support of AIMLE services for vertical applications. It provides stage 3 protocol definitions and message flows, and specifies the API for each service offered by the AIMLE Layer entities.

The stage 2 architecture and procedures are specified in 3GPP TS 23.482 \[9\].

The common protocol and interface aspects for API definition are specified in clause 5.2 of 3GPP TS 29.122 \[2\].
