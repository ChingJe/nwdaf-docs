# 6.2.1.7 Error Handling


## 6.2.1.7.1 General

For the MLR_MLModelManagement API, error handling shall be supported as specified in clause 6.7 of 3GPP TS 29.549 \[10\].

In addition, the requirements in the following clauses are applicable for the MLR_MLModelManagement API.

## 6.2.1.7.2 Protocol Errors

No specific protocol errors for the MLR_MLModelManagement API are specified.
