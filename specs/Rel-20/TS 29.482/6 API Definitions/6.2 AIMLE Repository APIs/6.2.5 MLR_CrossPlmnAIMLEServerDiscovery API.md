# 6.2.5 MLR_CrossPlmnAIMLEServerDiscovery API


## 6.2.5.1 Introduction

The MLR_CrossPlmnAIMLEServerDiscovery Service shall use the MLR_CrossPlmnAIMLEServerDiscovery API.

The API URI of the MLR_CrossPlmnAIMLEServerDiscovery API shall be:

**{apiRoot}/\<apiName\>/\<apiVersion\>**

The request URIs used in HTTP requests shall have the Resource URI structure defined in clause 6.5 of 3GPP TS 29.549 \[10\], i.e.:

**{apiRoot}/\<apiName\>/\<apiVersion\>/\<apiSpecificSuffixes\>**

with the following components:

\- The {apiRoot} shall be set as described in clause 6.5 of 3GPP TS 29.549 \[10\].

\- The \<apiName\> shall be "mlr-xplmnsd".

\- The \<apiVersion\> shall be "v1".

\- The \<apiSpecificSuffixes\> shall be set as described in clause 6.2.5.3 and clause 6.2.5.4.

NOTE: When 3GPP TS 29.122 \[2\] is referenced for the common protocol and interface aspects for API definition in the clauses under clause 6.2.5, the ML Repository takes the role of the SCEF and the service consumer takes the role of the SCS/AS.

## 6.2.5.2 Usage of HTTP


### 6.2.5.2.1 Overview

The provisions of clause 6.3 of 3GPP TS 29.549 \[10\] shall apply for the MLR_CrossPlmnAIMLEServerDiscovery API.

## 6.2.5.3 Resources

There are no resources defined for this API in this release of the specification.
