# 6.1.16.6 Data Model


## 6.1.16.6.1 General

This clause specifies the application data model supported by the API.

Table 6.1.16.6.1-1 specifies the data types defined for the AIMLES_MLModelMaintenance API.

Table 6.1.16.6.1-1: AIMLES_MLModelMaintenance API specific Data Types

| Data type            | Section defined | Description                                             | Applicability |
|----------------------|-----------------|---------------------------------------------------------|---------------|
| EventTrigger         | 6.1.16.6.3.4    | Represents a trigger event.                             |               |
| MaintMode            | 6.1.16.6.2.6    | Represents the Maintenance Mode.                        |               |
| MaintTrigger         | 6.1.16.6.3.3    | Represents a trigger of a Maintenance.                  |               |
| MLModelMaintNotif    | 6.1.16.6.2.4    | Represents the ML Model Maintenance Notification.       |               |
| MLModelMaintReq      | 6.1.16.6.2.5    | Represents the ML Model Maintenance Requirements.       |               |
| MLModelMaintSub      | 6.1.16.6.2.2    | Represents the ML Model Maintenance Subscription.       |               |
| MLModelMaintSubPatch | 6.1.16.6.2.3    | Represents the ML Model Maintenance Subscription Patch. |               |
| MLModelStatus        | 6.1.16.6.2.7    | Contains the status of the ML Model.                    |               |
| NotifEventTrigger    | 6.1.16.6.3.5    | Represents the events that can trigger notification.    |               |
| NotifReq             | 6.1.16.6.2.8    | Represents the notification requirements.               |               |

Table 6.1.16.6.1-2 specifies data types re-used by the AIMLES_MLModelMaintenance API service.

Table 6.1.16.6.1-2: AIMLES_MLModelMaintenance API re-used Data Types

| Data type            | Reference             | Comments                                                                                         | Applicability |
|----------------------|-----------------------|--------------------------------------------------------------------------------------------------|---------------|
| Bytes                | 3GPP TS 29.122 \[2\]  | Represents data in bytes.                                                                        |               |
| DateTime             | 3GPP TS 29.122 \[2\]  | Represents a Date Time.                                                                          |               |
| EndPoint             | 3GPP TS 29.558 \[15\] | Represents the endpoint information of a node.                                                   |               |
| MLModelPerfInfo      | 6.1.17.6.2.5          | Represents the performance information of a ML model.                                            |               |
| ReportingInformation | 3GPP TS 29.523 \[19\] | Represents the reporting information.                                                            |               |
| SupportedFeatures    | 3GPP TS 29.571 \[11\] | Represents the supported features, used to negotiate the supported optional features of the API. |               |
| Uri                  | 3GPP TS 29.122 \[2\]  | Represents a URI.                                                                                |               |

## 6.1.16.6.3 Simple data types and enumerations


### 6.1.16.6.3.1 Introduction

This clause defines simple data types and enumerations that can be referenced from data structures defined in the previous clauses.

### 6.1.16.6.3.2 Simple data types

The simple data types defined in table 6.1.16.6.3.2-1 shall be supported.

Table 6.1.16.6.3.2-1: Simple data types

| Type Name | Type Definition | Description | Applicability |
|-----------|-----------------|-------------|---------------|
|           |                 |             |               |

### 6.1.16.6.3.3 Enumeration: MaintTrigger

The enumeration MaintTrigger represents a trigger of a Maintenance. It shall comply with the provisions defined in table 6.1.16.6.3.3-1.

Table 6.1.16.6.3.3-1: Enumeration MaintTrigger

| Enumeration value  | Description                                                | Applicability |
|--------------------|------------------------------------------------------------|---------------|
| PERIODIC           | Indicates the maintenance is periodically triggered.       |               |
| ON_EVENT_DETECTION | Indicates the maintenance is triggered on event detection. |               |

### 6.1.16.6.3.4 Enumeration: EventTrigger

The enumeration EventTrigger represents a trigger event. It shall comply with the provisions defined in table 6.1.16.6.3.4-1.

Table 6.1.16.6.3.4-1: Enumeration EventTrigger

| Enumeration value                   | Description                                                  | Applicability |
|-------------------------------------|--------------------------------------------------------------|---------------|
| ML_MODEL_EVENT_DEGRADATION_DETECTED | Indicates a detection of a ML Model Event Degradation event. |               |
| DATA_DRIFT_DETECTED                 | Indicates a detection of a Data Drift event.                 |               |

### 6.1.16.6.3.5 Enumeration: NotifEventTrigger

The enumeration NotifEventTrigger represents the events that can trigger notification. It shall comply with the provisions defined in table 6.1.16.6.3.5-1.

Table 6.1.16.6.3.5-1: Enumeration NotifEventTrigger

| Enumeration value       | Description                                | Applicability |
|-------------------------|--------------------------------------------|---------------|
| ML_MODEL_STATUS_CHANGED | Indicates a status change in the ML Model. |               |

## 6.1.16.6.4 Data types describing alternative data types or combinations of data types

There are no data types describing alternative data types or combinations of data types defined for this API in this release of the specification.
