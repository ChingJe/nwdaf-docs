# 6.1.16.7 Error Handling


## 6.1.16.7.1 General

For the AIMLES_MLModelMaintenance API, HTTP error responses shall be supported as specified in clause 5.2.1.6 of 3GPP TS 29.122 \[2\]. Protocol errors and application errors specified in clause 5.2.1.6 of 3GPP TS 29.122 \[2\] shall be supported for the HTTP status codes specified in table 5.2.1.6-1 of 3GPP TS 29.122 \[2\].

In addition, the requirements in the following clauses are applicable for the AIMLES_MLModelMaintenance API.

## 6.1.16.7.2 Protocol Errors

No specific protocol errors for the AIMLES_MLModelMaintenance API are specified.
