# 6.1.3.6 Data Model


## 6.1.3.6.1 General

This clause specifies the application data model supported by the API.

Table 6.1.3.6.1-1 specifies the data types defined for the AIMLES_FLMemberGroupSupport API.

Table 6.1.3.6.1-1: AIMLES_FLMemberGroupSupport API specific Data Types

| Data type         | Clause defined | Description                                                                    | Applicability |
|-------------------|----------------|--------------------------------------------------------------------------------|---------------|
| FlMbrStatus       | 6.1.3.6.3.5    | Represents information on whether the FL member is a candidate or is selected. |               |
| FlMbrSuppGrp      | 6.1.3.6.2.2    | Create a new Individual FL Member Group Support for an FL process.             |               |
| FlMbrSuppGrpPatch | 6.1.3.6.2.3    | Individual FL Member Group Support to be partially modified.                   |               |
| FlMbrType         | 6.1.3.6.3.4    | Represents information on the type of the FL member.                           |               |
| FLMember          | 6.1.3.6.2.5    | Represents information on candidate FL member.                                 |               |
| MlTaskInfo        | 6.1.3.6.2.4    | Represents information on the identity and type of the ML task.                |               |
| MlTaskType        | 6.1.3.6.3.3    | Represents information on the identity of the ML model.                        |               |

Table 6.1.3.6.1-2 specifies data types re-used by the AIMLES_FLMemberGroupSupport API from other specifications, including a reference to their respective specifications, and when needed, a short description of their use within the AIMLES_FLMemberGroupSupport API.

Table 6.1.3.6.1-2: AIMLES_FLMemberGroupSupport API re-used Data Types

| Data type         | Reference             | Comments                                                                                                      | Applicability |
|-------------------|-----------------------|---------------------------------------------------------------------------------------------------------------|---------------|
| AdaeAnalyticsId   | 3GPP TS 29.549 \[10\] | Represents the ADAE analytics identifier.                                                                     |               |
| FlGroupInfo       | 3GPP TS 24.560 \[12\] | Created Individual FL Member Group Support for the FL process.                                                |               |
| MLModelProfile    | 6.2.1.6.2.3           | Represents the ML Model Profile.                                                                              |               |
| SupportedFeatures | 3GPP TS 29.571 \[11\] | Represents the list of supported feature(s) and used to negotiate the applicability of the optional features. |               |

### 6.1.3.6.3.3 Enumeration: MlTaskType

The enumeration MlTaskType represents information regarding the training identity or inference identity of the ML model. It shall comply with the provisions defined in table 6.1.3.6.3.3-1.

Table 6.1.3.6.3.3-1: Enumeration MlTaskType

| Enumeration value | Description                      | Applicability |
|-------------------|----------------------------------|---------------|
| FL_TRAINING       | Identifies an ML model training  |               |
| FL_INFERENCE      | Identifies an ML model inference |               |

### 6.1.3.6.3.4 Enumeration: FlMbrType

The enumeration FlMbrType represents information regarding the FL member being an FL server or an FL client. It shall comply with the provisions defined in table 6.1.3.6.3.4-1.

Table 6.1.3.6.3.4-1: Enumeration FlMbrType

| Enumeration value | Description             | Applicability |
|-------------------|-------------------------|---------------|
| FL_SERVER         | Identifies an FL server |               |
| FL_CLIENT         | Identifies an FL client |               |

### 6.1.3.6.3.5 Enumeration: FlMbrStatus

The enumeration FlMbrStatus represents information regarding the FL member being a candidate or being selected. It shall comply with the provisions defined in table 6.1.3.6.3.5-1.

Table 6.1.3.6.3.5-1: Enumeration FlMbrStatus

| Enumeration value | Description                               | Applicability |
|-------------------|-------------------------------------------|---------------|
| FL_CANDIDATE      | Identifies an FL member being a candidate |               |
| FL_SELECTED       | Identifies an FL member being selected    |               |

## 6.1.3.6.4 Data types describing alternative data types or combinations of data types

There are no data types describing alternative data types or combination of data types for AIMLES_FLMemberGroupSupport API in this release of the specification.
