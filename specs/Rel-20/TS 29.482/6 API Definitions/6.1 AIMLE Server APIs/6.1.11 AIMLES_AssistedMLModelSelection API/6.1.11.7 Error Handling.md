# 6.1.11.7 Error Handling


## 6.1.11.7.1 General

For the AIMLES_AssistedMLModelSelection API, error handling shall be supported as specified in clause 6.7 of 3GPP TS 29.549 \[10\].

In addition, the requirements in the following clauses are applicable for the AIMLES_AssistedMLModelSelection API.

## 6.1.11.7.2 Protocol Errors

No specific protocol errors for the AIMLES_AssistedMLModelSelection API are specified.
