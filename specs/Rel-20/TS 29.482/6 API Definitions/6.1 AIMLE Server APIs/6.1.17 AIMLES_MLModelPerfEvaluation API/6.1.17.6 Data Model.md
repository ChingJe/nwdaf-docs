# 6.1.17.6 Data Model


## 6.1.17.6.1 General

This clause specifies the application data model supported by the API.

Table 6.1.17.6.1-1 specifies the data types defined for the AIMLES_MLModelPerfEvaluation API.

Table 6.1.17.6.1-1: AIMLES_MLModelPerfEvaluation API specific Data Types

| Data type               | Section defined | Description                                                        | Applicability |
|-------------------------|-----------------|--------------------------------------------------------------------|---------------|
| MLModelPerfEvalNotif    | 6.1.17.6.2.4    | Represents the ML Model Performance Evaluation Notification.       |               |
| MLModelPerfEvalSub      | 6.1.17.6.2.2    | Represents the ML Model Performance Evaluation Subscription.       |               |
| MLModelPerfEvalSubPatch | 6.1.17.6.2.3    | Represents the ML Model Performance Evaluation Subscription Patch. |               |
| MLModelPerfInfo         | 6.1.17.6.2.5    | Represents the ML Model Performance Information.                   |               |

Table 6.1.17.6.1-2 specifies data types re-used by the AIMLES_MLModelPerfEvaluation API service.

Table 6.1.17.6.1-2: AIMLES_MLModelPerfEvaluation API re-used Data Types

| Data type         | Reference             | Comments                                                                                         | Applicability |
|-------------------|-----------------------|--------------------------------------------------------------------------------------------------|---------------|
| Float             | 3GPP TS 29.571 \[11\] | Represents a Float.                                                                              |               |
| SupportedFeatures | 3GPP TS 29.571 \[11\] | Represents the supported features, used to negotiate the supported optional features of the API. |               |
| Uri               | 3GPP TS 29.122 \[2\]  | Used to indicate the notification URI.                                                           |               |
