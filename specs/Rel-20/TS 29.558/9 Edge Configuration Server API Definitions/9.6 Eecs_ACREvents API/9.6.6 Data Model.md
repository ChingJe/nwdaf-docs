# 9.6.6 Data Model


## 9.6.6.1 General

This clause specifies the application data model supported by the API.

Table 9.6.6.1-1 specifies the data types defined for the Eecs_ACREvents API.

Table 9.6.6.1-1: Eecs_ACREvents API specific Data Types

| Data type           | Clause defined | Description                                                           | Applicability |
|---------------------|----------------|-----------------------------------------------------------------------|---------------|
| AcrEventsNotif      | 9.6.6.2.4      | Represents an ACR Events Notification.                                |               |
| AcrEventsSubsc      | 9.6.6.2.2      | Represents an ACR Events Subscription.                                |               |
| AcrEventsSubscPatch | 9.6.6.2.3      | Represents the requested modifications to an ACR Events subscription. |               |
| AcrEvent            | 9.6.6.3.3      | Represents the ACR event.                                             |               |

Table 9.6.6.1-2 specifies data types re-used by the Eecs_ACREvents API from other specifications, including a reference to their respective specifications and when needed, a short description of their use within the Eecs_ACREvents API.

Table 9.6.6.1-2: Eecs_ACREvents API re-used Data Types

| Data type         | Reference            | Comments                                                                                                      | Applicability |
|-------------------|----------------------|---------------------------------------------------------------------------------------------------------------|---------------|
| DateTime          | 3GPP TS 29.122 \[6\] | Represents a date and a time.                                                                                 |               |
| DateTimeRm        | 3GPP TS 29.571 \[8\] | Represents the same as the DateTime data type but with the OpenAPI "nullable:true" property.                  |               |
| EDNInfo           | Clause 9.1.5.2.10    | Represent EDN related information.                                                                            |               |
| SupportedFeatures | 3GPP TS 29.571 \[8\] | Represents the list of supported feature(s) and used to negotiate the applicability of the optional features. |               |
| Uinteger          | 3GPP TS 29.571 \[8\] | Used to express the maximum response time of EAS service KPI.                                                 |               |
| Uri               | 3GPP TS 29.122 \[6\] | Represents a URI.                                                                                             |               |
