# 9.6.3 Resources


## 9.6.3.1 Overview

This clause describes the structure for the Resource URIs and the resources and methods used for the service.

Figure 9.6.3.1-1 depicts the resource URIs structure for the Eecs_ACREvents API.

![](../../assets/rendered/image24.png)

Figure 9.6.3.1-1: Resource URIs structure of the Eecs_ACREvents API

Table 9.6.3.1-1 provides an overview of the resources and applicable HTTP methods for the Eecs_ACREvents API.

Table 9.6.3.1-1: Resources and methods overview

| Resource name                      | Resource URI                   | HTTP method or custom operation | Description                                                                            |
|------------------------------------|--------------------------------|---------------------------------|----------------------------------------------------------------------------------------|
| ACR Events Subscriptions           | /subscriptions                 | POST                            | Request the creation of a ACR Events Subscription.                                     |
| Individual ACR Events Subscription | /sbscriptions/{subscriptionId} | GET                             | Retrieve an existing "Individual ACR Events Subscription" resource.                    |
|                                    |                                | PUT                             | Request the update of an existing "Individual ACR Events Subscription" resource.       |
|                                    |                                | PATCH                           | Request the modification of an existing "Individual ACR Events Subscription" resource. |
|                                    |                                | DELETE                          | Request the deletion of an existing "Individual ACR Events Subscription" resource.     |

## 9.6.3.2 Resource: ACR Events Subscriptions


### 9.6.3.2.1 Description

This resource represents the collection of ACR Events Subscriptions managed by the ECS.

### 9.6.3.2.2 Resource Definition

Resource URI: **{apiRoot}/eecs-ae/\<apiVersion\>/subscriptions**

This resource shall support the resource URI variables defined in table 9.6.3.2.2-1.

Table 9.6.3.2.2-1: Resource URI variables for this resource

| Name    | Data type | Definition        |
|---------|-----------|-------------------|
| apiRoot | string    | See clause 9.6.1. |
