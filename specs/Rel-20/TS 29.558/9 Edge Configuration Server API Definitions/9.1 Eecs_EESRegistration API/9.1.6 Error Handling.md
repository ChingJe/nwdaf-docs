# 9.1.6 Error Handling


## 9.1.6.1 General

For the Eecs_EESRegistration API, HTTP error responses shall be supported as specified in clause 5.2.6 of 3GPP TS 29.122 \[6\]. Protocol errors and application errors specified in clause 5.2.6 of 3GPP TS 29.122 \[6\] shall be supported for the HTTP status codes specified in table 5.2.6-1 of 3GPP TS 29.122 \[6\].

In addition, the requirements in the following clauses are applicable for the Eecs_EESRegistration API.

## 9.1.6.2 Protocol Errors

No specific protocol errors for the Eecs_EESRegistration API are specified.
