# 5.16 Eees_EASInformationProvisioning Service


## 5.16.1 Service Description

The Eees_EASInformationProvisioning API enables a service consumer (e.g., EES) to:

\- declare the received EAS Information provisioning information to the EES.

## 5.16.2 Service Operations


### 5.16.2.1 Introduction

The service operations defined for Eees_EASInformationProvisioning API are shown in the table 5.16.2.1-1.

Table 5.16.2.1-1: Operations of the Eees_EASInformationProvisioning API

|                                         |                                                                                                                          |              |
|-----------------------------------------|--------------------------------------------------------------------------------------------------------------------------|--------------|
| Service operation name                  | Description                                                                                                              | Initiated by |
| Eees_EASInformationProvisioning_Declare | This service operation is used by the service consumer to declare the received EAS Information provisioning information. | e.g., EES    |

### 5.16.2.2 Eees_EASInformationProvisioning_Declare


#### 5.16.2.2.1 General

This service operation is used by the service consumer to declare the received EAS Information provisioning information to the EES, as specified in clause 8.18.2.4.5 of 3GPP TS 23.558 \[2\].

#### 5.16.2.2.2 EAS Information Provisioning Information Declaration

To declare the received EAS Information provisioning information, the service consumer shall send an HTTP POST request message to the EES targeting the URI of the "Declare" custom operation, with the request body including the EASInfoProvReq data structure as defined in clause 6.6.3.2.2 of 3GPP TS 24.558 \[14\].

Upon receiving the HTTP POST message from the service consumer, the EES shall:

1\. verify the identity of the service consumer and check if the service consumer is authorized to perform this operation; and

2\. if the service consumer is authorized, then the EES shall process the request and respond with either:

\- an HTTP "200 OK" status code with the response body including EAS information provisioning related information within the EASInfoProvResp data structure; or

\- an HTTP "204 No Content" status code.

If the EES determines that the received HTTP POST message needs to be redirected, the EES may respond instead with an HTTP "307 Temporary Redirect" status code or an HTTP "308 Permanent Redirect" status code including an HTTP "Location" header containing an alternative URI representing the end point of an alternative EES towards which the request message should be redirected. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[6\].

On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the POST response body, as specified in clause 6.6.6 of 3GPP TS 24.558 \[14\].
