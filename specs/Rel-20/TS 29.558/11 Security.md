# 11 Security

The authentication and authorization between EES and ECS shall be as specified in 3GPP TS 33.558 \[20\].

The authentication and authorization in EES capability exposure shall be as specified in 3GPP TS 33.558 \[20\]. When CAPIF is used, the aspects specified in clause 10 shall be used.

The security credentials to be used for verification and authorization of various API requests from EAS and EES shall be as specified in 3GPP TS 33.558 \[20\].
