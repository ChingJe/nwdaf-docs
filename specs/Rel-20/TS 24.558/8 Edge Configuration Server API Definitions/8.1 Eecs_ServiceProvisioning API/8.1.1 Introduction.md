# 8.1.1 Introduction

The Eecs_ServiceProvisioning service shall use the Eecs_ServiceProvisioning API.

The API URI of Eecs_ServiceProvisioning API shall be:

**{apiRoot}/\<apiName\>/\<apiVersion\>**

The request URI used in HTTP requests shall have the Resource URI structure defined in clause 7.5 of 3GPP TS 29.558 \[4\], i.e:

**{apiRoot}/\<apiName\>/\<apiVersion\>/\<apiSpecificResourceUriPart\>**

with the following components:

\- The {apiRoot} shall be set as described in clause 7.5 of 3GPP TS 29.558 \[4\].

\- The \<apiName\> shall be "eecs-serviceprovisioning".

\- The \<apiVersion\> shall be "v1".

\- The \<apiSpecificResourceUriPart\> shall be set as described in clause 8.1.2.
