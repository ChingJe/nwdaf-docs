# 6.3.1 API URI

The Eees_EASDiscovery service shall use the Eees_EASDiscovery API.

The request URIs used in HTTP requests shall have the Resource URI structure defined in clause 7.5 of 3GPP TS 29.558 \[4\] with the following clarifications:

\- The {apiRoot} shall be set as described in clause 7.5 of 3GPP TS 29.558 \[4\].

\- The \<apiName\> shall be "eees-easdiscovery".

\- The \<apiVersion\> shall be "v1".

\- The \<apiSpecificResourceUriPart\> shall be set as described in clause 6.3.2.
