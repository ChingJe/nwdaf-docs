# 6.3.5.2.13 Type: RequestorId

Table 6.3.5.2.13-1: Definition of type RequestorId

| Attribute name                                                                                                                     | Data type | P   | Cardinality | Description                                                         | Applicability |
|------------------------------------------------------------------------------------------------------------------------------------|-----------|-----|-------------|---------------------------------------------------------------------|---------------|
| eesId                                                                                                                              | string    | C   | 0..1        | The identifier of the EES (e.g. S-EES).                             |               |
| easId                                                                                                                              | string    | C   | 0..1        | The application identifier of the EAS (e.g. S-EAS), e.g. FQDN, URI. |               |
| eecId                                                                                                                              | string    | C   | 0..1        | The identifier of the EEC.                                          |               |
| NOTE: Either the "eecId" attribute, the "eesId" attribute or the "easId" attribute shall be provided, they are mutually exclusive. |           |     |             |                                                                     |               |
