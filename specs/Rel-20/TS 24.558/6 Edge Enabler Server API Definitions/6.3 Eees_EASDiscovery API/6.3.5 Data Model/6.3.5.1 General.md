# 6.3.5.1 General

This clause specifies the application data model supported by the Eees_EASDiscovery API.

Table 6.3.5.1-1 specifies the data types defined specifically for the Eees_EASDiscovery API service.

Table 6.3.5.1-1: Eees_EASDiscovery API specific Data Types

| Data type                     | Section defined | Description                                                                    | Applicability |
|-------------------------------|-----------------|--------------------------------------------------------------------------------|---------------|
| ACCharacteristics             | 6.3.5.2.11      | Represents EAS dynamic information changes filter.                             |               |
| DiscoveredEas                 | 6.3.5.2.8       | Represents an EAS discovery information.                                       |               |
| EasCharacteristics            | 6.3.5.2.7       | Represents the EAS chararcteristics.                                           |               |
| EASDiscEventIDs               | 6.3.5.3.3       | Represents the EAS Discovery Subscription events.                              |               |
| EasDiscoveryFilter            | 6.3.5.2.6       | Represents the EAS characteristics.                                            |               |
| EasDiscoveryNotification      | 6.3.5.2.5       | Notification of EAS discovery information.                                     |               |
| EasDiscoveryReq               | 6.3.5.2.2       | Contains the EAS discovery request information                                 |               |
| EasDiscoveryResp              | 6.3.5.2.3       | Represents the EAS discovery response.                                         |               |
| EasDiscoverySubscription      | 6.3.5.2.4       | Represents an Individual EAS Discovery Subscription resource.                  |               |
| EasDiscoverySubscriptionPatch | 6.3.5.2.12      | Represents an updated Individual EAS Discovery Subscription resource.          |               |
| EasDynamicInfoFilter          | 6.3.5.2.9       | Represents EAS dynamic information changes filter.                             |               |
| EasDynamicInfoFilterData      | 6.3.5.2.10      | Represents an EAS dynamic information.                                         |               |
| EdgeLoadAnalytic              | 6.3.5.2.14      | Contains the statistical analytics data and predictive analytics data.         |               |
| PredictiveData                | 6.3.5.2.15      | Contains the predictive analytics data for each discovered EAS service change. |               |
| RequestorId                   | 6.3.5.2.13      | Represents identifier of the requestor.                                        |               |
| StatisticalData               | 6.3.5.2.16      | Contains the statistical analytics data.                                       |               |
