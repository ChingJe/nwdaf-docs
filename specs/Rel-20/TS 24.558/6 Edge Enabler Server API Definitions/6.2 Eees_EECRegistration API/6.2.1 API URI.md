# 6.2.1 API URI

The request URI used in each HTTP request from the EEC towards the EES shall have the structure as defined in clause 7.5 of 3GPP TS 29.558 \[4\] with the following clarifications:

\- The {apiRoot} shall be set as described in clause 7.5 of 3GPP TS 29.558 \[4\].

\- The \<apiName\> shall be "eees-eecregistration".

\- The \<apiVersion\> shall be "v1".

\- The \<apiSpecificResourceUriPart\> shall be set as described in clause 6.2.2.
