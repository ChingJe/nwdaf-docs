## 6.4.4.2 ACR Information Notification


### 6.4.4.2.1 Description

The ACR Information Notification is used by the EES to notify a previously subscribed service consumer on ACR events subscriptions.

### 6.4.4.2.2 Target URI

The Callback URI: **{notificationDestination}** shall be used with the callback URI variables specified in table 6.4.4.2.2-1.

Table 6.4.4.2.2-1: Callback URI variables

| Name                    | Definition                                     |
|-------------------------|------------------------------------------------|
| notificationDestination | String formatted as URI with the Callback Uri. |

### 6.4.4.2.3 Standard Methods


#### 6.4.4.2.3.1 POST

This method shall support the request data structures specified in table 6.4.4.2.3.1-1 and the response data structures and response codes specified in table 6.4.4.2.3.1-2.

Table 6.4.4.2.3.1-1: Data structures supported by the POST Request Body on this resource

| Data type           | P   | Cardinality | Description                      |
|---------------------|-----|-------------|----------------------------------|
| ACRInfoNotification | M   | 1           | Notification of ACR information. |
