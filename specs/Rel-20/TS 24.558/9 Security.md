# 9 Security

The authentication and authorization between EEC and ECS shall be as specified in 3GPP TS 33.558 \[7\].

The authentication and authorization between EEC and EES shall be as specified in 3GPP TS 33.558 \[7\].

The security credentials to be used for verification and authorization of various API requests from EEC shall be as specified in 3GPP TS 33.558 \[7\].

The EEC, prior to consuming services offered by the EES APIs, may obtain the "access tokens" from the ECS, by invoking the Eecs_ServiceProvisioning service, as described in 3GPP TS 33.558 \[7\].
