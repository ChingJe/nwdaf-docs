# 1 Scope

The present document specifies the stage-3 protocol and data model for services. It provides stage-3 protocol definitions and message flows, and specifies the APIs for services offered by the Edge Enabler Server and the Edge Configuration Server.

The stage 2 architecture and procedures are specified in 3GPP TS 23.558 \[2\].

The common protocol and interface aspects for API definition are specified in clause 5.2 of 3GPP TS 29.122 \[6\].
