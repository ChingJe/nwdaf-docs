# 8.41 Service API performance analytics


## 8.41.1 General

When service API performance analytics is desired by the consumer (e.g. AMF), the CCF can implement service API analytics of ADAE server as specified in clause 8.6 of 3GPP TS 23.436 \[r23436\] for generating the requested analytics, based on the service API information available at the CCF. In such case, the CCF can provide the service API performance analytics for example, Usage Metrics (Requests per Second, Total Requests, Response Times), Error Tracking (Error Rates), Most Used Endpoints, Security Monitoring (Unauthorized Access Attempts, Rate Limiting Violations), Latency Analysis, Audit Logs, etc.
