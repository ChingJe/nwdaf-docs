# 5.17 Server change service


## 5.17.1 Service description

The server change service enables the AIMLE server to trigger and complete AIMLE server change as defined in clause 8.32 in 3GPP TS 23.482 \[4\].

## 5.17.2 Service operations


### 5.17.2.1 Introduction

The service operation defined for the server change service is shown in the table 5.17.2.1-1.

Table 5.17.2.1-1: Service operations of server change

|                              |                                                                                       |                                      |
|------------------------------|---------------------------------------------------------------------------------------|--------------------------------------|
| Service operation name       | Description                                                                           | Initiated by                         |
| Aimles_ServerChange_Trigger  | This service operation allows a service consumer to trigger the AIMLE server change.  | Service consumer (e.g. AIMLE server) |
| Aimles_ServerChange_Complete | This service operation allows a service consumer to complete the AIMLE server change. | Service consumer (e.g. AIMLE server) |

### 5.17.2.2 Aimles_ServerChange_Trigger


#### 5.17.2.2.1 General

This service operation is used by a service consumer (e.g. the AIMLE server) to trigger the AIMLE server change.

#### 5.17.2.2.2 AIMLE Server Change Trigger

To request the AIMLE client for triggering the AIMLE server change, the AIMLE server shall send to the AIMLE client the HTTP POST (custom operation: "AIMLE server change trigger") with a Request-URI set to "{apiRoot}/aimles-sc/\<apiVersion\>/trigger" and the request body including the AimleServerChangeTriggerReq data structure as specified in clause 6.16.6.2.2.

Upon receipt of the HTTP POST request from the AIMLE server, the AIMLE client shall verify the identity of the AIMLE server and determine if the AIMLE server is authorized for the request. If the AIMLE server:

a\) is not authorized to request, the AIMLE client shall respond to the AIMLE server with an appropriate error status code as specified in clause 6.16.7; or

b\) is authorized, the AIMLE client shall respond to the AIMLE server:

1\) if the HTTP POST request is handled successfully:

\- the HTTP "200 OK" status code with the response body including the AimleServerChangeTriggerResp as specified in clause 6.16.6.2.3; or

\- the HTTP "204 No Content" status code; and

2\) if the HTTP POST request is not handled successfully, an appropriate error response as specified in clause 6.16.7.

The AIMLE client may respond to the AIMLE server with an HTTP "307 Temporary Redirect" status code or an HTTP "308 Permanent Redirect" status code including an HTTP "Location" header containing an alternative URI representing the end point of an alternative AIMLE client towards which the request shall be sent. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].

### 5.17.2.3 Aimles_ServerChange_Complete


#### 5.17.2.3.1 General

This service operation is used by a service consumer (e.g. the AIMLE server) to complete the AIMLE server change.

#### 5.17.2.3.2 AIMLE Server Change Complete

To request the AIMLE client for completion of the AIMLE server change, the AIMLE server shall send to the AIMLE client the HTTP POST (custom operation: "AIMLE server change complete") with a Request-URI set to "{apiRoot}/aimles-sc/\<apiVersion\>/complete" and the request body including the AimleServerChangeComplete data structure as specified in clause 6.16.6.2.4.

Upon receipt of the HTTP POST request from the AIMLE server, the AIMLE client shall verify the identity of the AIMLE server and determine if the AIMLE server is authorized for the request. If the AIMLE server:

a\) is not authorized to request, the AIMLE client shall respond to the AIMLE server with an appropriate error status code as specified in clause 6.16.7; or

b\) is authorized, the AIMLE client shall respond to the AIMLE server:

1\) if the HTTP POST request is handled successfully, the HTTP "204 No Content" status code; and

2\) if the HTTP POST request is not handled successfully, an appropriate error response as specified in clause 6.16.7.

The AIMLE client may respond to the AIMLE server with an HTTP "307 Temporary Redirect" status code or an HTTP "308 Permanent Redirect" status code including an HTTP "Location" header containing an alternative URI representing the end point of an alternative AIMLE client towards which the request shall be sent. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].
