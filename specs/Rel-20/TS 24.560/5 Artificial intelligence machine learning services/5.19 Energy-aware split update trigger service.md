# 5.19 Energy-aware split update trigger service


## 5.19.1 Service description

The energy-aware split update trigger service enables the AIMLE client to retrieve information from the AIMLE server to update the split AI/ML operation pipeline due to the energy credit or budget of the VAL UE as defined in clause 8.14.2.8 of 3GPP TS 23.482 \[4\].

## 5.19.2 Service operations


### 5.19.2.1 Introduction

The service operation defined for energy-aware split update trigger service is shown in the table 5.19.2.1-1.

Table 5.19.2.1-1: Operations of Energy-aware split update trigger service

|                            |                                                                                                                                                                                                      |              |
|----------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------|
| Service operation name     | Description                                                                                                                                                                                          | Initiated by |
| EnergySplitUpdate_Retrieve | This service operation is used by the AIMLE client as a part of the VAL UE to retrieve information from the AIMLE server to update the split AI/ML operation pipeline due to its energy information. | AIMLE client |

### 5.19.2.2 EnergySplitUpdate_Retrieve


#### 5.19.2.2.1 General

The EnergySplitUpdate_Retrieve service operation is used by AIMLE client to retrieve information from the AIMLE server to update the split AI/ML operation pipeline.

#### 5.19.2.2.2 Energy-aware split update trigger service operation

To retreive information from the AIMLE server for updating split AI/ML operation pipeline, the AIMLE client shall send an HTTP GET request with a Request-URI set to "{apiRoot}/aimles-esut/\<apiVersion\>/splitUpdate" targeting the URI of the "Split AI/ML operation pipeline update" resource in clause 6.18.3.2.

Upon receipt of the HTTP GET request:

a\) the AIMLE server shall verify the identity of the AIMLE client and determine if the AIMLE client is authorized to request the AIMLE server to update for split AI/ML operation pipeline; and

b\) if the AIMLE client:

1\) is not authorized, the AIMLE server shall respond to the AIMLE client with an appropriate error status code; or

2\) is authorized, the AIMLE server shall respond to the AIMLE client with:

i\) if the HTTP GET request is handled successfully, an HTTP "200 OK" status code with the response body including the EnergySplitUpdateResp data structure as specified in clause 6.18.6.2.3; or

ii\) if the HTTP GET request is not handled successfully, an appropriate error response as specified in clause 6.18.7.

The AIMLE server may respond to the AIMLE client with an HTTP "307 Temporary Redirect" status code or an HTTP "308 Permanent Redirect" status code including an HTTP "Location" header containing an alternative URI representing the end point of an alternative AIMLE server towards which the request shall be sent. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].
