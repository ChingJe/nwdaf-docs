# 5.18 Intermediate node service


## 5.18.1 Service description

The intermediate node service enables the AIMLE client requests the AIMLE server to discover and select one or more intermediate nodes which may be Edge Application Server (EAS) or an AIMLE client, to update the AIMLE pipeline operation to maintain the AIMLE service continuity, see clause 8.29 in 3GPP TS 23.482 \[4\].

## 5.18.2 Service operations


### 5.18.2.1 Introduction

The service operation defined for intermediate node service is shown in the table 5.18.2.1-1.

Table 5.18.2.1-1: Operations of intermediate node service

|                                   |                                                                                                                                                                                                      |              |
|-----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------|
| Service operation name            | Description                                                                                                                                                                                          | Initiated by |
| IntermediateNodeDiscovery_Request | This service operation is used by the AIMLE client to request for discovery of one or more intermediate nodes which can be used to update the AIMLE pipeline operation for AIMLE service continuity. | AIMLE client |
| IntermediateNodeSelect_Request    | This service operation is used by the AIMLE client to request for selection of one or more intermediate nodes to update the AIMLE pipeline operation for AIMLE service continuity.                   | AIMLE client |

### 5.18.2.2 IntermediateNodeDiscovery_Request


#### 5.18.2.2.1 General

The IntermediateNodeDiscovery_Request service operation is used by AIMLE client to request the AIMLE server to discover one or more intermediate nodes for updating the AIMLE pipeline.

#### 5.18.2.2.2 Intermediate node discovery service operation

To request the AIMLE server for discovering of one or more intermediate nodes, the AIMLE client shall send an HTTP GET request with a Request-URI set to "{apiRoot}/aimles-in/\<apiVersion\>/discoverNode" targeting the URI of the "discover one or more intermediate nodes" resource in clause 6.17.3.2.

Upon receipt of the HTTP GET request:

a\) the AIMLE server shall verify the identity of the AIMLE client and determine if the AIMLE client is authorized to request the AIMLE server to request discovery of one or more intermediate node to update AIMLE pipeline for AIMLE service continuity; and

b\) if the AIMLE client:

1\. is not authorized, the AIMLE server shall respond to the AIMLE client with an appropriate error status code; or

2\. is authorized, the AIMLE server shall respond to the AIMLE client with:

i\. if the HTTP GET request is handled successfully, an HTTP "200 OK" status code with the response body including the IntermediateNodeDiscoveryResp data structure as specified in clause 6.17.6.2.3; or

ii\. if the HTTP GET request is not handled successfully, an appropriate error response as specified in clause 6.17.7.

The AIMLE server may respond to the AIMLE client with an HTTP "307 Temporary Redirect" status code or an HTTP "308 Permanent Redirect" status code including an HTTP "Location" header containing an alternative URI representing the end point of an alternative AIMLE server towards which the request shall be sent. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].

### 5.18.2.3 IntermediateNodeSelect_Request


#### 5.18.2.3.1 General

The IntermediateNodeSelect_Request service operation is used by AIMLE client to request the AIMLE server to select one or more discovered intermediate nodes for updating the AIMLE pipeline.

#### 5.18.2.3.2 Intermediate node selection service operation

To request the AIMLE server for selection of one or more discovered intermediate node, the AIMLE client shall send an HTTP POST request with a Request-URI set to "{apiRoot}/aimles-in/\<apiVersion\>/selectNode" with the request body including the IntermediateNodeSelectReq data structure as specified in clause 6.17.6.2.4.

Upon receipt of the HTTP POST request:

a\) the AIMLE server shall verify the identity of the AIMLE client and determine if the AIMLE client is authorized to request the AIMLE server to request selecting the one or more discovered intermediate nodes to update AIMLE pipeline for AIMLE service continuity; and

b\) if the AIMLE client:

1\) is not authorized, the AIMLE server shall respond to the AIMLE client with an appropriate error status code; or

2\) is authorized, the AIMLE server shall respond to the AIMLE client with:

i\) if the HTTP POST request is handled successfully, an HTTP "204 No Content" status code to acknowledge the reception of the selection of the one or more discovered intermediate nodes to be used to update the AIMLE pipeline operation for AIMLE service continuity; or

ii\) if the HTTP POST request is not handled successfully, an appropriate error response as specified in clause 6.17.7.

The AIMLE server may respond to the AIMLE client with an HTTP "307 Temporary Redirect" status code or an HTTP "308 Permanent Redirect" status code including an HTTP "Location" header containing an alternative URI representing the end point of an alternative AIMLE server towards which the request shall be sent. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].
