# 5.16 ML model evaluation information service


## 5.16.1 Service description

The ML model evaluation information service enables AIMLE client to request ML model update at the AIMLE server as defined in 3GPP TS 23.482 \[4\].

## 5.16.2 Service operations


### 5.16.2.1 Introduction

The service operations defined for the Aimles_MLModelEvalInfo API are shown in Table 5.16.2.1‑1.

Table 5.16.2.1-1: Operations for ML model evaluation information service

| Service operation name                             | Description                                                                                                                       | Initiated by |
|----------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------|--------------|
| Aimles_MLModelEvalInfoStore_Request                | This service operation is used by the AIMLE client to request storage of ML model evaluation information at the AIMLE server.     | AIMLE client |
| Aimles_MLModelEvalInfoRetrieve_Request             | This service operation is used by the AIMLE client to request retrieval of ML model evaluation information from the AIMLE server. | AIMLE client |
| Aimles_MLModelEvalInfoRemove_Request               | This service operation is used by the AIMLE client to request removal of ML model evaluation information from the AIMLE server.   | AIMLE client |
| Aimles_MLModelEvalInfoRetrieval_Subscribe          | Creates a subscription for retrieval of ML model evaluation information.                                                          | AIMLE client |
| Aimles_MLModelEvalInfoRetrieval_Notify             | Notifies a subscribed service consumer of retrieved ML model evaluation information.                                              | AIMLE server |
| Aimles_MLModelEvalInfoRetrieval_UpdateSubscription | Updates an existing subscription for retrieval of ML model evaluation information.                                                | AIMLE client |
| Aimles_MLModelEvalInfoRetrieval_Unsubscribe        | Deletes an existing subscription for retrieval of ML model evaluation information.                                                | AIMLE client |

### 5.16.2.2 Aimles_MLModelEvalInfoStore_Request


#### 5.16.2.2.1 General

The Aimles_MLModelEvalInfoStore_Request service operation is used by the AIMLE client to store ML model evaluation information at the AIMLE server.

#### 5.16.2.2.2 ML model evaluation information storage request

To request storage of ML model evaluation information at the AIMLE server, the AIMLE client shall send an HTTP POST request, as specified in clause 6.15.4.2, with a body containing data type MLMdlEvalInfoStoreReq as defined in clause 6.15.6.2.2.

Upon receipt of the HTTP POST request:

a\) the AIMLE server shall verify the identity of the AIMLE client and determine if the AIMLE client is authorized to request ML model evaluation information storage; and

b\) if the AIMLE client:

1\) is not authorized, the AIMLE server shall respond to the AIMLE client with an appropriate error status code; or

2\) is authorized, the AIMLE server:

i\) shall store the ML model evaluation information in the ML repository as described in clause 6.15.4.2.2; and

ii\) shall respond to the AIMLE client with:

A\) if the HTTP POST request is handled successfully, the HTTP "200 OK" response code with the response body containing data type MLMdlEvalInfoStoreRsp as defined in clause 6.15.6.2.3; and

B\) if the HTTP POST request is not handled successfully, an appropriate error response as specified in clause 6.15.7.

The AIMLE server may respond to the AIMLE client with the HTTP "307 Temporary Redirect" status code or the HTTP "308 Permanent Redirect" status code including the HTTP "Location" header containing an alternative URI representing the end point of an alternative AIMLE server. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].

### 5.16.2.3 Aimles_MLModelEvalInfoRetrieve_Request


#### 5.16.2.3.1 General

The Aimles_MLModelEvalInfoRetrieve_Request service operation is used by the AIMLE client to retrieve ML model evaluation information from the AIMLE server.

#### 5.16.2.3.2 ML model evaluation information retrieval request

To request retrieval of ML model evaluation information from the AIMLE server, the AIMLE client shall send an HTTP POST request, as specified in clause 6.15.4.3, with a body containing data type MLMdlEvalInfoRetrieveReq as defined in clause 6.15.6.2.4.

Upon receipt of the HTTP POST request:

a\) the AIMLE server shall verify the identity of the AIMLE client and determine if the AIMLE client is authorized to request ML model evaluation information retrieval; and

b\) if the AIMLE client:

1\) is not authorized, the AIMLE server shall respond to the AIMLE client with an appropriate error status code; or

2\) is authorized, the AIMLE server:

i\) shall retrieve the requested ML model evaluation information from the ML repository based on the provided filtering criteria as described in clause 6.15.4.3.2; and

ii\) shall respond to the AIMLE client with:

A\) if the HTTP POST request is handled successfully, the HTTP "200 OK" response code with the response body containing data type MLMdlEvalInfoRetrieveRsp as defined in clause 6.15.6.2.5; and

B\) if the HTTP POST request is not handled successfully, an appropriate error response as specified in clause 6.15.7.

The AIMLE server may respond to the AIMLE client with the HTTP "307 Temporary Redirect" or "308 Permanent Redirect" status codes including the HTTP "Location" header containing an alternative URI representing the end point of an alternative AIMLE server. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].

### 5.16.2.4 Aimles_MLModelEvalInfoRemove_Request


#### 5.16.2.4.1 General

The Aimles_MLModelEvalInfoRemove_Request service operation is used by the AIMLE client to remove ML model evaluation information from the AIMLE server.

#### 5.16.2.4.2 ML model evaluation information removal request

To request removal of ML model evaluation information from the AIMLE server, the AIMLE client shall send an HTTP POST request, as specified in clause 6.15.4.4, with a body containing data type MLMdlEvalInfoRemoveReq as defined in clause 6.15.6.2.6.

Upon receipt of the HTTP POST request:

a\) the AIMLE server shall verify the identity of the AIMLE client and determine if the AIMLE client is authorized to request ML model evaluation information removal; and

b\) if the AIMLE client:

1\) is not authorized, the AIMLE server shall respond to the AIMLE client with an appropriate error status code; or

2\) is authorized, the AIMLE server:

i\) shall remove the specified ML model evaluation information from the ML repository as described in clause 6.15.4.4.2; and

ii\) shall respond to the AIMLE client with:

A\) if the HTTP POST request is handled successfully, the HTTP "200 OK" response code with the response body containing data type MLMdlEvalInfoRemoveRsp as defined in clause 6.15.6.2.7; and

B\) if the HTTP POST request is not handled successfully, an appropriate error response as specified in clause 6.15.7.

The AIMLE server may respond with HTTP "307 Temporary Redirect" or "308 Permanent Redirect" including the HTTP "Location" header containing an alternative URI representing the end point of an alternative AIMLE server. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].

### 5.16.2.5 Aimles_MLModelEvalInfoRetrieval_Subscribe


#### 5.16.2.5.1 General

The Aimles_MLModelEvalInfoRetrieval_Subscribe service operation is used by an AIMLE client to subscribe with the AIMLE server to be notified for retrieval of ML model evaluation information.

#### 5.16.2.5.2 ML model evaluation information retrieval subscription

To create an ML model evaluation information retrieval subscription, the service consumer shall send an HTTP POST request targeting the "ML model evaluation information retrieval subscriptions" collection resource as specified in clause 6.15.3.2, with the request body including the MLMdlEvalInfoSub data type as specified in clause 6.15.6.2.8.

Upon receipt of the HTTP POST request, the AIMLE server shall verify the identity of the service consumer and determine whether the service consumer is authorized for the request. If the service consumer:

a\) is not authorized, the AIMLE server shall respond with an appropriate error status code as specified in clause 6.15.7; or

b\) is authorized, the AIMLE server shall:

1\) create an "Individual ML model evaluation information retrieval subscription" resource and store the subscription information; and

2\) respond with an HTTP "201 Created" status code, an HTTP "Location" header containing the URI of the created resource and a response body containing the MLMdlEvalInfoSub data type as specified in clause 6.15.6.2.8.

The AIMLE server may respond with an HTTP "307 Temporary Redirect" status code or an HTTP "308 Permanent Redirect" status code including an HTTP "Location" header containing an alternative URI representing the end point of an alternative AIMLE server. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].

### 5.16.2.6 Aimles_MLModelEvalInfoRetrieval_Notify


#### 5.16.2.6.1 General

The Aimles_MLModelEvalInfoRetrieval_Notify service operation is used by the AIMLE server to notify a subscribed service consumer of retrieved ML model evaluation information.

#### 5.16.2.6.2 ML model evaluation information retrieval notification

To notify a subscribed service consumer of retrieved ML model evaluation information, the AIMLE server shall send an HTTP POST request to the notification URI provided in the corresponding subscription, with the request body including the MLMdlEvalInfoNotif data type as specified in clause 6.15.6.2.10.

Upon receipt of the HTTP POST request, the service consumer shall verify the identity of the AIMLE server and determine whether the AIMLE server is authorized for the request. The service consumer shall respond with:

a\) an HTTP "204 No Content" status code if the notification is received and processed successfully; or

b\) an appropriate error response as specified in clause 6.15.7 if the request is not handled successfully.

The service consumer may respond with an HTTP "307 Temporary Redirect" status code or an HTTP "308 Permanent Redirect" status code including an HTTP "Location" header containing an alternative URI representing an alternative notification end point. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].

### 5.16.2.7 Aimles_MLModelEvalInfoRetrieval_UpdateSubscription


#### 5.16.2.7.1 General

The Aimles_MLModelEvalInfoRetrieval_UpdateSubscription service operation is used by an AIMLE client or VAL server to update an existing ML model evaluation information retrieval subscription at the AIMLE server.

#### 5.16.2.7.2 ML model evaluation information retrieval subscription update

To update an existing ML model evaluation information retrieval subscription, the service consumer shall send to the AIMLE server:

\- an HTTP PUT request for full replacement of the subscription, with the request body including the MLMdlEvalInfoSub data type as specified in clause 6.15.6.2.8; or

\- an HTTP PATCH request for partial modification of the subscription, with the request body including the MLMdlEvalInfoSubPatch data type as specified in clause 6.15.6.2.9,

targeting the "Individual ML model evaluation information retrieval subscription" resource as specified in clause 6.15.3.3.

Upon receipt of the HTTP PUT request or HTTP PATCH request, the AIMLE server shall verify the identity of the service consumer and determine whether the service consumer is authorized for the request. If the service consumer:

a\) is not authorized, the AIMLE server shall respond with an appropriate error status code as specified in clause 6.15.7; or

b\) is authorized, the AIMLE server shall update the subscription and respond with either:

1\) an HTTP "200 OK" status code with the response body containing the updated MLMdlEvalInfoSub data type; or

2\) an HTTP "204 No Content" status code.

If the subscription contains an expiration time, the service consumer shall update the subscription before the expiration time to maintain the subscription. If the AIMLE server does not receive an update before the expiration time, the AIMLE server shall delete the corresponding subscription resource.

The AIMLE server may respond with an HTTP "307 Temporary Redirect" status code or an HTTP "308 Permanent Redirect" status code including an HTTP "Location" header containing an alternative URI representing the end point of an alternative AIMLE server. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].

### 5.16.2.8 Aimles_MLModelEvalInfoRetrieval_Unsubscribe


#### 5.16.2.8.1 General

The Aimles_MLModelEvalInfoRetrieval_Unsubscribe service operation is used by an AIMLE client or VAL server to cancel an existing ML model evaluation information retrieval subscription at the AIMLE server.

#### 5.16.2.8.2 ML model evaluation information retrieval unsubscription

To cancel an existing ML model evaluation information retrieval subscription, the service consumer shall send an HTTP DELETE request targeting the "Individual ML model evaluation information retrieval subscription" resource as specified in clause 6.15.3.3.

Upon receipt of the HTTP DELETE request, the AIMLE server shall verify the identity of the service consumer and determine whether the service consumer is authorized for the request. If the service consumer:

a\) is not authorized, the AIMLE server shall respond with an appropriate error status code as specified in clause 6.15.7; or

b\) is authorized, the AIMLE server shall delete the corresponding subscription resource and respond with an HTTP "204 No Content" status code.

The AIMLE server may respond with an HTTP "307 Temporary Redirect" status code or an HTTP "308 Permanent Redirect" status code including an HTTP "Location" header containing an alternative URI representing the end point of an alternative AIMLE server. Redirection handling is described in clause 5.2.10 of 3GPP TS 29.122 \[5\].
