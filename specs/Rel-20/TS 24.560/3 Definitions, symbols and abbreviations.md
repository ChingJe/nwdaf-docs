# 3 Definitions, symbols and abbreviations


## 3.1 Definitions

For the purposes of the present document, the terms and definitions given in 3GPP TR 21.905 \[2\] and the following apply. A term defined in the present document takes precedence over the definition of the same term, if any, in 3GPP TR 21.905 \[2\].

**AIMLE client:** An AI/ML enablement layer entity (see 3GPP TS 23.482 \[4\] clause 5) which is an AI/ML endpoint, and performs client-side operations.

**AI/ML intermediate model:** An AI/ML intermediate model defined in 3GPP TS 23.482 \[4\].

**AI/ML operation:** An AI/ML operation defined in 3GPP TS 23.482 \[4\].

**AIMLE server:** An AI/ML enablement layer entity (see 3GPP TS 23.482 \[4\] clause 5) which is an AI/ML endpoint, and performs server-side operations.

For the purposes of the present document, the following terms and definitions given in 3GPP TS 23.434 \[3\] apply:

**SEAL service**

**VAL client**

**VAL server**

**VAL service**

**Vertical**

**Vertical application**
