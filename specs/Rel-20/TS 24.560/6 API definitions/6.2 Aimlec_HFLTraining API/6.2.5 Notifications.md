## 6.2.5.2 HFL training event notification


### 6.2.5.2.1 Description

The HFL training event notification is used by the AIMLE client to report HFL training event to AIMLE server that has subscribed to such an event notification.

### 6.2.5.2.2 Target URI

The Callback URI **"{notifUri}"** shall be used with the callback URI variables defined in table 6.2.5.2.2-1.
