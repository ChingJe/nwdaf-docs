# 6.16 Aimles_ServerChange API


## 6.16.1 Introduction

Service change service shall use the Aimles_ServerChange API.

The API URI of the Aimles_ServerChange API shall be:

**{apiRoot}/\<apiName\>/\<apiVersion\>**

The request URIs used in HTTP requests shall have the Resource URI structure defined in clause 5.2.4 of 3GPP TS 29.122 \[5\], i.e.:

**{apiRoot}/\<apiName\>/\<apiVersion\>/\<apiSpecificSuffixes\>**

with the following components:

\- The {apiRoot} shall be set as described in clause 5.2.4 of 3GPP TS 29.122 \[5\].

\- The \<apiName\> shall be "aimles-sc".

\- The \<apiVersion\> shall be "v1".

\- The \<apiSpecificSuffixes\> shall be set as described in clause 6.16.4.

## 6.16.2 Usage of HTTP and common API related aspects


### 6.16.2.1 Overview

The provisions of clause 5.2 of 3GPP TS 29.122 \[5\] shall apply for the Aimles_ServerChange API.

## 6.16.3 Resources

There are no resources defined for this API in this release of the specification.

### 6.16.4.2 Operation: AIMLE server change trigger


#### 6.16.4.2.1 Description

The custom operation enables the source AIMLE server to send the AIMLE server change as a trigger request to the AIMLE client, notifying the AIMLE client about the available AIMLE servers in the VPLMN.
