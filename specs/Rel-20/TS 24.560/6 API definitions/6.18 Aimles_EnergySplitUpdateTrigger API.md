# 6.18 Aimles_EnergySplitUpdateTrigger API


## 6.18.1 Introduction

The energy-aware split update trigger service shall use the Aimles_EnergySplitUpdateTrigger API.

The API URI of the Aimles_EnergySplitUpdateTrigger API shall be:

**{apiRoot}/\<apiName\>/\<apiVersion\>**

The request URIs used in HTTP requests shall have the Resource URI structure defined in clause 5.2.4 of 3GPP TS 29.122 \[5\], i.e.:

**{apiRoot}/\<apiName\>/\<apiVersion\>/\<apiSpecificSuffixes\>**

with the following components:

\- The {apiRoot} shall be set as described in clause 5.2.4 of 3GPP TS 29.122 \[5\].

\- The \<apiName\> shall be "aimles-esut".

\- The \<apiVersion\> shall be "v1".

\- The \<apiSpecificSuffixes\> shall be set as described in clause 6.18.3.

## 6.18.2 Usage of HTTP and common API related aspects

The provisions of clause 5.2 of 3GPP TS 29.122 \[5\] shall apply for the Aimles_EnergySplitUpdateTrigger API.
