# 6.15.6 Data model


## 6.15.6.1 General

This clause specifies the application data model supported by the Aimles_MLModelEvalInfo API.

Table 6.15.6.1-1 specifies the data types defined for the Aimles_MLModelEvalInfo API.

Table 6.15.6.1-1: Aimles_MLModelEvalInfo API specific Data Types

| Data type                | Clause defined | Description                                                                       | Applicability |
|--------------------------|----------------|-----------------------------------------------------------------------------------|---------------|
| MlMdlEvalInfo            | 6.15.6.2.13    | Represents information used to evaluate ML model performance and correctness.     |               |
| MlMdlEvalInfoFilter      | 6.15.6.2.14    | Represents filtering criteria for ML model evaluation information.                |               |
| MlMdlEvalInfoFilterData  | 6.15.6.2.15    | Represents ML model evaluation information fields used as filtering criteria.     |               |
| MlMdlEvalInfoNotif       | 6.15.6.2.10    | Represents a retrieval notification.                                              |               |
| MlMdlEvalInfoNotifItem   | 6.15.6.2.11    | Identifies or contains an ML model evaluation profile provided in a notification. |               |
| MlMdlEvalProfile         | 6.15.6.2.12    | Represents an ML model evaluation profile.                                        |               |
| MlMdlEvalInfoRemoveReq   | 6.15.6.2.6     | Represents a request to remove ML model evaluation information.                   |               |
| MlMdlEvalInfoRemoveRsp   | 6.15.6.2.7     | Represents the successful response to a removal request.                          |               |
| MlMdlEvalInfoRetrieveReq | 6.15.6.2.4     | Represents a request to retrieve ML model evaluation information.                 |               |
| MlMdlEvalInfoRetrieveRsp | 6.15.6.2.5     | Represents the successful response to a retrieval request.                        |               |
| MlMdlEvalInfoSub         | 6.15.6.2.8     | Represents an ML model evaluation information retrieval subscription.             |               |
| MlMdlEvalInfoSubPatch    | 6.15.6.2.9     | Represents a partial update of a retrieval subscription.                          |               |
| MlMdlEvalInfoStoreReq    | 6.15.6.2.2     | Represents a request to store ML model evaluation information.                    |               |
| MlMdlEvalInfoStoreRsp    | 6.15.6.2.3     | Represents the successful response to a storage request.                          |               |

Table 6.15.6.1-2 specifies data types re-used by the Aimles_MLModelEvalInfo API from other specifications, including a reference to their respective specifications, and when needed, a short description of their use within the Aimles_MLModelEvalInfo API.

Table 6.15.6.1-2: Aimles_MLModelEvalInfo API re-used Data Types

| Data type         | Reference             | Comments                                                  | Applicability     |
|-------------------|-----------------------|-----------------------------------------------------------|-------------------|
| DateTime          | 3GPP TS 29.122 \[5\]  | Represents a date and time.                               | DateTime          |
| SupportedFeatures | 3GPP TS 29.571 \[11\] | Used to negotiate the applicability of optional features. | SupportedFeatures |
| Uri               | 3GPP TS 29.122 \[5\]  | Represents a URI.                                         | Uri               |
