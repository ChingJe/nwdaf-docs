# 6.15.4 Custom operations without associated resources


## 6.15.4.1 Overview

Table 6.15.4.1-1: Custom operations without associated resources

| Operation name                           | Custom operation URI | Mapped HTTP method | Description                                                      |
|------------------------------------------|----------------------|--------------------|------------------------------------------------------------------|
| Store ML model evaluation information    | /store               | POST               | Stores ML model evaluation information at the AIMLE server.      |
| Retrieve ML model evaluation information | /retrieve            | POST               | Retrieves ML model evaluation information from the AIMLE server. |
| Remove ML model evaluation information   | /remove              | POST               | Removes ML model evaluation information from the AIMLE server.   |

Table 6.15.4.1-2: URI variables for these custom operations

| Name    | Data type | Definition         |
|---------|-----------|--------------------|
| apiRoot | string    | See clause 6.15.1. |

## 6.15.4.2 Operation: Store ML model evaluation information


### 6.15.4.2.1 Description

The custom operation enables a service consumer to store ML model evaluation information at the AIMLE server.

### 6.15.4.2.2 Operation definition

This operation shall support the response data structures and response codes specified in tables 6.15.4.2.2-1 and tables 6.15.4.2.2-2.

Table 6.15.4.2.2-1: Data structures supported by the POST Request Body on this resource

|                       |     |             |                                                            |
|-----------------------|-----|-------------|------------------------------------------------------------|
| Data type             | P   | Cardinality | Description                                                |
| MLMdlEvalInfoStoreReq | M   | 1           | Contains the ML model evaluation information to be stored. |
