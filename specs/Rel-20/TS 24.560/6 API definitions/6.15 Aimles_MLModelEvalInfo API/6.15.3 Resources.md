# 6.15.3 Resources


## 6.15.3.1 Overview

This clause describes the resource URIs and methods used for ML model evaluation information retrieval subscriptions.

Editor's note: (WIC AIML_Ph2_APP-CT, CR#0040): The figure depicting the resource URIs structure is FFS.

Table 6.15.3.1-1 provides an overview of the resources and applicable HTTP methods.

Table 6.15.3.1-1: Resources and methods overview

| Resource name                                                     | Resource URI                    | HTTP method or custom operation | Description                                                                       |
|-------------------------------------------------------------------|---------------------------------|---------------------------------|-----------------------------------------------------------------------------------|
| ML Model Evaluation Information Retrieval Subscriptions           | /subscriptions                  | POST                            | Creates a new "ML Model Evaluation Information Retrieval Subscriptions" resource. |
| Individual ML Model Evaluation Information Retrieval Subscription | /subscriptions/{subscriptionId} | PUT                             | Fully replaces an existing subscription resource.                                 |
|                                                                   |                                 | PATCH                           | Partially modifies an existing subscription resource.                             |
|                                                                   |                                 | DELETE                          | Deletes an existing subscription resource.                                        |

## 6.15.3.2 Resource: ML model evaluation information retrieval subscriptions


### 6.15.3.2.1 Description

This resource represents the collection of ML model evaluation information retrieval subscriptions at an AIMLE server.

### 6.15.3.2.2 Resource definition

Resource URI: **{apiRoot}/aimles-mlmei/\<apiVersion\>/subscriptions**

This resource shall support the resource URI variables defined in table 6.15.3.2.2-1.

Table 6.15.3.2.2-1: Resource URI variables for this resource

| Name    | Data type | Definition         |
|---------|-----------|--------------------|
| apiRoot | string    | See clause 6.15.1. |
