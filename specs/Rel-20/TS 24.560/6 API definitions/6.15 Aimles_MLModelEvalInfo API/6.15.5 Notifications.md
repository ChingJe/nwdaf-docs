## 6.15.5.2 ML model evaluation information retrieval notification


### 6.15.5.2.1 Description

The notification is used by the AIMLE server to provide retrieved ML model evaluation information to a service consumer that has subscribed to such notifications.

### 6.15.5.2.2 Target URI

The callback URI "{notifUri}" shall be used. The notification URI is provided in the corresponding subscription creation or update request.

### 6.15.5.2.3 Standard methods


#### 6.15.5.2.3.1 POST

This method shall support the request data structures specified in table 6.15.5.2.3.1-1 and the response data structures and response codes specified in table 6.15.5.2.3.1-2.
