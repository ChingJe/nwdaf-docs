# 5.13 CAPIF_Open_Discover_Service_API


## 5.13.1 Service Description

The CAPIF_Open_Discover_Service_API, as defined in 3GPP TS 23.222 \[2\], service exposed by the CCF enables a service consumer to:

\- request open discovery of the Service API(s) according to a set of filtering criteria.

## 5.13.2 Service Operations


### 5.13.2.1 Introduction

The service operations defined for CAPIF_Open_Discover_Service_API service are shown in table 5.13.2.1-1.

Table 5.13.2.1-1: CAPIF_Open_Discover_Service_API Service Operations

| Service operation name    | Description                                                                                                                                      | Initiated by      |
|---------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------|-------------------|
| Open_Discover_Service_API | This service operation is used by the service consumer to request open discovery of the Service API(s) according to a set of filtering criteria. | e.g., API Invoker |

### 5.13.2.2 Open_Discover_Service_API


#### 5.13.2.2.1 General

This service operation is used by a service consumer to request open discovery of the Service API(s) according to a set of filtering criteria at the CCF.

The following procedures are supported by the "Open_Discover_Service_API" service operation:

\- Open Service API(s) Discovery.

#### 5.13.2.2.2 Open Service API(s) Discovery

In order to request open discovery of the Service API(s), the service consumer shall send an HTTP GET request message to the CCF, targeting the URI of the "Service APIs" Store resource with query parameter(s) containing a set of filtering criteria.

Upon reception of this HTTP GET request message, the CCF shall:

1\. retrieve the stored service API(s) information based on the received query parameter(s), if any;

2\. filter the resulting service API(s) based on service API dissemination information available within "apiInfoDissem" attribute of ServiceAPIDescription data structure;

3\. upon success, respond to the service consumer with an HTTP "200 OK" status code with the response body containing the result of the requested Open Service APIs discovery within the OpenDiscoveryResp data structure;

and

4\. if errors occur when processing the request, respond to the service consumer with an appropriate error status code as defined in clause 8.11.6.
