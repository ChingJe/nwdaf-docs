## 8.4.3.2 Notify_Onboarding_Completion


### 8.4.3.2.1 Description

The Notify_Onboarding_Completion notification is used by the CCF to notify an API Invoker on the on-boarding creation/update result.

### 8.4.3.2.2 Notification definition

The HTTP POST method shall be used for the Notify_Onboarding_Completion and the URI shall be the one provided by the API Invoker during the on-boarding creation/update request.

Callback URI: **{notificationDestination}**

This method shall support the URI query parameters specified in table 8.4.3.2.2-1.

Table 8.4.3.2.2-1: URI query parameters supported by the POST method on this resource
