# 8.2.4.2.15 Type: UsageInfo

Table 8.2.4.2.15-1: Definition of type UsageInfo

| Attribute name | Data type     | P   | Cardinality | Description                                                                                                                                                                                                                            | Applicability |
|----------------|---------------|-----|-------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------|
| usageValue     | UsageValue    | M   | 1           | Contains the service API information usage value.                                                                                                                                                                                      |               |
| targetIds      | array(string) | O   | 1..N        | Contains the identification information of the entity(ies) (e.g., the name(s) of the other API Provider(s), the identifier(s) of the other APF(s)) for which the usage information provided within the "usageValue" attribute applies. |               |
