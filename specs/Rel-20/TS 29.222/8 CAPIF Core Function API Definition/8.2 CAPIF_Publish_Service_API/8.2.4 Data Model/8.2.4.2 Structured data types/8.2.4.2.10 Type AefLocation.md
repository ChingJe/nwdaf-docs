# 8.2.4.2.10 Type: AefLocation

Table 8.2.4.2.10-1: Definition of type AefLocation

| Attribute name                                          | Data type      | P   | Cardinality | Description                                                                               | Applicability |
|---------------------------------------------------------|----------------|-----|-------------|-------------------------------------------------------------------------------------------|---------------|
