# 8.2.4.2.12 Type: ApiStatus

Table 8.2.4.2.12-1: Definition of type ApiStatus

| Attribute name | Data type     | P   | Cardinality | Description                                                                                                                                  | Applicability |
|----------------|---------------|-----|-------------|----------------------------------------------------------------------------------------------------------------------------------------------|---------------|
| aefIds         | array(string) | M   | 0..N        | Indicates the list of AEF ID(s) where the API is active. If an empty array is provided, it indicates that the API is inactive in all AEF(s). |               |
