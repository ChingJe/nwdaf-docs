# 8.3.6 Feature negotiation

The optional features in table 8.3.6-1 are defined for the CAPIF_Events_API. They shall be negotiated using the extensibility mechanism defined in clause 7.8.

<td>Testing of notification connection is supported according to clause 7.6.</td>
