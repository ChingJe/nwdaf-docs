# 7.1.3.2.3 Resource: VAL Service Area Change Subscriptions


## 7.1.3.2.3.1 Description

## 7.1.3.2.3.2 Resource Definition

Resource URI: {**apiRoot**}/**ss-vsac**/\<**apiVersion**\>/**subscriptions**

This resource shall support the resource URI variables defined in table 7.1.3.2.3.2-1.

Table 7.1.3.2.3.2-1: Resource URI variables for this resource

| Name    | Data Type | Definition          |
|---------|-----------|---------------------|
| apiRoot | string    | See clause 7.1.3.1. |

## 7.1.3.2.3.3 Resource Standard Methods


### 7.1.3.2.3.3.1 POST

This method enables a SEAL Server to request the creation of the individual VAL service area change subscription at the LM Server. This method shall support the URI query parameters specified in table 7.1.3.2.3.3.1-1.

Table 7.1.3.2.3.3.1-1: URI query parameters supported by the POST method on this resource

|------|-----------|-----|-------------|-------------|
| Name | Data type | P   | Cardinality | Description |
|      |           |     |             |             |

Table 7.1.3.2.3.3.1-2: Data structures supported by the POST Request Body on this resource
