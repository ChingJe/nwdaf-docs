# 7.1.3.2.4 Resource: Individual VAL Service Area Change Subscription


## 7.1.3.2.4.1 Description

## 7.1.3.2.4.2 Resource Definition

Resource URI: {**apiRoot**}/**ss-vsac**/\<**apiVersion**\>/**subscriptions**/{**subscriptionId**}

This resource shall support the resource URI variables defined in table 7.1.3.2.4.2-1.

Table 7.1.3.2.4.2-1: Resource URI variables for this resource

| Name           | Data Type | Definition                                                                                         |
|----------------|-----------|----------------------------------------------------------------------------------------------------|
| apiRoot        | string    | See clause 7.1.3.1.                                                                                |
| subscriptionId | string    | Represents the identifier of an individual VAL service area change event(s) subscription resource. |
