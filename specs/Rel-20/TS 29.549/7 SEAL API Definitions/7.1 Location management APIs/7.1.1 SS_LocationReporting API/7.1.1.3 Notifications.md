## 7.1.1.3.3 Adaptive Location Configuration Notification


### 7.1.1.3.3.1 Description

The Adaptive Location Configuration Notification is used by the LM Server to notify the suggested adaptive location configuration and request feedback.

### 7.1.1.3.3.2 Target URI

The Callback URI **"{notifUri}**/**configure"** shall be used with the callback URI variables defined in table 7.1.1.3.3.2-1.

Table 7.1.1.3.3.2-1: Callback URI variables

| Name     | Data type | Definition                                                        |
|----------|-----------|-------------------------------------------------------------------|
| notifUri | Uri       | Contains a string formatted as a URI containing the Callback URI. |

### 7.1.1.3.3.3 Standard Methods


#### 7.1.1.3.3.3.1 POST
