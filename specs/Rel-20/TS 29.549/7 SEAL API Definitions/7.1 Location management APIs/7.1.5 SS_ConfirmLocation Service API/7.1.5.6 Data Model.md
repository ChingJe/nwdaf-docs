# 7.1.5.6 Data Model


## 7.1.5.6.1 General

This clause specifies the application data model supported by the API.

Table 7.1.5.6.1-1 specifies the data types defined for the SS_ConfirmLocation API.

Table 7.1.5.6.1-1: SS_ConfirmLocation API specific Data Types

| Data type             | Clause defined | Description                                                                                            | Applicability |
|-----------------------|----------------|--------------------------------------------------------------------------------------------------------|---------------|
| LocConfirmSubsc       | 7.1.5.6.2.2    | Represents a Location Confirmation Service Subscription.                                               |               |
| LocConfirmSubscPatch  | 7.1.5.6.2.3    | Represents the parameters to request the modification of a Location Confirmation Service Subscription. |               |
| LocConfirmUsageNotif  | 7.1.5.6.2.4    | Represents a Location Confirmation Service Usage Notification.                                         |               |
| LocConfirmUsageReport | 7.1.5.6.2.5    | Represents a location confirmation service usage report.                                               |               |

Table 7.1.5.6.1-2 specifies data types re-used by the SS_ConfirmLocation API from other specifications, including a reference to their respective specifications, and when needed, a short description of their use within the SS_ConfirmLocation API.

Table 7.1.5.6.1-2: SS_ConfirmLocation API re-used Data Types

| Data type         | Reference             | Comments                                                                                                      | Applicability |
|-------------------|-----------------------|---------------------------------------------------------------------------------------------------------------|---------------|
| DateTime          | 3GPP TS 29.122 \[3\]  | Represents a date and a time.                                                                                 |               |
| SupportedFeatures | 3GPP TS 29.571 \[21\] | Represents the list of supported feature(s) and used to negotiate the applicability of the optional features. |               |
