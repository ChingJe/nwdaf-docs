## 7.1.5.5.2 Location Confirmation Service Usage Notification


### 7.1.5.5.2.1 Description

The Location Confirmation Service Usage Notification is used by an LM Server to notify a previously subscribed service consumer on location confirmation service usage related event(s).

### 7.1.5.5.2.2 Target URI

The Callback URI **"{notifUri}"** shall be used with the callback URI variables defined in table 7.1.5.5.2.2-1.

Table 7.1.5.5.2.2-1: Callback URI variables

| Name     | Data type | Definition                                                          |
|----------|-----------|---------------------------------------------------------------------|
| notifUri | Uri       | Represents the callback URI encoded as a string formatted as a URI. |

### 7.1.5.5.2.3 Standard Methods


#### 7.1.5.5.2.3.1 POST

This method shall support the request data structures specified in table 7.1.5.5.2.3.1-1 and the response data structures and response codes specified in table 7.1.5.5.2.3.1-2.

Table 7.1.5.5.2.3.1-1: Data structures supported by the POST Request Body

| Data type            | P   | Cardinality | Description                                                      |
|----------------------|-----|-------------|------------------------------------------------------------------|
| LocConfirmUsageNotif | M   | 1           | Represents the Location Confirmation Service Usage Notification. |
