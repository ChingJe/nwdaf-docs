# 7.4.4.6 Data Model


## 7.4.4.6.1 General

This clause specifies the application data model supported by the API. Data types listed in clause 6.2 apply to this API.

Table 7.4.4.6.1-1 specifies the data types defined specifically for the SS_MMetaConnectivityRequirements API service.

**Table 7.4.4.6.1-1: SS_MMetaConnectivityRequirements API specific Data Types**

| **Data type**                 | **Section defined** | **Description**                                                                                | **Applicability** |
|-------------------------------|---------------------|------------------------------------------------------------------------------------------------|-------------------|
| ConnectivityReport            | 7.4.4.6.2.3         | Represents the mobile metaverse connectivity requirements notification.                        |                   |
| ConnectivitySubscription      | 7.4.4.6.2.2         | Represents the mobile metaverse connectivity requirements subscription.                        |                   |
| ConnectivitySubscriptionPatch | 7.4.4.6.2.4         | Used to modify the mobile metaverse connectivity requirements subscription.                    |                   |
| ConnUe                        | 7.4.4.6.2.9         | Represents the selected VAL UE for the established connectivity.                               |                   |
| MMetaCapReqs                  | 7.4.4.6.2.6         | Represents the mobile metaverse capability requirements.                                       |                   |
| MMetaPerfReqs                 | 7.4.4.6.2.5         | Represents the mobile metaverse performance requirements.                                      |                   |
| MMetaSessionInfo              | 7.4.4.6.2.7         | Represents the information about the VAL application session for the established connectivity. |                   |
| MMetaSessionQos               | 7.4.4.6.2.8         | Represent the QoS for the VAL application session for the established connectivity.            |                   |
| MMetaSessionType              | 7.4.4.6.3.3         | Represents the type of the VAL application session for the established connectivity.           |                   |

Table 7.4.4.6.1-2 specifies data types re-used by the SS_MMetaConnectivityRequirements API service.

**Table 7.4.4.6.1-2: Re-used Data Types**

| **Data type**     | **Reference**         | **Comments**                                             | **Applicability** |
|-------------------|-----------------------|----------------------------------------------------------|-------------------|
| ConnInfo          | 3GPP TS 29.548 \[35\] | Represents the data transmission connection information. |                   |
| Float             | 3GPP TS 29.571 \[21\] | Represent the fractional part.                           |                   |
| LocationArea5G    | 3GPP TS 29.122 \[3\]  | Represents location information.                         |                   |
| PacketErrRate     | 3GPP TS 29.571 \[21\] | Used to represent packet error rate.                     |                   |
| SupportedFeatures | 3GPP TS 29.571 \[21\] | Supported features.                                      |                   |
| TimeWindow        | 3GPP TS 29.122 \[3\]  | Represents a time window.                                |                   |
| Uinteger          | 3GPP TS 29.571 \[21\] | Represents an unsigned integer.                          |                   |
| Uri               | 3GPP TS 29.122 \[3\]  | Used to indicate the notification URI.                   |                   |
| ValTargetUe       | Clause 7.3.1.4.2.3    | Indicate either VAL User ID or VAL UE ID.                |                   |

### 7.4.4.6.3.3 Enumeration: MMetaSessionType

The enumeration MMetaSessionType represents the type of the type VAL application session for the established connectivity. It shall comply with the provisions defined in table 7.4.4.6.3.3-1.

**Table 7.4.4.6.3.3-1: Enumeration MMetaSessionType**

| **Enumeration value** | **Description**                                                                                   | **Applicability** |
|-----------------------|---------------------------------------------------------------------------------------------------|-------------------|
| UE_TO_NETWORK         | Identifies the VAL application session for the established connectivity is of type UE to network. |                   |
| UE_TO_UE              | Identifies the VAL application session for the established connectivity is of type UE to UE.      |                   |
