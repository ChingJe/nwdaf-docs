# 7.4.4.1 Introduction

The SS_MMetaConnectivityRequirements Service shall use the SS_MMetaConnectivityRequirements API.

The API URI of the SS_MMetaConnectivityRequirements Service API shall be:

**{apiRoot}/\<apiName\>/\<apiVersion\>**

The request URIs used in HTTP requests shall have the Resource URI structure defined in clause 6.5, i.e.:

**{apiRoot}/\<apiName\>/\<apiVersion\>/\<apiSpecificSuffixes\>**

with the following components:

> \- The {apiRoot} shall be set as described in clause 6.5.
>
> \- The \<apiName\> shall be "ss-mmeta".
>
> \- The \<apiVersion\> shall be "v1".
>
> \- The \<apiSpecificSuffixes\> shall be set as described in clause 7.4.4.3.
