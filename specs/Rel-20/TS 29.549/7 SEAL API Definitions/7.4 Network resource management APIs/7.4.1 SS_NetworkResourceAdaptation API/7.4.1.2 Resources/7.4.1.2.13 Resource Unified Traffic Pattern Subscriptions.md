# 7.4.1.2.13 Resource: Unified Traffic Pattern Subscriptions


## 7.4.1.2.13.1 Description

This resource represents the collection of Unified Traffic Patterns Subscriptions managed by the NRM Server.

## 7.4.1.2.13.2 Resource definition

Resource URI: **{apiRoot}/ss-nra/\<apiVersion\>/unif-traff-subscriptions**

This resource shall support the resource URI variables defined in table 7.4.1.2.13.2-1.

Table 7.4.1.2.13.2-1: Resource URI variables for resource " Unified Traffic Pattern Subscriptions"

|         |           |                 |
|---------|-----------|-----------------|
| Name    | Data type | Definition      |
| apiRoot | string    | See clause 6.5. |
