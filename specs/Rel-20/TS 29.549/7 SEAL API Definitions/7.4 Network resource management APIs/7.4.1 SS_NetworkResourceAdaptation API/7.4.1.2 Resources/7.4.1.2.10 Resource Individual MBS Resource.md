# 7.4.1.2.10 Resource: Individual MBS Resource


## 7.4.1.2.10.1 Description

This resource represents an "Individual MBS Resource" resource managed by the NEF.

## 7.4.1.2.10.2 Resource Definition

Resource URI: **{apiRoot}/ss-nra/\<apiVersion\>/mbs-resources/{mbsResId}**

This resource shall support the resource URI variables defined in table 7.4.1.2.10.2-1.

Table 7.4.1.2.10.2-1: Resource URI variables for this resource

| Name     | Data Type | Definition                                                           |
|----------|-----------|----------------------------------------------------------------------|
| apiRoot  | string    | See clause 6.5.                                                      |
| mbsResId | string    | Represents the identifier of the "Individual MBS Resource" resource. |
