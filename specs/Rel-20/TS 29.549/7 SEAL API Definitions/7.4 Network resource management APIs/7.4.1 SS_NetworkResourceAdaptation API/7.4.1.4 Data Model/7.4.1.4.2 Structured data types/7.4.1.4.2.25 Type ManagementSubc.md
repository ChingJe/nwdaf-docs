# 7.4.1.4.2.25 Type: ManagementSubc

Table 7.4.1.4.2.25-1: Definition of type ManagementSubc

| Attribute name | Data type                       | P   | Cardinality | Description                                                                                                           | Applicability |

| valServId      | string                          | M   | 1           | Identifies a VAL Service.                                                                                             |               |
