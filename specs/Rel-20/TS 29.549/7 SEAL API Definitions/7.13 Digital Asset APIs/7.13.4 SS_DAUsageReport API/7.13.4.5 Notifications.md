## 7.13.4.5.2 DA Usage Report Notification

7.13.4.5.2.1 Description

The DA Usage Report Notification is used by the DA Server to notify a previously subscribed service consumer on DA Usage information report(s).

7.13.4.5.2.2 Target URI

The Callback URI **"{notifUri}"** shall be used with the callback URI variables defined in table 7.13.4.5.2.2-1.

**Table 7.13.4.5.2.2-1: Callback URI variables**

| **Name** | **Definition**                                              |
|----------|-------------------------------------------------------------|
| notifUri | Represents a string formatted as URI with the Callback Uri. |

### 7.13.4.5.2.3 Standard Methods

7.13.4.5.2.3.1 POST

This method shall support the request data structures specified in table 7.13.4.5.2.3.1-1 and the response data structures and response codes specified in table 7.13.4.5.2.3.1-2.

**Table 7.13.4.5.2.3.1-1: Data structures supported by the POST Request Body**

| **Data type**      | **P** | **Cardinality** | **Description**                            |
|--------------------|-------|-----------------|--------------------------------------------|
| DaUsageReportNotif | M     | 1               | Contains the DA Usage Report Notification. |
