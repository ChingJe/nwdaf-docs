# 7.13.4.6 Data Model


## 7.13.4.6.1 General

This clause specifies the application data model supported by the API.

Table 7.13.4.6.1-1 specifies the data types defined for the SS_DAUsageReport API.

**Table 7.13.4.6.1-1: SS_DAUsageReport API specific Data Types**

| **Data type**         | **Clause defined** | **Description**                                                                | **Applicability** |
|-----------------------|--------------------|--------------------------------------------------------------------------------|-------------------|
| AppServInfo           | 7.13.4.6.2.12      | Represents the application service related reporting information.              |                   |
| DaConsumerInfo        | 7.13.4.6.2.5       | Represents the DA Consumer related reporting information.                      |                   |
| DAInfo                | 7.13.4.6.2.9       | Represents the DA(s) related reporting information.                            |                   |
| DaLocationInfo        | 7.13.4.6.2.10      | Represents the DA location related reporting information.                      |                   |
| DaNumAccess           | 7.13.4.6.2.11      | Represents the number of times a particular DA is accessed/used.               |                   |
| DaUsageReportFilters  | 7.13.4.6.2.4       | Represents the DA usage reporting filters.                                     |                   |
| DaUsageReportNotif    | 7.13.4.6.2.7       | Represents the DA Usage Report Notification.                                   |                   |
| DaUsageReportResp     | 7.13.4.6.2.6       | Represents the response to a DA Usage information report(s) retrieval request. |                   |
| DaUsageReportSub      | 7.13.4.6.2.2       | Represents the DA Usage Report Subscription.                                   |                   |
| DaUsageReportSubPatch | 7.13.4.6.2.3       | Represents the requested modifications to a DA Usage Report Subscription.      |                   |
| DaUsgRpt              | 7.13.4.6.2.8       | Represents the DA Usage report.                                                |                   |

Table 7.13.4.6.1-2 specifies data types re-used by the SS_DAUsageReport API from other specifications, including a reference to their respective specifications, and when needed, a short description of their use within the SS_DAUsageReport API.

**Table 7.13.4.6.1-2: SS_DAUsageReport API re-used Data Types**

| **Data type**        | **Reference**         | **Comments**                                                                                                  | **Applicability** |
|----------------------|-----------------------|---------------------------------------------------------------------------------------------------------------|-------------------|
| DaId                 | 7.13.1.6.3.2          | Represents the identifier of the DA.                                                                          |                   |
| DurationSec          | 3GPP TS 29.571 \[21\] | Represents a time duration in unites of seconds.                                                              |                   |
| LocationArea5G       | 3GPP TS 29.122 \[3\]  | Represents the location information.                                                                          |                   |
| ReportingInformation | 3GPP TS 29.523 \[20\] | Represents the reporting requirements.                                                                        |                   |
| SupportedFeatures    | 3GPP TS 29.571 \[21\] | Represents the list of supported feature(s) and used to negotiate the applicability of the optional features. |                   |
| Uinteger             | 3GPP TS 29.571 \[21\] | Represents an unsigned integer.                                                                               |                   |
| Uri                  | 3GPP TS 29.122 \[3\]  | Represents a URI.                                                                                             |                   |
