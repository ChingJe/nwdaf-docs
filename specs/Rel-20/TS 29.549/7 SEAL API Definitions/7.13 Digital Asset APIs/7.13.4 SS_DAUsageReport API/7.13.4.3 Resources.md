# 7.13.4.3 Resources


## 7.13.4.3.1 Overview

This clause describes the structure for the Resource URIs and the resources and methods used for the service.

Figure 7.13.4.3.1-1 depicts the resource URIs structure for the SS_DAUsageReport API.

![](../../../assets/rendered/part2-image42.png)

**Figure 7.13.4.3.1-1: Resource URIs structure of the SS_DAUsageReport API**

Table 7.13.4.3.1-1 provides an overview of the resources and applicable HTTP methods.

Table 7.13.4.3.1-1: Resources and methods overview

| Resource purpose/name                   | Resource URI (relative path after API URI) | HTTP method or custom operation | Description (service operation)                                          |
|-----------------------------------------|--------------------------------------------|---------------------------------|--------------------------------------------------------------------------|
| DA Usage Report Subscriptions           | /subscriptions                             | POST                            | Create a new DA Usage Report Subscription.                               |
| Individual DA Usage Report Subscription | /subscriptions/{subscriptionId}            | GET                             | Retrieve an existing "Individual DA Usage Report Subscription" resource. |
|                                         |                                            | PUT                             | Update an existing "Individual DA Usage Report Subscription" resource.   |
|                                         |                                            | PATCH                           | Modify an existing "Individual DA Usage Report Subscription" resource.   |
|                                         |                                            | DELETE                          | Delete an existing "Individual DA Usage Report Subscription" resource.   |

## 7.13.4.3.2 Resource: DA Usage Report Subscriptions

7.13.4.3.2.1 Description

This resource represents the collection of DA Usage Report Subscription(s) managed by the DA Server.

### 7.13.4.3.2.2 Resource Definition

Resource URI: **{apiRoot}/ss-da-urpt/\<apiVersion\>/subscriptions**

This resource shall support the resource URI variables defined in table 7.13.4.3.2.2-1.

Table 7.13.4.3.2.2-1: Resource URI variables for this resource

| Name    | Data type | Definition          |
|---------|-----------|---------------------|
| apiRoot | string    | See clause 7.13.4.1 |
