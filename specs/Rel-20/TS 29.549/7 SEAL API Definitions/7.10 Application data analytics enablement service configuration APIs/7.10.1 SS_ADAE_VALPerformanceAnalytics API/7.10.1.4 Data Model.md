# 7.10.1.4 Data Model


## 7.10.1.4.1 General

This clause specifies the application data model supported by the API. Data types listed in clause 6.2 apply to this API.

Table 7.10.1.4.1-1 specifies the data types defined specifically for the SS_ADAE_VALPerformanceAnalytics API service.

Table 7.10.1.4.1-1: SS_ADAE_VALPerformanceAnalytics API specific Data Types

| Data type             | Section defined | Description                                                                                       | Applicability |
|-----------------------|-----------------|---------------------------------------------------------------------------------------------------|---------------|
| AnalyticsCategory     | 7.10.1.4.3.3    | Represents the category of analytics.                                                             |               |
| AnalyticsIdVpa        | 7.10.1.4.3.8    | Represents the analytics identifier for VAL performance analytics.                                | ADAE_Ext1     |
| AnalyticsOutput       | 7.10.1.4.2.10   | Represents the VAL performance analytics output.                                                  | ADAE_Ext1     |
| AnalyticsType         | 7.10.1.4.2.6    | Represents the type of analytics.                                                                 |               |
| AppPerfNotif          | 7.10.1.4.2.3    | Notification information of the application performance analytics.                                |               |
| AppPerfSub            | 7.10.1.4.2.2    | Subscription to the VAL application performance analytics                                         |               |
| ClientApplicationData | 7.10.1.4.2.9    | Represents the ADAE client application data.                                                      | ADAE_Ext1     |
| PerfData              | 7.10.1.4.2.7    | Represents the performance data.                                                                  | ADAE_Ext1     |
| PerfThreshold         | 7.10.1.4.2.8    | Represents the performance threshold.                                                             | ADAE_Ext1     |
