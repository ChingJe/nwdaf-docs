# 7.10.8.1 API URI

The SS_AADRF_DataManagement service shall use the SS_AADRF_DataManagement API.

The request URIs used in HTTP requests from the ADAE server towards the A-ADRF shall have the Resource URI structure as defined in clause 6.5 with the following clarifications:

\- The \<apiName\> shall be "ss-aadrf-datamanagement".

\- The \<apiVersion\> shall be "v1".

\- The \<apiSpecificSuffixes\> shall be set as described in clauses 7.10.8.2 and 7.10.8.3.
