# 7.10.12.6 Data Model


## 7.10.12.6.1 General

This clause specifies the application data model supported by the API.

Table 7.10.12.6.1-1 specifies the data types defined for the SS_ADAE_UeRatConnectivityAnalytics API.

Table 7.10.12.6.1-1: SS_ADAE_UeRatConnectivityAnalytics API specific Data Types

| Data type                 | Section defined | Description                                                                             | Applicability |
|---------------------------|-----------------|-----------------------------------------------------------------------------------------|---------------|
| AnalyticsIdUeRat          | 7.10.12.6.3.3   | Represents the analytics ID for UE RAT connectivity.                                    |               |
| AreaPrediction            | 7.10.12.6.2.5   | Represents the RAT type changes for a given way point.                                  |               |
| TimeWindowPrediction      | 7.10.12.6.2.6   | Represents the RAT type changes for a given set of time period(s).                      |               |
| UeRatAnalyticsSub         | 7.10.12.6.2.7   | Represents the UE RAT Connectivity Analytics Subscription related information.          |               |
| UeRatAnalyticsOutput      | 7.10.12.6.2.8   | Represents the UE RAT Connectivity Analytics output information.                        |               |
| UeRatConnectivityNotif    | 7.10.12.6.2.4   | Represents the UE RAT Connectivity Analytics Notification.                              |               |
| UeRatConnectivitySub      | 7.10.12.6.2.2   | Represents the UE RAT Connectivity Analytics Subscription.                              |               |
| UeRatConnectivitySubPatch | 7.10.12.6.2.3   | Represents the requested modifications to a UE RAT Connectivity Analytics Subscription. |               |

Table 7.10.12.6.1-2 specifies data types re-used by the SS_ADAE_UeRatConnectivityAnalytics API from other specifications, including a reference to their respective specifications, and when needed, a short description of their use within the SS_ADAE_UeRatConnectivityAnalytics API.

Table 7.10.12.6.1-2: SS_ADAE_UeRatConnectivityAnalytics API Re-used Data Types

| Data type            | Reference             | Comments                                                                                                      | Applicability |
|----------------------|-----------------------|---------------------------------------------------------------------------------------------------------------|---------------|
| AnalyticsType        | Clause 7.10.1.4.2.6   | Represents the type of analytics.                                                                             |               |
| LocationArea5G       | 3GPP TS 29.122 \[3\]  | Represents the location information.                                                                          |               |
| RatType              | 3GPP TS 29.571 \[21\] | Represents the RAT type.                                                                                      |               |
| ReportingInformation | 3GPP TS 29.523 \[20\] | Represents the reporting requirements information.                                                            |               |
| SupportedFeatures    | 3GPP TS 29.571 \[21\] | Represents the list of supported feature(s) and used to negotiate the applicability of the optional features. |               |
| TimeWindow           | 3GPP TS 29.122 \[3\]  | Represents a time window.                                                                                     |               |
| UeMobility           | 3GPP TS 29.520 \[33\] | Represents the UE Mobility and route information.                                                             |               |
| Uri                  | 3GPP TS 29.122 \[3\]  | Represent a URI.                                                                                              |               |
