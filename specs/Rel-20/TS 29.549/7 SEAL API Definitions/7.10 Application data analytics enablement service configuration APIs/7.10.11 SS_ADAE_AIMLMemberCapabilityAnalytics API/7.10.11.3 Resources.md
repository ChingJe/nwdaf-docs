# 7.10.11.3 Resources


## 7.10.11.3.1 Overview

This clause describes the structure for the Resource URIs and the resources and methods used for the service.

Figure 7.10.11.3.1-1 depicts the resource URIs structure for the SS_ADAE_AIMLMemberCapabilityAnalytics API.

![](../../../assets/rendered/part2-image32.png)

Figure 7.10.11.3.1-1: Resource URI structure of the SS_ADAE_AIMLMemberCapabilityAnalytics API

Table 7.10.11.3.1-1 provides an overview of the resources and applicable HTTP methods.

Table 7.10.11.3.1-1: Resources and methods overview

| Resource name                                            | Resource URI                         | HTTP method or custom operation | Description                                                                                                  |
|----------------------------------------------------------|--------------------------------------|---------------------------------|--------------------------------------------------------------------------------------------------------------|
| AIML Member Capability Analytics Subscriptions           | /application-aimlmcas                | POST                            | Request the creation of AIML Member Capability Analytics Subscription.                                       |
| Individual AIML Member Capability Analytics Subscription | /application-aimlmcas/{appAimlmcaId} | GET                             | Retrieve an existing "Individual AIML Member Capability Analytics Subscription" resource.                    |
|                                                          |                                      | PUT                             | Request the update of an existing "Individual AIML Member Capability Analytics Subscription" resource.       |
|                                                          |                                      | PATCH                           | Request the modification of an existing "Individual AIML Member Capability Analytics Subscription" resource. |
|                                                          |                                      | DELETE                          | Delete an existing "Individual AIML Member Capability Analytics Subscription" resource.                      |

## 7.10.11.3.3 Resource: Individual AIML Member Capability Analytics Subscription


### 7.10.11.3.3.1 Description

The Individual AIML member capability analytics subscription resource represents an individual event subscription of a service consumer to the AIML member capability analytics analytics of the ADAE server.

### 7.10.11.3.3.2 Resource Definition

Resource URI: **{apiRoot}/ss-adae-aimlmca/\<apiVersion\>/application-aimlmcas/{appAimlmcaId}**

This resource shall support the resource URI variables defined in the table 7.10.11.3.3.2-1.

Table 7.10.11.3.3.2-1: Resource URI variables for this resource

| Name         | Data Type | Definition                                   |
|--------------|-----------|----------------------------------------------|
| apiRoot      | string    | See clause 7.10.11.1.                        |
| appAimlmcaId | string    | Identifies an Individual Events Subscription |
