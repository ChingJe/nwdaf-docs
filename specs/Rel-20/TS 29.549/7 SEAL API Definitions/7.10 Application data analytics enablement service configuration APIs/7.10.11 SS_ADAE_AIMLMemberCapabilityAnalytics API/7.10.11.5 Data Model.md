# 7.10.11.5 Data Model


## 7.10.11.5.1 General

This clause specifies the application data model supported by the API.

Table 7.10.11.5.1-1 specifies the data types defined specifically for the SS_ADAE_AIMLMemberCapabilityAnalytics API service.

Table 7.10.11.5.1-1: SS_ADAE_AIMLMemberCapabilityAnalytics API specific Data Types

| Data type                    | Section defined | Description                                                                           | Applicability |
|------------------------------|-----------------|---------------------------------------------------------------------------------------|---------------|
| AimlMemCapability            | 7.10.11.5.2.8   | Represents AIML member capability information in the notification.                    |               |
| AnalyticsOutput              | 7.10.11.5.2.7   | Represents analytics output parameters in the notification.                           |               |
| AppAimlMemCapAnalytics       | 7.10.11.5.3.3   | Represents AIML member capability analytics event.                                    |               |
| AppAimlMemCapAnalyticsOutput | 7.10.11.5.2.6   | Represents analytics output information in the notification.                          |               |
| AppAimlMemCapAnalyticsSub    | 7.10.11.5.2.5   | Represents the information related to the analytics subscription.                     |               |
| AppAimlMemCapAttributes      | 7.10.11.5.3.4   | Represents AIML member capability attributes to be analyzed at the ADAE client.       |               |
| AppAimlMemCapNotif           | 7.10.11.5.2.3   | Represent the AIML member capability analytics notification.                          |               |
| AppAimlMemCapSub             | 7.10.11.5.2.2   | Represents the AIML member capability analytics subscription details.                 |               |
| AppAimlMemCapSubPatch        | 7.10.11.5.2.4   | Represents the AIML member capability analytics analytics subscription patch details. |               |

## 7.10.11.5.3 Simple data types and enumerations


### 7.10.11.5.3.1 Introduction

This clause defines simple data types and enumerations that can be referenced from data structures defined in the previous clauses.

### 7.10.11.5.3.2 Simple data types

The simple data types defined in table 7.10.11.5.3.2-1 shall be supported.

Table 7.10.11.5.3.2-1: Simple data types

|              |                 |                                                 |               |
|--------------|-----------------|-------------------------------------------------|---------------|
| Type Name    | Type Definition | Description                                     | Applicability |
| AimlMemberId | string          | Represents unique identifier of a AIMLE Member. |               |

### 7.10.11.5.3.3 Enumeration: AppAimlMemCapAnalytics

The enumeration AppAimlMemCapAnalytics represents a analytics event. It shall comply with the provisions defined in table 6.1.6.3.3-1.

Table 7.10.11.5.3.3-1: Enumeration AppAimlMemCapAnalytics

| Enumeration value     | Description                                                                                    | Applicability |
|-----------------------|------------------------------------------------------------------------------------------------|---------------|
| APP_MEMBER_CAPABILITY | Indicates that the identifier of the Application layer AIML member capability analytics event. |               |

### 7.10.11.5.3.4 Enumeration: AppAimlMemCapAttributes

The enumeration AppAimlMemCapAttributes represents the AIML member capability attributes to be analyzed at the ADAE client. It shall comply with the provisions defined in table 7.10.11.5.3.4-1.

Table 7.10.11.5.3.4-1: Enumeration AppAimlMemCapAttributes

| Enumeration value        | Description                                                                        | Applicability |
|--------------------------|------------------------------------------------------------------------------------|---------------|
| COMMUNICATION_CAPABILITY | Indicates that the requested attribute to be analyzed is communication capability. |               |
