# 7.10.11.1 Introduction

The SS_ADAE_AIMLMemberCapabilityAnalytics service shall use the SS_ADAE_AIMLMemberCapabilityAnalytics API.

The API URI of the SS_ADAE_AIMLMemberCapabilityAnalytics Service API shall be:

**{apiRoot}/\<apiName\>/\<apiVersion\>**

The request URIs used in HTTP requests shall have the Resource URI structure defined in clause 6.5, i.e.:

**{apiRoot}/\<apiName\>/\<apiVersion\>/\<apiSpecificSuffixes\>**

with the following components:

\- The {apiRoot} shall be set as described in clause 6.5.

\- The \<apiName\> shall be "ss-adae-aimlmca".

\- The \<apiVersion\> shall be "v1".

\- The \<apiSpecificSuffixes\> shall be set as described in clauses 7.10.11.3 and 7.10.11.3A.

NOTE: When 3GPP TS 29.122 \[3\] is referenced for the common protocol and interface aspects for API definition in the clauses under clause 7.10.11, the ADAE Server takes the role of the SCEF and the service consumer takes the role of the SCS/AS.
