# 7.10.4.4 Data Model


## 7.10.4.4.1 General

This clause specifies the application data model supported by the API. Data types listed in clause 6.2 apply to this API.

Table 7.10.4.4.1-1 specifies the data types defined specifically for the SS_ADAE_LocationAccuracyAnalytics API service.

Table 7.10.4.4.1-1: SS_ADAE_LocationAccuracyAnalytics API specific Data Types

| Data type               | Section defined | Description                                                          | Applicability |
|-------------------------|-----------------|----------------------------------------------------------------------|---------------|
| LocAccurAnalytics       | 7.10.4.4.3.3    | Represents the analytics identifier for location accuracy analytics. | ADAE_Ext1     |
| LocAccurAnalyticsOutput | 7.10.4.4.2.4    | Represents the location accuracy analytics output.                   | ADAE_Ext1     |
| LocAccurChange          | 7.10.4.4.3.4    | Represents the type of location accuracy change.                     | ADAE_Ext1     |
| LocAccurPrediction      | 7.10.4.4.2.5    | Represents the location accuracy prediction analytics output.        | ADAE_Ext1     |
| LocAccurSustain         | 7.10.4.4.2.6    | Represents the location accuracy sustainability analytics output.    | ADAE_Ext1     |
| LocAccurNotif           | 7.10.4.4.2.3    | Notification information of the location accuracy analytics event.   |               |
| LocAccurSub             | 7.10.4.4.2.2    | Subscription to the location accuracy analytics event.               |               |

### 7.10.4.4.3.3 Enumeration: LocAccurAnalytics

The enumeration LocAccurAnalytics represents the analytic IDs for location accuracy analytics. It shall comply with the provisions defined in table 7.10.4.4.3.3-1.

Table 7.10.4.4.3.3-1: Enumeration LocAccurAnalytics

| Enumeration value                | Description                                                                 | Applicability |
|----------------------------------|-----------------------------------------------------------------------------|---------------|
| LOCATION_ACCURACY_PREDICTION     | Indicates that the requested analytics is location accuracy prediction.     |               |
| LOCATION_ACCURACY_SUSTAINABILITY | Indicates that the requested analytics is location accuracy sustainability. |               |

### 7.10.4.4.3.4 Enumeration: LocAccurChange

The enumeration LocAccurChange represents the change . It shall comply with the provisions defined in table 7.10.4.4.3.4-1.

Table 7.10.4.4.3.4-1: Enumeration LocAccurChange

| Enumeration value | Description                                       | Applicability |
|-------------------|---------------------------------------------------|---------------|
| DOWNGRADE         | Indicates the downgrade of the location accuracy. |               |
| UPGRADE           | Indicates the upgrade of the location accuracy.   |               |
