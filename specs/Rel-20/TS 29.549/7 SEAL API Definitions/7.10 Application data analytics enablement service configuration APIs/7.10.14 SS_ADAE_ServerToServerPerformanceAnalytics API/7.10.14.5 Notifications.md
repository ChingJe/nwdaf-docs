## 7.10.14.5.2 Server to Server Performance analytics Notification


### 7.10.14.5.2.1 Description

Server to Server Performance Analytics Notification is used by the ADAE Server to notify a previously subscribed service consumer on Server to Server Performance Analytics related event(s).

### 7.10.14.5.2.2 Target URI

The Callback URI **"{notifUri}"** shall be used with the callback URI variables defined in table 7.10.14.5.2.2-1.

Table 7.10.14.5.2.2-1: Callback URI variables

| Name     | Data type | Definition                                                          |
|----------|-----------|---------------------------------------------------------------------|
| notifUri | Uri       | Represents the callback URI encoded as a string formatted as a URI. |

### 7.10.14.5.2.3 Standard Methods

The HTTP POST method shall be used for delivering the Server to Server Performance Analytics Notification.

This method shall support the URI query parameters specified in table 7.10.14.5.2.3-1.

Table 7.10.14.5.2.3-1: URI query parameters supported by the POST method on this resource

| Name | Data type | P   | Cardinality | Description |
|------|-----------|-----|-------------|-------------|
| n/a  |           |     |             |             |

This method shall support the request data structures specified in table 7.10.14.5.2.3-2 and the response data structures and response codes specified in table 7.10.14.5.2.3-3.

Table 7.10.14.5.2.3-2: Data structures supported by the POST Request Body on this resource
