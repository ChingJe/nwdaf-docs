# 7.10.14.6 Data Model


## 7.10.14.6.1 General

This clause specifies the application data model supported by the API. Data types listed in clause 6.2 apply to this API.

Table 7.10.14.6.1-1 specifies the data types defined specifically for the SS_ADAE_Server2ServerPerformanceAnalytics service.

Table 7.10.14.6.1-1: SS_ADAE_Server2ServerPerformanceAnalytics specific Data Types

| Data type            | Clause defined | Description                                                                                      | Applicability |
|----------------------|----------------|--------------------------------------------------------------------------------------------------|---------------|
| S2SPerfAnalyticsData | 7.10.14.6.2.5  | Represents the Server to Server Performance Analytics data.                                      |               |
| S2SPerfNotif         | 7.10.14.6.2.3  | Represents the Server to Server Performance Analytics Notification.                              |               |
| S2SPerfSubsc         | 7.10.14.6.2.2  | Represents the Server to Server Performance Analytics Subscription.                              |               |
| S2SPerfSubscPatch    | 7.10.14.6.2.4  | Represents the requested modifications to a Server to Server Performance Analytics Subscription. |               |
| AnalyticsIdSspa      | 7.10.14.6.3.3  | Represents the Analytics ID for Server to Server Performance Analytics.                          |               |
| ServerInfo           | 7.10.14.6.2.6  | Represents the Server Information.                                                               |               |

Table 7.10.14.6.1-2 specifies data types re-used by the SS_ADAE_Server2ServerPerformanceAnalytics service:

Table 7.10.14.6.1-2: Re-used Data Types

| Data type            | Reference             | Comments                                                                                                      | Applicability |
|----------------------|-----------------------|---------------------------------------------------------------------------------------------------------------|---------------|
| AnalyticsType        | Clause 7.10.1.4.2.6   | Represents the type of the analytics.                                                                         |               |
| IpAddr               | 3GPP TS 29.571 \[8\]  | Represents an IP Address.                                                                                     |               |
| LocationArea5G       | 3GPP TS 29.122 \[3\]  | Represents location information.                                                                              |               |
| ReportingInformation | 3GPP TS 29.523 \[20\] | Indicates the reporting requirements.                                                                         |               |
| SupportedFeatures    | 3GPP TS 29.571 \[21\] | Represents the list of supported feature(s) and used to negotiate the applicability of the optional features. |               |
| TimeWindow           | 3GPP TS 29.122 \[3\]  | Indicate the time window.                                                                                     |               |
| U2UAnalyticsData     | 7.10.3.4.2.6          | Represents the UE-to-UE analytics data.                                                                       |               |
| Uri                  | 3GPP TS 29.122 \[3\]  | Indicates a URI.                                                                                              |               |
