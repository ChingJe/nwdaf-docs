# 7.10.14.3 Resources

7.10.14.3.1 Overview

This clause describes the structure for the Resource URIs and the resources and methods used for the service.

Figure 7.10.14.3.1-1 depicts the resource URIs structure for the SS_ADAE_ServerToServerPerformanceAnalytics.

![](../../../assets/rendered/part2-image35.png)

**Figure 7.10.14.3.1-1: Resource URI structure of the SS_ADAE_ServerToServerPerformanceAnalytics**

Table 7.10.14.3.1-1 provides an overview of the resources and applicable HTTP methods.

**Table 7.10.14.3.1-1: Resources and methods overview**

| **Resource name**                                              | **Resource URI**                | **HTTP method** | **Description**                                                                         |
|----------------------------------------------------------------|---------------------------------|-----------------|-----------------------------------------------------------------------------------------|

| Individual Server to Server Performance Analytics Subscription | /subscriptions/{subscriptionId} | GET             | Retrieve the "Individual Server to Server Performance Analytics Subscription" resource. |
|                                                                |                                 | PUT             | Update the "Individual Server to Server Performance Analytics Subscription" resource.   |
|                                                                |                                 | PATCH           | Modify the "Individual Server to Server Performance Analytics Subscription" resource.   |
|                                                                |                                 | DELETE          | Delete the "Individual Server to Server Performance Analytics Subscription" resource.   |

## 7.10.14.3.2 Resource: Server to Server Performance Analytics Subscriptions


### 7.10.14.3.2.1 Description

The "Server to Server Performance Analytics Subscriptions" resource collection represents Server to Server Performance analytics subscriptions.

7.10.14.3.2.2 Resource Definition

Resource URI: **{apiRoot}/ss-adae-stspa/\<apiVersion\>/subscriptions**

This resource shall support the resource URI variables defined in the table 7.10.14.3.2.2-1.

**Table 7.10.14.3.2.2-1: Resource URI variables for this resource**

| **Name** | **Data Type** | **Definition**        |
|----------|---------------|-----------------------|
| apiRoot  | string        | See clause 7.10.14.1. |
