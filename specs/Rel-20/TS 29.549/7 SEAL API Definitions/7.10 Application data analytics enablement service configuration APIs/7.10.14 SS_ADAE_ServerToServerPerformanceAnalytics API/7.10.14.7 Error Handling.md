# 7.10.14.7 Error Handling


## 7.10.14.7.1 General

For the SS_ADAE_Server2ServerPerformanceAnalytics API, error handling shall be supported as specified in clause 6.7.

In addition, the requirements in the following clauses are applicable for the SS_ADAE_Server2ServerPerformanceAnalytics API.
