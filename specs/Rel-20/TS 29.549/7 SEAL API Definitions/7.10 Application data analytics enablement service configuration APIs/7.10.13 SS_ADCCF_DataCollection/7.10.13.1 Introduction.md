# 7.10.13.1 Introduction

The A-DCCF Data Collection service shall use the SS_ADCCF_DataCollection API.

The API URI of the SS_ADCCF_DataCollection API shall be:

**{apiRoot}/\<apiName\>/\<apiVersion\>**

The request URIs used in HTTP requests shall have the Resource URI structure defined in clause 6.5, i.e.:

**{apiRoot}/\<apiName\>/\<apiVersion\>/\<apiSpecificSuffixes\>**

with the following components:

\- The {apiRoot} shall be set as described in clause 6.5.

\- The \<apiName\> shall be "ss-adccf-dc".

\- The \<apiVersion\> shall be "v1".

\- The \<apiSpecificSuffixes\> shall be set as described in clause 7.10.13.3.

NOTE: When 3GPP TS 29.122 \[3\] is referenced for the common protocol and interface aspects for API definition in the clauses under clause 7.10.13, the A-DCCF takes the role of the SCEF and the service consumer takes the role of the SCS/AS.
