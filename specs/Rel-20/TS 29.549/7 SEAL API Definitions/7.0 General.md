# 7.0 General

The following clauses specify the API definition of the SEAL Service APIs.

NOTE: When used to denote the service consumer of the service APIs in the provisions documented in the clauses under clause 7, the "VAL Server" is just one example service consumer of these SEAL service APIs and does not preclude other potential service consumers as per the SEAL architecture and if permitted by the SEAL service provider’s policy.
