# 1 Scope

The present specification describes the stage 3 APIs for the Service Enabler Architecture Layer for Verticals (SEAL). The related stage 2 architecture, functional requirements and information flows are specified in 3GPP TS 23.434 \[2\], 3GPP TS 23.433 \[34\] (for SEAL Data Delivery), 3GPP TS 23.435 \[41\] (for NSCE), 3GPP TS 23.436 \[38\] (for ADAE), 3GPP TS 23.437 \[45\] (for SM and SAn), 3GPP TS 23.438 \[46\] (for DA management) and 3GPP TS 23.482 \[47\] (for AIMLE).
