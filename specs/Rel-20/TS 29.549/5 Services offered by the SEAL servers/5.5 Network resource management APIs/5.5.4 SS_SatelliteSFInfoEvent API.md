# 5.5.4 SS_SatelliteSFInfoEvent API

The SS_SatelliteSFInfoEvent API, as defined in 3GPP TS 23.434 \[2\], allows a VAL Server via the NRM-S reference point to subscribe and receive notifications from the NRM Server on Satellite S&F related event(s). The SS_SatelliteSFInfoEvent API supports this via the "NRM_SAT_SF_INFO" event of the SS_Events API as specified in clause 7.5.
