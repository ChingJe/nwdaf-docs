# 5.5.1.1 Service Description


## 5.5.1.1.1 Overview

The SS_NetworkResourceAdaptation API, as defined 3GPP TS 23.434 \[2\], allows a service consumer to communicate with the network resource management server for network resource adaptation including reserving network resource, requesting and subscribing for unicast and multicast/broadcast resources.
