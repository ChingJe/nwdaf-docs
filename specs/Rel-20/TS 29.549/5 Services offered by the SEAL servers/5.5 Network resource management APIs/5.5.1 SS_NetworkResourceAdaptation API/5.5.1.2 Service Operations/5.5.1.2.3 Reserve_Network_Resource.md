# 5.5.1.2.3 Reserve_Network_Resource


## 5.5.1.2.3.1 General

This service operation is used by a service consumer to request for network resource.

## 5.5.1.2.3.2 Service consumer requesting for network resource adaptation using Reserve_Network_Resource service operation

The service consumer shall send a HTTP POST message to the NRM server. The body of the POST message shall include VAL user or UE information and the VAL service requirement. Upon receiving HTTP POST message, the NRM server shall

1\. verify the identity of the service consumer and check if the service consumer is authorized to request for unicast resource;

2\. if the service consumer is authorized, the NRM server evaluates the need for network resources and use of resource sharing;

3\. for the VAL user or UE, the NRM server initiates interaction via SIP core;

4\. the NRM server creates a unicast subscription as specified in clause 7.4.1.2.4.3.1; and

5\. the NRM server provides result in the response message.
