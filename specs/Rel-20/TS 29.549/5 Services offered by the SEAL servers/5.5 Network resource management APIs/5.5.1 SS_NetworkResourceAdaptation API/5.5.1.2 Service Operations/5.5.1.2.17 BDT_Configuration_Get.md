# 5.5.1.2.17 BDT_Configuration_Get


## 5.5.1.2.17.1 General

This service operation is used by a service consumer to request the retrieval of an existing "Individual BDT Policy Configuration" resource at the NRM Server.

## 5.5.1.2.17.2 Retreivel of an individual background data transfer policy configuration using the BDT_Configuration_Get service operation

In order to retrieve an individual background data transfer policy configuration resource, the service consumer shall send an HTTP GET request message targeting the URI of the corresponding "Individual BDT Policy Configuration" resource.

Upon reception of the HTTP GET request message, the NRM server shall:

\- verify whether the service consumer is authorized to retrieve the BDT policy configuration information;

\- if the service consumer is authorized to fetch the BDT policy configuration information, the NRM server shall;

\- responds to the service consumer with an HTTP "200 OK" status code with the response body including the requested BDT policy configuration within the BdtPolConfig data structure.
