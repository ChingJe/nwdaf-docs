# 5.11.9 SS_ADAE_LocationRelatedUeGroupAnalytics API


## 5.11.9.1 Service Description

The SS_ADAE_LocationRelatedUeGroupAnalytics API, as defined 3GPP TS 23.436 \[38\], enables a service consumer to:

\- create/update/delete a Location-Related UE Group Analytics Subscription; and

\- receive Location-Related UE Group Analytics Subscription related event(s) notifications.

## 5.11.9.2 Service Operations


### 5.11.9.2.1 Introduction

The service operations defined for the SS_ADAE_LocationRelatedUeGroupAnalytics are shown in the table 5.11.9.2.1-1.

Table 5.11.9.2.1-1: Operations of the SS_ADAE_LocationRelatedUeGroupAnalytics

|                                                   |                                                                                                                                                                            |                 |
|---------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------|
| Service operation name                            | Description                                                                                                                                                                | Initiated by    |
| SS_ADAE_LocationRelatedUeGroupAnalytics_Subscribe | This service operation is used by the service consumer to create/update/delete a Location-Related UE Group Analytics Subscription.                                         | e.g., LM Server |
| SS_ADAE_LocationRelatedUeGroupAnalytics_Notify    | This service operation is used by the ADAE Server to notify a previously subscribed service consumer on Location-Related UE Group Analytics Subscription related event(s). | ADAE Server     |

### 5.11.9.2.2 SS_ADAE_LocationRelatedUeGroupAnalytics_Subscribe


#### 5.11.9.2.2.1 General

This service operation is used by a service consumer to request the creation of a Location-Related UE Group Analytics Subscription at the ADAE Server.

The following procedures are supported by the "SS_ADAE_LocationRelatedUeGroupAnalytics_Subscribe" service operation:

\- Location-Related UE Group Analytics Subscription Creation.

\- Location-Related UE Group Analytics Subscription Update.

\- Location-Related UE Group Analytics Subscription Deletion.

#### 5.11.9.2.2.2 Location-Related UE Group Analytics Subscription Creation

To subscribe to location-related UE group analytics related event(s) reporting, the service consumer shall send an HTTP POST message to the ADAES targeting the URI of the "Location-Related UE Group Analytics Subscriptions" collection resource, with the request body containing the LocRelUeGroupSub data structure as defined in clause 7.10.9.4.2.2.

Upon reception of the HTTP POST request message, the ADAE Server shall:

\- verify the identity of the service consumer and determine if the service consumer is authorized to subscribe to location-related UE group analytics related event(s) reporting; and

\- if the service consumer is authorized and upon successful processing of the request, the ADAE Server shall respond with an HTTP "201 Created" status code with the response body including a representation of the created "Individual Location-Related UE Group Analytics Subscription" resource within the LocRelUeGroupSub data structure, and an HTTP Location header field containing the URI for the created resource;

On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the HTTP POST response body, as specified in clause 7.10.9.7.

#### 5.11.9.2.2.3 Location-Related UE Group Analytics Subscription Deletion

To unsubscribe from location-related UE group analytics related event(s) reporting, the service consumer shall send an HTTP DELETE request targeting the URI of the correseponding "Individual Location-Related UE Group Analytics Subscription" resource.

Upon reception of the HTTP DELETE request, the ADAE Server shall:

\- verify the identity of the service consumer and check if the service consumer is authorised to terminate the targeted "Individual Location-Related UE Group Analytics Subscription" resource;

\- if the service consumer is authorized and upon successful processing of the request, the ADAE Server shall delete the corresponding subscription and respond with an HTTP "204 No Content" status code.

On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the HTTP DELETE response body, as specified in clause 7.10.9.7.

#### 5.11.9.2.2.4 Location-Related UE Group Analytics Subscription Update

In order to request the update of an existing location-related UE group analytics subscription, the service consumer shall send an HTTP PUT/PATCH request to the ADAE Server, targeting the corresponding "Individual Location-Related UE Group Analytics Subscription" resource, with the request body including either:

\- the updated representation of the resource within the LocRelUeGroupSub data structure, in case the HTTP PUT method is used; or

\- the requested modifications to the resource within the LocRelUeGroupSubPatch data structure, in case the HTTP PATCH method is used.

Upon reception of the HTTP DELETE request, the ADAES Server shall:

\- verify the identity of the service consumer and check if the service consumer is authorised to update the targeted "Individual Location-Related UE Group Analytics Subscription" resource;

\- if the service consumer is authorized and upon successful processing of the request, update the targeted "Individual Location-Related UE Group Analytics Subscription" resource accordingly and respond with either:

\- an HTTP "200 OK" status code with the response body containing a representation of the updated "Individual Location-Related UE Group Analytics Subscription" resource within the LocRelUeGroupSub data structure; or

\- an HTTP "204 No Content" status code.

On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the HTTP PUT/PATCH response body, as specified in clause 7.10.9.7.

### 5.11.9.2.3 SS_ADAE_LocationRelatedUeGroupAnalytics_Notify


#### 5.11.9.2.3.1 General

This service operation is used by the ADAE Server to notify on Location-Related UE Group Analytics related event(s).

The following procedures are supported by the "SS_ADAE_LocationRelatedUeGroupAnalytics_Notify" service operation:

\- Location-Related UE Group Analytics Event Notification.

#### 5.11.9.2.3.2 Location-Related UE Group Analytics Event Notification

To notify on location-related UE group analytics related event(s), the ADAE Server shall send an HTTP POST request to the service consumer with the request URI set to "{notifUri}", where the "notifUri" variable is set to the value received from the service consumer during the creation of the corresponding Location-Related UE Group Analytics Subscription using the procedures defined in clauses 5.11.9.2.2, and the request body containing the LocRelUeGroupNotif data structure as defined in clause 7.10.9.4.2.3.

Upon success, the service consumer shall respond to the ADAE Server with an HTTP "204 No Content" status code to acknowledge the reception of the notification.

On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the HTTP POST response body, as specified in clause 7.10.9.7.
