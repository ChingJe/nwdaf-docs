# 5.11.13 SS_ADAE_ServerToServerPerformanceAnalytics API


## 5.11.13.1 Service Description

The SS_ADAE_ServerToServerPerformanceAnalytics API enables a service consumer to:

\- create/update/delete a Server to Server Performance Analytics Subscription (see also clause 8.13 of 3GPP TS 23.436 \[38\]); and

\- receive Server to Server Performance Analytics Subscription related event(s) reporting (see also clause 8.13 of 3GPP TS 23.436 \[38\]).

## 5.11.13.2 Service Operations


### 5.11.13.2.1 Introduction

The service operations defined for the SS_ADAE_ServerToServerPerformanceAnalytics API are shown in the table 5.11.13.2.1-1.

Table 5.11.13.2.1-1: SS_ADAE_ServerToServerPerformanceAnalytics Service Operations

|                                                      |                                                                                                                                     |                 |
|------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------|-----------------|
| Service operation name                               | Description                                                                                                                         | Initiated by    |
| SS_ADAE_ServerToServerPerformanceAnalytics_Subscribe | This service operation is used by the service consumer to create/update/delete Server to Server Performance Analytics Subscription. | VAL server, EES |
| SS_ADAE_ServerToServerPerformanceAnalytics_Notify    | This service operation is used by the ADAE Server to notify about the subscribed Server to Server Performance Analytics event(s).   | ADAE Server     |

### 5.11.13.2.2 Subscribe


#### 5.11.13.2.2.1 General

This service operation is used by a service consumer to request the creation of a Server to Server Performance Analytics Subscription at the ADAE Server.

The following procedures are supported by the "SS_ADAE_ServerToServerPerformanceAnalytics_Subscribe" service operation:

\- Server to Server Performance Analytics Subscription Creation.

\- Server to Server Performance Analytics Subscription Update.

\- Server to Server Performance Analytics Subscription Deletion.

#### 5.11.13.2.2.2 Server to Server Performance Analytics Subscription Creation

To subscribe to Server to Server Performance analytics, the service consumer shall send an HTTP POST message to the ADAES targeting the URI of the "Server to Server Performance analytics Subscriptions" collection resource, with the request body containing the S2SPerfSubsc data structure as defined in clause 7.10.14.6.2.2.

Upon reception of the HTTP POST request message, the ADAE Server shall:

1\. verify the identity of the service consumer and determine if the service consumer is authorized to subscribe to Server to Server Performance Analytics event(s) reporting; and

2\. if the service consumer is authorized and upon successful processing of the request, the ADAES shall create a new "Individual Server to Server Performance analytics Subscription" resource and respond to the service consumer with an HTTP "201 Created" status code, including a Location header field containing the URI for the created resource and the response body including the S2SPerfSubsc data structure containing a representation of the created resource.

On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the HTTP POST response body, as specified in clause 7.10.14.7.

#### 5.11.13.2.2.3 Server to Server Performance Analytics Subscription Update

In order to request the update of an existing Server to Server Performance analytics subscription, the service consumer shall send an HTTP PUT/PATCH request to the ADAE Server, targeting the corresponding "Individual Server to Server Performance Analytics Subscription" resource, with the request body including either:

\- the updated representation of the resource within the S2SPerfSubsc data structure as defined in clause 7.10.14.6.2.2, in case the HTTP PUT method is used; or

\- the requested modifications to the resource within the S2SPerfSubscPatch data structure as defined in clause 7.10.14.6.2.4, in case the HTTP PATCH method is used.

Upon reception of the HTTP PUT/PATCH request message, the ADAE Server shall:

1\. verify the identity of the service consumer and determine if the service consumer is authorized to updated the targeted "Individual Server to Server Performance Analytics Subscription" resource; and

2\. if the service consumer is authorized and upon successful processing of the request, the ADAES Server shall update the targeted "Individual Server to Server Performance analytics Subscription" resource accordingly and respond with either:

\- an HTTP "200 OK" status code with the response body containing a representation of the updated "Individual Server to Server Performance analytics Subscription" resource within the S2SPerfSubsc data structure; or

\- an HTTP "204 No Content" status code.

On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the HTTP PUT/PATCH response body, as specified in clause 7.10.14.7.

#### 5.11.13.2.2.4 Server to Server Performance Analytics Subscription Deletion

To unsubscribe from Server to Server Performance Analytics event(s) reporting, the service consumer shall send an HTTP DELETE request targeting the URI of the corresponding "Individual Server to Server Performance Analytics Subscription" resource.

Upon reception of the HTTP DELETE request, the ADAE Server shall:

1\. verify the identity of the service consumer and check if service consumer is authorised to terminate the targeted "Individual Server to Server Performance Analytics Subscription" resource; and

2\. if the service consumer is authorized, the ADAE Server shall delete the corresponding subscription and respond with an HTTP "204 No Content" status code.

On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the HTTP DELETE response body, as specified in clause 7.10.14.7.

### 5.11.13.2.3 Notify


#### 5.11.13.2.3.1 General

This service operation is used by the ADAE Server to notify Server to Server Performance Analytics event(s).

The following procedures are supported by the "SS_ADAE_ServerToServerPerformanceAnalytics_Notify" service operation:

\- Server to Server Performance Analytics Event Notification.

#### 5.11.13.2.3.2 Server to Server Performance Analytics Event Notification

To notify on Server to Server Performance Analytics Event(s), the ADAE Server shall send an HTTP POST request to the service consumer targeting the notification URI that was received during the creation/update of the corresponding subscription as defined in clauses 5.11.13.2.2.2 and 5.11.13.2.2.3, with the request body containing the S2SPerfNotif data structure as defined in clause 7.10.14.6.2.3.

Upon reception of the HTTP POST request message, the service consumer shall process the Server to Server Performance Analytics Notification, and in case of success, respond with an HTTP "204 No Content" status code.

On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the HTTP POST response body, as specified in clause 7.10.14.7.
