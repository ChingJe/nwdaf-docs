# 8.8.4.22 ACT status subscription response

Table 8.8.4.22-1 describes the information elements for the ACT status subscription response from EES to EAS.

> Table 8.8.4.22-1: ACT status subscription response

|                     |        |                                            |
|---------------------|--------|--------------------------------------------|
| Information element | Status | Description                                |
| Successful response | O      | Indicates that the request was successful. |
| \> Subscription ID  | O      | Identifier of the subscription             |
| Failure response    | O      | Indicates that the request failed          |
| \> Cause            | O      | Indicates the cause of request failure     |
