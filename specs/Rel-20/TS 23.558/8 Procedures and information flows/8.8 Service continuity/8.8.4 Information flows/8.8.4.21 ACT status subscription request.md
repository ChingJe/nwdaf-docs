# 8.8.4.21 ACT status subscription request

Table 8.8.4.21-1 describes the information elements for the ACT status subscription request from EAS to EES.

> Table 8.8.4.21-1: ACT status subscription request

|                             |        |                                                                                        |
|-----------------------------|--------|----------------------------------------------------------------------------------------|
| Information element         | Status | Description                                                                            |
| EASID                       | M      | The identifier of the EAS providing the update                                         |
| Security credentials        | M      | Security credentials of the EAS                                                        |
| Notification Target Address | M      | Notification Target Address of the EAS where the notification is to be sent by the EES |
