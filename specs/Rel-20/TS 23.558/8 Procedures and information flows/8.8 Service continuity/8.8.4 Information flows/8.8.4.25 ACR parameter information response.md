# 8.8.4.25 ACR parameter information response

Table 8.8.4.25-1 describes information elements for the ACR parameter information response sent from the T-EES to the S-EES or CES.

Table 8.8.4.25-1: ACR parameter information response

|                                                         |        |                                                                      |
|---------------------------------------------------------|--------|----------------------------------------------------------------------|
| Information element                                     | Status | Description                                                          |
| Successful response (NOTE)                              | O      | Indicates that the ACR parameter information request was successful. |
| Failure response (NOTE)                                 | O      | Indicates that the ACR parameter information request failed.         |
| \> Cause                                                | O      | Indicates the cause of ACR parameter information request failure     |
| NOTE: One of these IEs shall be present in the message. |        |                                                                      |
