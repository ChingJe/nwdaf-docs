# 8.8.4.23 ACT status notification

Table 8.8.4.23-1 describes the information elements for an ACT status notification from the EES to the EAS.

> Table 8.8.4.23-1: ACT status notification

|                     |        |                                                                                             |
|---------------------|--------|---------------------------------------------------------------------------------------------|
| Information element | Status | Description                                                                                 |
| Subscription ID     | M      | Subscription identifier corresponding to the subscription stored in the EES for the request |
| ACT status          | M      | Status of the ACT between S-EES and the T-EES                                               |
