# 8.8.4.24 ACR parameter information request

Table 8.8.4.24-1 describes information elements for the ACR parameter information request sent from the S-EES or CES to the T-EES.

Table 8.8.4.24-1: ACR parameter information request

|                                                 |        |                                                                                                          |
|-------------------------------------------------|--------|----------------------------------------------------------------------------------------------------------|
| Information element                             | Status | Description                                                                                              |
| EES ID                                          | M      | Unique identifier of the requesting S-EES or CES.                                                        |
| EECID (NOTE 1)                                  | M      | Unique identifier of the EEC.                                                                            |
| ACID (NOTE 1)                                   | M      | The identifier of the AC.                                                                                |
| S-EAS Endpoint (NOTE 1)                         | M      | Endpoint information (e.g. URI, FQDN, IP 3-tuple) of the S-EAS or CAS.                                   |
| T-EAS Endpoint (NOTE 1)                         | M      | Endpoint information (e.g. URI, FQDN, IP 3-tuple) of the T-EAS.                                          |
| ACR parameters                                  | M      | ACR parameters                                                                                           |
| \> Prediction expiration time                   | O      | The estimated time the UE may reach the Predicted/Expected UE location or EAS service area at the latest |
| NOTE 1: These IEs are used to identify the ACR. |        |                                                                                                          |
