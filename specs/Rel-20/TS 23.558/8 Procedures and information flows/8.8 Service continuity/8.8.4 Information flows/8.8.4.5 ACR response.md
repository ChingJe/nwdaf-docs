# 8.8.4.5 ACR response

Table 8.8.4.5-1 describes the information elements for the ACR response sent either from the S-EES to the EEC or S-EAS, or by the T-EES to the EEC. In the EAS bundle case, the ACR response is sent by the associated S-EES(s) to the main S-EES.

Table 8.8.4.5-1: ACR response

|                                                         |        |                                                |
|---------------------------------------------------------|--------|------------------------------------------------|
| Information element                                     | Status | Description                                    |
| Successful response (NOTE)                              | O      | Indicates that the ACR request was successful. |
| Failure response (NOTE)                                 | O      | Indicates that the ACR request failed.         |
| \> Cause                                                | O      | Indicates the cause of ACR request failure     |
| NOTE: One of these IEs shall be present in the message. |        |                                                |
