# 8.8.4.16 EELManagedACR service response

Table 8.8.4.16-1 describes information elements for the EELManagedACR service response from the Edge Enabler Server to the Edge Application Server.

Table 8.8.4.16-1: EELManagedACR service response

| Information element                                                                                                                                | Status | Description                                                                         |
|----------------------------------------------------------------------------------------------------------------------------------------------------|--------|-------------------------------------------------------------------------------------|
| Successful response                                                                                                                                | O      | Indicates that the ACR request was successful.                                      |
| \> Address for Application Context storage (NOTE)                                                                                                  | O      | The address information from where the Application Context can be accessed for ACT. |
| Failure response                                                                                                                                   | O      | Indicates that the EELManagedACR request failed.                                    |
| \> Cause                                                                                                                                           | O      | Indicates the cause of request failure                                              |
| NOTE: This IE is included if "Address for Application Context storage" IE as specified in Table 8.8.4.15-1 is not included in ACR service request. |        |                                                                                     |
