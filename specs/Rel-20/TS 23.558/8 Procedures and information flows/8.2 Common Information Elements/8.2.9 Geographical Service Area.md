# 8.2.9 Geographical Service Area

The following formats may be used for expressing a Geographical Service Area:

Table 8.2.9-1: Geographical Service Area

| Information element           | Status | Description                                                                                            |
|-------------------------------|--------|--------------------------------------------------------------------------------------------------------|
| Geographical Area Description | O      | A shape defined in 3GPP TS 23.032 \[21\]                                                               |
| Civic Location                | O      | An area identified by a civic location element, e.g. building, park, arena, civic address or ZIP code. |
