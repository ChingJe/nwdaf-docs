# 8.2.11 Application Group profile

An Application Group profile includes information about the Application Group used to determine common EAS.

Table 8.2.11-1: Application Group profile

|                                           |        |                                                                                                                                                                                                            |
|-------------------------------------------|--------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Information element                       | Status | Description                                                                                                                                                                                                |
| Application Group ID                      | M      | Application group identifier as defined in 7.2.11.                                                                                                                                                         |
| E2E response time                         | O      | The response time required for E2E communication between ACs on two UEs via EAS(s).                                                                                                                        |
| EAS ID                                    | M      | Identifier of EAS                                                                                                                                                                                          |
| Expected Group Geographical Service Area. | O      | The expected location(s) (e.g. route) of the group of UEs during the AC's operation schedule. This geographic information can express a geographic point, polygon, route, signalling map, or waypoint set. |
