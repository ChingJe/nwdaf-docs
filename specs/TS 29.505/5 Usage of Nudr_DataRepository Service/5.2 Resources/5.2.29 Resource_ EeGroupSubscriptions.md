# 5.2.29 Resource: EeGroupSubscriptions

## 5.2.29.1 Description

This resource represents the collection of EE Subscriptions for a group of UEs or any UE (i.e. all UEs).

This resource is modelled with the Collection resource archetype (see clause C.1 of 3GPP TS 29.501 \[7\]).

## 5.2.29.2 Resource Definition

Resource URI: {apiRoot}/nudr-dr/\<apiVersion\>/subscription-data/group-data/{ueGroupId}/ee-subscriptions
