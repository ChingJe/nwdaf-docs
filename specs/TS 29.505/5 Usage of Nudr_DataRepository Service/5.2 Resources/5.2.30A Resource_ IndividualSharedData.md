# 5.2.30A Resource: IndividualSharedData

## 5.2.30A.1 Description

This resource represents the individual shared data.

## 5.2.30A.2 Resource Definition

Resource URI: {apiRoot}/nudr-dr/\<apiVersion\>/subscription-data/shared-data/{sharedDataId}

This resource shall support the resource URI variables defined in table 5.2.30A.2-1.

Table 5.2.30A.2-1: Resource URI variables for this resource

| Name         | Definition                                      |
|--------------|-------------------------------------------------|
| apiRoot      | See 3GPP TS 29.504 \[2\] clause 6.1.1           |
| sharedDataId | Contains the individual Shared Data Identifier. |
