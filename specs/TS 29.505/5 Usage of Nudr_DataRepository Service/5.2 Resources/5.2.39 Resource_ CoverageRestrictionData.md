# 5.2.39 Resource: CoverageRestrictionData

## 5.2.39.1 Description

This resource represents UE's subscribed enhanced Coverage Restriction Data for a UE identifier. It is queried by the UDM during Enhanced Coverage Restriction Data Retrieval.

This resource is modelled with the Document resource archetype (see clause C.1 of 3GPP TS 29.501 \[7\]).

## 5.2.39.2 Resource Definition

Resource URI: {apiRoot}/nudr-dr/\<apiVersion\>/subscription-data/{ueId}/coverage-restriction-data
