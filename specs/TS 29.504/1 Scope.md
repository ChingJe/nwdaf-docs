# 1 Scope

The present document specifies the stage 3 protocol and high level data model for the Nudr Service Based Interface. It provides stage 3 protocol definitions and message flows, and specifies the API for each service offered by the Unified Data Repository (UDR). The data model and usage of the subscription data is specified in TS 29.505 \[2\], and the data model and usage of the policy data, structured data for exposure and application data are specified in TS 29.519 \[3\].

The 5G System architecture is specified in TS 23.501 \[4\]. The stage 2 definition and related procedures for Nudr SBI service are specified in TS 23.502 \[5\] and TS 23.503 \[6\].

The Technical Realization of the Service Based Architecture is specified in TS 29.500 \[7\] and the Principles and Guidelines for Services Definition is specified in TS 29.501 \[8\].
