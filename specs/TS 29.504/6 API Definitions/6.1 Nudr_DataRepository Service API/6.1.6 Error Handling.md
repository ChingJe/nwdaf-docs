The "ProblemDetails" data structure may contain a "cause" attribute to indicate the application error, see TS 29.571 \[10\]. The values for "cause" attribute are defined in table 6.1.6-2.

|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
