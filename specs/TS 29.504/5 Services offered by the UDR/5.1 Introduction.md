# 5.1 Introduction

The UDR offers the following services via the Nudr interface:

\- Nudr_DataRepository Service

NOTE: This service corresponds to the Nudr_DataManagement service in TS 23.501 \[4\], TS 23.502 \[5\] and TS 23.503 \[6\].

\- Nudr_GroupIDmap Service

Table 5.1-1 summarizes the corresponding APIs defined for this specification.

Table 5.1-1: API Descriptions

|---------------------|--------|-----------------------------------------------------------|------------------------------|-------------------|-----------|
| Nudr_DataRepository | 6.1    | Unified Data Repository Service                           | TS29504_Nudr_DR.yaml         | nudr-dr           | A.2       |
| Nudr_GroupIDmap     | 6.2    | Unified Data Repository Service for NF-Group ID retrieval | TS29504_Nudr_GroupIDmap.yaml | nudr-group-id-map | A.3       |
